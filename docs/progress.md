# Мой прогресс

Сохрани свою копию этого файла и отмечай пройденные задания.

Чтобы поставить галочку, замени `[ ]` на `[x]` в исходном Markdown:

```markdown
- [x] Задание разобрано
```

В файле репозитория отметки меняются через редактирование, а не простым нажатием на чекбокс.

Считай задание пройденным, когда программа работает и ты можешь объяснить её алгоритм. Если понадобилась теория — ничего страшного. Можно дописать рядом: «с подсказкой» или «повторить».

`extra` обозначает дополнительное тренировочное задание, а не подтверждённое условие экзамена.
