# Памятка по C

Чтобы быстро вспомнить синтаксис и вернуться к задаче. Подробные объяснения ищи в `theory.md` нужного задания.

## Сборка и запуск

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
./main
```

С математической библиотекой:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main -lm
```

С отладочной информацией:

```bash
gcc -Wall -Wextra -Werror -std=c11 -g main.c -o main
```

Собирай один файл решения за раз, а не все `.c` через `*.c`.

## Минимальная программа

```c
#include <stdio.h>

int main(void) {
    /* Твой код. */

    return 0;
}
```

## Типы и форматирование

| Тип | Для чего | `scanf` | `printf` |
| --- | --- | --- | --- |
| `int` | Целые числа | `%d` | `%d` |
| `long long` | Целые с большим диапазоном | `%lld` | `%lld` |
| `float` | Вещественные числа | `%f` | `%f` |
| `double` | Вещественные с большей точностью | `%lf` | `%f` |
| `char` | Символ | `%c` | `%c` |
| `size_t` | Размеры и индексы | `%zu` | `%zu` |

В `printf` значение `float` передаётся как `double`. Для `double` в C11 допустим и `%lf`, но обычно пишут `%f`.

В `scanf` разница между `%f` и `%lf` принципиальна: они ожидают указатели на разные типы.

### Примеры вывода

```c
printf("%d", 42);          /* 42 */
printf("%05d", 42);        /* 00042 */
printf("%05d", -12);       /* -0012 */
printf("%.2f", 3.141);     /* 3.14 */
printf("%.2f", 0.0);       /* 0.00 */
printf("%s", "Hello");     /* Hello */
```

Ширина поля — минимальная, а не максимальная. `%05d` не обрежет число из шести цифр.

`printf` не добавляет перевод строки автоматически.

## Ввод чисел

```c
int x;

if (scanf("%d", &x) != 1) {
    printf("n/a");
    return 0;
}
```

Два числа:

```c
int a, b;

if (scanf("%d %d", &a, &b) != 2) {
    printf("n/a");
    return 0;
}
```

`scanf` возвращает количество успешно присвоенных значений.

- При вводе числа нужен адрес: `&x`.
- При выводе нужно значение: `x`.

> Проверка результата `scanf` не является полной проверкой произвольного ввода. Например, `%d` может прочитать `12` из `12abc`, оставив буквы в потоке. Обрабатывать ли такой случай — зависит от условия.

## Арифметика

```c
7 / 2       /* 3 — целочисленное деление */
7.0 / 2     /* 3.5 */
7 % 2       /* 1 — остаток */
```

Если оба операнда целые, результат деления тоже целый:

```c
4 / 3       /* 1 */
4.0 / 3.0   /* примерно 1.333333 */
```

Операции с цифрами неотрицательного числа:

```c
digit = number % 10;  /* Последняя цифра. */
number /= 10;        /* Убираем последнюю цифру. */
```

Для отрицательных чисел нужно отдельно продумать знак. Не пытайся безусловно менять знак минимального значения типа: положительное значение может не помещаться.

### Переполнение

Тип переменной результата не исправляет переполнение, которое уже произошло при вычислении:

```c
long long result = (long long)a * b;
```

Приведение перед умножением заставляет выполнить его в `long long`. Но и у этого типа есть пределы.

## Условия

| Оператор | Значение |
| --- | --- |
| `==` | Равно |
| `!=` | Не равно |
| `<`, `>`, `<=`, `>=` | Сравнения |
| `&&` | И |
| `||` | Или |
| `!` | Не |

```c
if (x >= 0 && x <= 9) {
    /* x находится от 0 до 9 включительно. */
}
```

Не пиши:

```c
0 <= x <= 9
```

В C это не математическая запись двойного неравенства.

### Короткое замыкание

- `a && b`: если `a` ложно, `b` не вычисляется.
- `a || b`: если `a` истинно, `b` не вычисляется.

Порядок проверок может быть важен:

```c
i < length && text[i] != '\0'
```

Сначала проверяем индекс, потом обращаемся к элементу.

## Циклы

Фиксированное количество повторений:

```c
for (int i = 0; i < n; i++) {
    /* i: от 0 до n - 1. */
}
```

Числа до маркера `-1`:

```c
while (scanf("%d", &x) == 1 && x != -1) {
    /* Обработка числа. */
}
```

- `break` — выйти из ближайшего цикла.
- `continue` — перейти к следующей итерации.

## Символы

| Запись | Что означает |
| --- | --- |
| `'A'` | Символьный литерал |
| `"A"` | Строковый литерал |
| `' '` | Пробел |
| `'\n'` | Перевод строки |
| `'\0'` | Нулевой символ, завершающий строку в C |
| `'0'` | Символ цифры ноль |
| `EOF` | Специальное значение, сигнализирующее о конце ввода или ошибке чтения |

### Посимвольное чтение

```c
int ch;

while ((ch = getchar()) != EOF && ch != '\n') {
    putchar(ch);
}
```

Результат `getchar()` храним в `int`, чтобы различать символы и EOF.

### Проверка символов

Цифра:

```c
ch >= '0' && ch <= '9'
```

Латинская буква в ASCII:

```c
(ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z')
```

Смена регистра в ASCII:

```c
if (ch >= 'A' && ch <= 'Z') {
    ch = ch - 'A' + 'a';
}
```

Эти проверки латиницы не предназначены для кириллицы и UTF-8.

## Строки

Строка в C заканчивается `'\0'`.

```c
char word[] = "cat";
```

В массиве четыре элемента:

```text
'c' 'a' 't' '\0'
```

### Чтение строки с пробелами

Для текста до 100 символов:

```c
char text[102];

if (fgets(text, sizeof(text), stdin) == NULL) {
    text[0] = '\0';
}
```

Место нужно для 100 символов текста, возможного `'\n'` и завершающего `'\0'`.

`fgets` сохраняет перевод строки, если прочитала его.

Длина без завершающего перевода:

```c
int length = 0;

while (text[length] != '\0' && text[length] != '\n') {
    length++;
}
```

При необходимости убрать перевод строки:

```c
text[length] = '\0';
```

> Этот пример рассчитан на соблюдение ограничения длины. Если строка длиннее буфера, её остаток останется во входном потоке.

### Полезно помнить

- `scanf("%s", text)` читает слово до пробельного символа.
- `printf("%s", text)` выводит строку целиком до `'\0'`, включая пробелы.
- Для `%s` при вводе задавай максимальную ширину: например, `%100s` для массива из 101 элемента.
- После `scanf("%d", &x)` перевод строки обычно остаётся во входном потоке. Следующий `fgets` может прочитать только его.
- `first == second` не сравнивает содержимое двух массивов. Сравнивай символы или используй `strcmp`, если она разрешена.
- Не используй пользовательский текст как строку формата: пиши `printf("%s", text)`, а не `printf(text)`.

## Массивы

```c
int a[10];
```

Допустимые индексы: от `0` до `9`.

```c
a[0]   /* Первый элемент. */
a[9]   /* Последний элемент. */
a[10]  /* Выход за границу. */
```

Для строки длины `length`:

```c
text[length - 1]      /* Последний символ, если length > 0. */
text[length - 1 - i]  /* Симметричный символ для позиции i. */
```

Для матрицы:

```c
int matrix[3][4];
```

Первый индекс — строка, второй — столбец.

## Динамическая память

Подключи:

```c
#include <stdlib.h>
```

Выделение массива:

```c
int *a = malloc(count * sizeof(*a));

if (a == NULL) {
    /* Обработка ошибки. */
}
```

Перед выделением проверь размер по условию. При больших размерах нужно также убедиться, что произведение `count * sizeof(*a)` не переполнит `size_t`.

Освобождение:

```c
free(a);
a = NULL;
```

После `free` обращаться к элементам нельзя. Присваивание `NULL` не заменяет освобождение памяти.

### Изменение размера

Для положительного, заранее проверенного нового размера:

```c
int *tmp = realloc(a, new_count * sizeof(*a));

if (tmp != NULL) {
    a = tmp;
} else {
    /* Старый массив a остаётся доступным. */
}
```

Не записывай результат `realloc` сразу в единственный указатель на старый массив: при неудаче потеряешь его адрес.

## Побитовое исключающее ИЛИ

Оператор XOR — `^`.

```c
x ^ x  /* 0 */
x ^ 0  /* x */
```

Порядок применения XOR к целым значениям не меняет результат. Поэтому парные значения можно взаимно сократить, если условие задачи гарантирует нужное количество повторений.

`^` — не возведение в степень.

## Частые ошибки

| Ошибка | Что не так |
| --- | --- |
| `scanf("%d", x)` | Нужен указатель `&x` |
| `printf("%d", &x)` | Формат ожидает `int`, а передан указатель: неопределённое поведение |
| `if (x = 5)` | Это присваивание, а не сравнение |
| Чтение неинициализированной переменной | Может привести к неопределённому поведению |
| Выход за границы массива | Неопределённое поведение, даже если программа не упала |
| Забытый `'\0'` при ручной сборке строки | Строковые функции могут читать за её пределами |
| Потерянный указатель на выделенную память | Утечка памяти |
| Лишний пробел или `'\n'` | Ответ может не соответствовать формату |
