# EXAM_02_05. 205 — теория

## 1. Что не так в исходном коде

```c
int x = 205;
printf("%05d", &x);
```

Ошибок две:

1. В `printf` передан адрес переменной вместо её значения.
2. Формат `%05d` добавляет нули, а по условию нужно вывести ровно `205`.

## 2. Почему `&x` здесь лишний

```c
printf("%05d", &x);   /* неправильно */
printf("%d", x);      /* правильно */
```

`printf` не изменяет переменную, ей нужно само значение. Для `%d` ожидается `int`, а `&x` имеет тип `int *`. Это несовпадение формата и аргумента — неопределённое поведение. Компилятор предупреждает:

```text
warning: format '%d' expects argument of type 'int', but argument 2 has type 'int *'
```

С `-Werror` программа вообще не соберётся.

## 3. Почему `%05d` не подходит

```c
printf("%05d", x);
```

Такой формат выведет `00205`: минимальная ширина 5, свободные позиции слева заполняются нулями.

А в задании требуется ровно:

```text
205
```

Поэтому нужен обычный `%d`:

```c
printf("%d", x);
```

Если бы в условии требовалось `00205`, то `%05d` был бы правильным. Формат вывода всегда определяется примерами из задания.

## 4. Правильная программа

```c
#include <stdio.h>

int main(void) {
    int x = 205;

    printf("%d", x);

    return 0;
}
```

Здесь не нужны ни `scanf`, ни проверки ввода: входных данных у задания нет, значение `205` задано в самой программе.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `printf("%05d", &x)` | Для `%d` нужен `int`, а не `int *` — UB |
| `printf("%05d", x)` | Выведет `00205`, а нужно `205` |
| `printf("%d", &x)` | Тот же перепутанный тип аргумента |
| Добавить `\n` | Условие запрещает завершающий перенос |
| Выводить `x = 205` или пояснения | Нужно только число |
