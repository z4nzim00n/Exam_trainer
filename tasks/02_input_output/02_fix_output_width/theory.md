# EXAM_02_02. Исправление ошибок №2 — теория

## 1. Что не так в исходном коде

```c
int x = -21;

scanf("%d", x);
printf("%03d", x);
```

Здесь две ошибки:

1. В `scanf` передан не адрес переменной.
2. Ширина вывода `3` не совпадает с примерами: нужна ширина `5`.

## 2. Ошибка с `scanf`

```c
scanf("%d", x);    /* неправильно */
scanf("%d", &x);   /* правильно */
```

`scanf` должна записать число в переменную, поэтому ей нужен адрес:

```c
int x;
scanf("%d", &x);
```

Если передать значение `x` вместо адреса, `scanf` попытается записать число по случайному адресу. Это неопределённое поведение. Компилятор предупреждает:

```text
warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int'
```

С `-Werror` это уже ошибка компиляции.

## 3. Ошибка с шириной

```c
printf("%03d", x);
```

Число `3` — минимальная ширина поля. Но в примерах задания выводятся пять знаков:

| Вход | Нужный вывод |
| --- | --- |
| `0` | `00000` |
| `1` | `00001` |
| `-12` | `-0012` |
| `555555` | `555555` |

Значит, нужна ширина `5`, а не `3`:

```c
printf("%05d", x);
```

Как читается формат:

- `0` — заполнять свободные позиции слева нулями;
- `5` — минимальная ширина поля;
- `d` — целое число.

Ширина включает знак минус. Поэтому `-12` превращается в `-0012` (знак и три нуля), а не в `-00012`. Слишком длинное число не обрезается: `555555` выводится целиком.

## 4. Правильная программа

```c
#include <stdio.h>

int main(void) {
    int x = -21;

    if (scanf("%d", &x) != 1) {
        printf("n/a");
        return 0;
    }

    printf("%05d", x);

    return 0;
}
```

Инициализация `int x = -21;` ошибкой не является: значение всё равно перезаписывается при чтении. Она нужна только для того, чтобы переменная не осталась неинициализированной, если ввод пустой.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `scanf("%d", x)` | Передан не адрес, а значение — UB |
| Оставить `%03d` | Примеры требуют ширину 5 |
| `%5d` вместо `%05d` | Свободные позиции заполнятся пробелами, а не нулями |
| `printf("%05d", &x)` | Для `%d` нужен сам `int`, а не адрес |
| Добавить `\n` | Условие запрещает завершающий перенос |
