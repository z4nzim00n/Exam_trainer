# EXAM_02_01. Исправление ошибок №1 — теория

## 1. Что не так в исходном коде

```c
int x = 0;

scanf("%d", x);
printf("%05d", x);
```

Ошибка одна, но серьёзная: в `scanf` передан не адрес переменной, а её значение.

```c
scanf("%d", x);    /* неправильно */
scanf("%d", &x);   /* правильно */
```

## 2. Зачем `scanf` нужен адрес

`scanf` должна **записать** прочитанное число в переменную. В C функция не может изменить чужую локальную переменную, если ей не передали её адрес. Поэтому для `%d` нужен указатель на `int`:

```c
int x;
scanf("%d", &x);
```

`&x` — это адрес переменной `x`.

Когда адрес не передан, `scanf` воспринимает значение `x` (например, `0`) как адрес и пытается записать число по этому адресу. Это неопределённое поведение: программа может упасть, а может «сработать» случайно.

Компилятор это замечает:

```text
warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int'
```

С флагом `-Werror` предупреждение становится ошибкой компиляции. Поэтому тип ошибки здесь — не «логическая», а **ошибка работы с указателями / UB**.

## 3. Что делает `%05d`

```c
printf("%05d", x);
```

- `5` — минимальная ширина поля;
- `0` — заполнять свободные позиции слева нулями;
- `d` — вывести целое число.

Примеры:

| Значение `x` | Вывод `%05d` |
| --- | --- |
| `0` | `00000` |
| `1` | `00001` |
| `-12` | `-0012` |
| `666666` | `666666` |

Ширина включает знак минус, поэтому `-12` дополняется тремя нулями, а не четырьмя. Если число длиннее пяти символов, ширина не обрезает его: `666666` выводится полностью.

## 4. Правильная программа

```c
#include <stdio.h>

int main(void) {
    int x = 0;

    if (scanf("%d", &x) != 1) {
        printf("n/a");
        return 0;
    }

    printf("%05d", x);

    return 0;
}
```

- `&x` — адрес переменной;
- `scanf(...) != 1` — проверка, что число действительно прочитано (в задании этого не требуют, но на экзамене такая привычка полезна);
- `printf("%05d", x)` — вывод с нулями до ширины 5;
- `return 0;` — явное успешное завершение.

Инициализация `int x = 0;` не является ошибкой: значение всё равно перезапишет `scanf`. Она нужна только для того, чтобы переменная не была неинициализированной, если чтение не удалось.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `scanf("%d", x)` | Передан не адрес, а значение — UB |
| `printf("%05d", &x)` | В `printf` для `%d` нужен сам `int`, а не его адрес |
| `scanf("%d", &x);` без проверки результата | Пустой ввод оставит `x` без числа |
| Добавить `\n` в вывод | Условие запрещает завершающий перенос |
| Использовать `%5d` вместо `%05d` | Пробелы вместо нулей |
