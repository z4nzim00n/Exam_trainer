# EXAM_09_09. Подсчёт предложений

## Задание

| EXAM_09_09 | |
|---|---|
| **Уровень:** | 4 |
| **Темы:** | Текстовые файлы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, осуществляющую подсчёт предложений в текстовом файле. Путь до файла (относительно корневой директории) задаётся на стандартном потоке ввода stdin. Файл заканчивается символом новой строки `\n`.

Предложением считается фрагмент текста, который содержит хотя бы одну латинскую букву (в любом регистре) или цифру и заканчивается одним или несколькими подряд идущими знаками `.`, `!`, `?`. Количество предложений вывести на стандартный поток вывода stdout без переноса строки в конце. Если файл не удалось открыть, вывести "n/a".

## Примеры

| Входные данные (stdin) | Содержимое файла | Результат работы |
|------------------------|---|---|
| `test_1.txt`           | `what???` | `1` |
| `test_2.txt`           | `Test!? Yes!` | `2` |
| `test_3.txt` | `S.M.A.R.T. Smart smart! Test test....` | `7` |
| `nofile.txt`           | файла нет | `n/a` |

**Внимание:** Мы любезно напоминаем вам, что процедура тестирования вашей программы включает анализ стиля кода. Пожалуйста, загляните в папку "materials/". Также обязательно проверяйте вашу программу на утечки памяти (не забывайте закрывать файл).
