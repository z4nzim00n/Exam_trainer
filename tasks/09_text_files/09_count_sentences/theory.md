# EXAM_09_09. Подсчёт предложений — теория

## 1. С чего начать

Нужно прочитать файл и посчитать предложения. Предложение: есть хотя бы одна буква или цифра и в конце один или несколько знаков `.` `!` `?`.

Хранить текст не нужно. Достаточно читать по одному символу и помнить одно: **была ли уже буква или цифра** с конца прошлого предложения.

```
открыть → читать символы → буква/цифра: запомнить → знак конца: если было что запомнить, count++ → закрыть → вывести
```

## 2. Каркас решения (его стоит запомнить)

1. Путь через `scanf`, `fopen`, проверка `NULL` → `n/a`.
2. `int count = 0; int has_text = 0;`
3. `while ((c = fgetc(file)) != EOF)`:
    - буква или цифра → `has_text = 1`;
    - `.` `!` `?` → если `has_text`, то `count++; has_text = 0;`
4. `fclose(file)`, `printf("%d", count)`.

## 3. Как выразить это на C

### Проверка буквы и цифры без ctype.h

```c
(c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9')
```

Коды букв и цифр идут подряд, поэтому хватает сравнения с границами.

### Флаг has_text

Это «память» программы. Он включается, когда увидели букву или цифру, и выключается, когда предложение закончилось.

### Группа знаков

```
what???
```

Первый `?` видит `has_text == 1`: считаем предложение и выключаем флаг. Второй и третий `?` видят `has_text == 0` и ничего не делают. Так группа знаков считается ровно один раз.

### Строка только из знаков

`...` или `!?` предложением не считается: перед ними не было буквы или цифры, `has_text == 0`.

### Нет знака в конце

`hello` и `\n` без `.` `!` `?` предложением не считается. Флаг включён, но знака конца нет, и `count` не растёт.

### Предложение на нескольких строках

`\n` на флаг не влияет. Поэтому `Hello` на одной строке и `world.` на следующей составляют одно предложение.
### Сокращения с точками

Правило простое: знак `.` `!` `?` после текста завершает предложение. Поэтому в `S.M.A.R.T. Smart smart! Test test....` получается 7 предложений: `S.`, `M.`, `A.`, `R.`, `T.`, `Smart smart!` и `Test test....`. Исключений для сокращений нет.
## 4. Проверка на примере

`Test!? Yes!`

| Символ | Что происходит | `count` |
|---|---|---|
| `T` `e` `s` `t` | `has_text = 1` | 0 |
| `!` | есть текст → `count++`, `has_text = 0` | 1 |
| `?` | текста нет, пропускаем | 1 |
| пробел | ничего | 1 |
| `Y` `e` `s` | `has_text = 1` | 1 |
| `!` | есть текст → `count++` | 2 |

Вывод: `2`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Считать каждый `.` `!` `?` | `what???` даст 3 вместо 1 |
| Не сбрасывать `has_text` | Каждый следующий знак будет считаться предложением |
| Не проверять `has_text` | `...` будет считаться предложением |
| `char c` вместо `int c` | `EOF` нельзя надёжно отличить от символа |
| Нет проверки `file == NULL` | Падение, если файла нет |
| Не вызвать `fclose` | Утечка, видна в Valgrind |
| Печатать `\n` после числа | В конце вывода переноса быть не должно |
