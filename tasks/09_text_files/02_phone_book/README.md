Написать программу, осуществляющую вывод телефонного справочника на стандартный поток вывода stdout. Данные о контактах построчно хранятся в текстовом файле, путь до которого задаётся на стандартном потоке ввода stdin и заканчивается символом новой строки. Формат хранения данных в файле отличается от необходимого формата вывода на стандартный поток вывода, описание этих форматов приведено ниже. В конце ответа не должно быть переноса на следующую строку. Проверить на валидность введённые данные. В случае любой ошибки выводить "n/a".

**Формат входных данных (файл)**

Каждая строка файла: `имя_контакта:телефон_формат_1`

- `телефон_формат_1`: `8-xxx-xxx-xx-xx`, где x — цифра от 0 до 9.

Пример: `Test:8-950-111-22-33`

**Формат выходных данных**

Для каждого контакта: `имя_контакта телефон_формат_2`

- Контакты разделяются символом перевода строки `\n`. После последнего контакта перевода строки нет.
- Между именем контакта и его телефоном находится ровно один пробел.
- `телефон_формат_2`: `+7(xxx)xxx-xx-xx`, где x — цифра от 0 до 9.

Пример: `Test +7(950)111-22-33`

## Примеры
