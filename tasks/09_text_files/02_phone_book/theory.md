# EXAM_09_02. Телефонный справочник — теория

## 1. С чего начать

По условию:

- из stdin приходит **путь к файлу**;
- в файле строки `имя:8-xxx-xxx-xx-xx`, выводить надо `имя +7(xxx)xxx-xx-xx`;
- при любой ошибке выводится только `n/a`.

Последний пункт определяет структуру. Если ошибка в пятой строке, а первые четыре уже напечатаны, исправить вывод нельзя. Поэтому программа делает **два прохода**:

```
открыть файл → проход 1: проверить все строки → проход 2: напечатать
```

## 2. Каркас решения (его стоит запомнить)

Всё пишется в `main`, по шагам:

1. Объявить `path`, `line`, прочитать путь через `scanf("%255s", path)`.
2. `fopen`. Если `NULL` — `n/a`.
3. Проход 1: `while (fgets(...))`, в нём проверка строки, `count++`.
4. Если `!ok` или `count == 0` — `n/a`, `fclose`, `return 0`.
5. `rewind(file)`, `count = 0`.
6. Проход 2: `while (fgets(...))`, в нём `printf`.
7. `fclose`.

## 3. Как выразить это на C

### Чтение пути

```c
char path[256];
scanf("%255s", path);
```

`%s` читает слово до пробела или `\n`, поэтому убирать перенос не нужно. Число 255 защищает массив от переполнения. Перед `path` нет `&`: имя массива уже является адресом.

### Открытие и чтение файла

```c
FILE* file = fopen(path, "r");
if (file == NULL) { ... }

while (fgets(line, sizeof(line), file) != NULL) { ... }

fclose(file);
```

`fgets` читает строку **вместе с `\n`** и возвращает `NULL`, когда строки кончились. Каждый открытый файл нужно закрыть, иначе Valgrind покажет утечку.

### Как убрать `\n` из строки

```c
line[strcspn(line, "\n")] = '\0';
```

`strcspn` возвращает позицию первого `\n`, а если его нет (последняя строка без переноса) — позицию конца строки. В обоих случаях строка корректно обрезается.

### Поиск двоеточия

```c
const char* colon = strchr(line, ':');
```

Возвращает указатель на `:` или `NULL`. Телефон начинается с `colon + 1`.

### Проверка телефона по маске

Телефон `8-950-111-22-33` — это ровно 15 символов. Маска: `d` — цифра, остальное совпадает буквально.

```c
const char* mask = "8-ddd-ddd-dd-dd";
for (int i = 0; i < 15; i++) {
    if (mask[i] == 'd') {
        if (phone[i] < '0' || phone[i] > '9') ok = 0;
    } else if (phone[i] != mask[i]) {
        ok = 0;
    }
}
```

Сначала проверяем `strlen(colon + 1) == 15`, иначе цикл выйдет за границу строки.

### Вывод по частям

`%.3s` печатает не больше 3 символов. Для `phone = "8-950-111-22-33"`:

| Часть | Откуда | Пример |
|---|---|---|
| код | `phone + 2`, 3 символа | `950` |
| первые 3 цифры | `phone + 6`, 3 символа | `111` |
| первая пара | `phone + 10`, 2 символа | `22` |
| вторая пара | `phone + 13`, 2 символа | `33` |

Чтобы напечатать имя через `%s`, ставим `*colon = '\0'`: строка обрывается на двоеточии.

### Перенос строки только между контактами

Печатаем `\n` **перед** каждым контактом, кроме первого:

```c
if (count > 0) printf("\n");
```

### Возврат в начало

`rewind(file)` возвращает чтение в начало файла. Массив для хранения строк не нужен, поэтому `malloc` и `free` не нужны.

## 4. Проверка на примере

```
Smith:8-950-111-22-33
Miller:8-900-999-66-55
```

Проход 1: обе строки проходят маску. Проход 2: `Smith +7(950)111-22-33`, перенос, `Miller +7(900)999-66-55`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Печатать во время проверки | При ошибке в конце файла уже напечатана часть, а нужен только `n/a` |
| Не закрыть файл (в том числе перед `return` при ошибке) | Утечка, Valgrind её покажет |
| Не проверить `fopen` на `NULL` | Падение при несуществующем файле |
| Не обработать пустой файл | Нужно `n/a`, а не пустой вывод |
| Обращаться к `phone[i]`, не проверив длину | Выход за границу строки |
| `\n` после каждого контакта | После последнего переноса быть не должно |
| `&path` или `path[256]` в `scanf` | Для массива `&` не нужен, ширина указывается числом в формате |
