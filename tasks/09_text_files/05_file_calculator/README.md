Написать программу, осуществляющую вычисление арифметических выражений, которые содержатся в текстовом файле. Путь до файла (относительный) задаётся на стандартном потоке ввода stdin.

Каждая строка файла — одно арифметическое выражение. Выражение состоит из целых неотрицательных чисел, разделённых арифметическими операциями. Между двумя соседними числами находится ровно одна операция. Используются только сложение (`+`) и вычитание (`-`). Операции выполняются слева направо. Концом выражения является перевод строки или конец файла.

Результаты вычисления выражений необходимо вывести на стандартный поток вывода stdout через запятую с пробелом (`, `), в том порядке, в котором выражения расположены в файле. Если строка не удовлетворяет описанным выше критериям, то в качестве результата этого выражения вывести `n/a`. В конце вывода переноса строки нет.

Если файл невозможно открыть или в нём нет ни одного выражения, вывести `n/a`.

_Примечание: Числа в выражениях содержат не более 9 цифр, более длинные числа считаются ошибкой._

Примечание: Пробелы и любые другие символы, кроме цифр, `+` и `-`, в выражении недопустимы.

## Примеры

| Входные данные (stdin) | Содержимое файла | Результат работы |
|---|---|---|
| `test_1.txt` | `100+100` | `200` |
| `test_2.txt` | `100++100` | `n/a` |
| `test_3.txt` | `100+100-100` | `100` |
| `test_4.txt` | `1+1`<br>`2+2` | `2, 4` |
| `test_5.txt` | `1+1`<br>`100--100`<br>`2+2` | `2, n/a, 4` |
