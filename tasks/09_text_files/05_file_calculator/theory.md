# EXAM_09_05. Простой подсчёт — теория

## 1. С чего начать

По условию:

- путь к файлу приходит из stdin;
- каждая строка файла — отдельное выражение из чисел и знаков `+`/`-`;
- результаты выводятся через `, `, некорректная строка даёт `n/a` и не влияет на остальные.

Трудность в том, что строку нужно **проверять и считать одновременно**, и так для каждой строки файла.

## 2. Правила

Корректная строка: «число, операция, число, ..., число».

- начинается и заканчивается числом;
- между числами ровно одна операция (`1++1` и `1+-1` запрещены);
- других символов нет, даже пробелов.

Считаем слева направо: `10-5+3` = `(10-5)+3` = `8`.

## 3. Каркас решения (его стоит запомнить)

Два вложенных цикла в `main`:

```
c = fgetc(file)
пока c != EOF:                      ← одна итерация = одна строка
    total = 0, number = 0, sign = 1, digits = 0, ok = 1
    пока c != EOF и c != '\n':      ← символы строки
        цифра → дописать к number
        + или - после числа → прибавить number к total, запомнить знак
        иначе → ok = 0
        c = fgetc(file)
    если digits == 0 → ok = 0
    total += sign * number
    напечатать результат или n/a
    если c == '\n' → c = fgetc(file)
```

## 4. Как выразить это на C

### Чтение по одному символу

```c
int c = fgetc(file);
```

Тип `int`, а не `char`: `EOF` не помещается в `char` без потерь.

### Цифры

Цифра `'7'` — это код символа, а не число 7. Чтобы получить число, вычитаем `'0'`:

```c
number = number * 10 + (c - '0');
```

`1`, `2`, `3` дают `0 → 1 → 12 → 123`.

### Проверка цифры

```c
if (c >= '0' && c <= '9') { ... }
```

Коды цифр идут подряд, поэтому библиотека `ctype.h` не нужна.

### Запрет двух операций подряд

```c
(c == '+' || c == '-') && digits > 0
```

Если перед знаком не было цифр (начало строки или другой знак), условие ложно, и срабатывает ветка `else` с `ok = 0`. Одна проверка отсекает `+1`, `1++1`, `1--1`.

### Знак и накопление

После числа прибавляем `sign * number` к `total`, затем обновляем `sign` по новому знаку:

```c
total += sign * number;
sign = (c == '+') ? 1 : -1;
number = 0;
digits = 0;
```

Последнее число в конце строки прибавляется отдельно, после внутреннего цикла.

### Зачем читать строку до конца при ошибке

При ошибке только `ok = 0`, цикл продолжается. Иначе остаток плохой строки прочитается как начало следующей.

### Тип long long

`999999999 + 999999999` не помещается в `int`. Для сумм используем `long long` и формат `%lld`. Числа длиннее 9 цифр считаем ошибкой, чтобы `number` не переполнялся.

### Разделитель

`, ` печатаем **перед** каждым результатом, кроме первого:

```c
if (count > 0) printf(", ");
```

### Переход на следующую строку

После внутреннего цикла `c` равен `'\n'` или `EOF`. Если это `'\n'`, читаем следующий символ. Если файл закончился на `'\n'`, получится `EOF`, и пустой строки в конце не появится.

## 5. Проверка на примере

```
1+1
100--100
2+2
```

| Строка | Что происходит | Результат |
|---|---|---|
| `1+1` | `1`; `+` (total=1, sign=+1); `1` → total=2 | `2` |
| `100--100` | `100`; `-` (total=100, sign=−1); второй `-` при `digits == 0` → `ok = 0` | `n/a` |
| `2+2` | как первая | `4` |

Вывод: `2, n/a, 4`.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `char c` вместо `int c` | `EOF` нельзя надёжно отличить от символа |
| Прервать чтение строки при ошибке | Остаток попадёт в следующую строку |
| Забыть прибавить последнее число | В конце строки оно ещё не в `total` |
| Считать `10-5+3` как `10-(5+3)` | Вычисление идёт слева направо |
| Не проверить `digits == 0` в конце | `1+` будет посчитана как `1` |
| `, ` после каждого результата | Лишняя запятая в конце |
| `int` для суммы | Возможно переполнение |
| Не вызвать `fclose` | Утечка, видна в Valgrind |
| Считать `\n` в конце файла пустой строкой | Появится лишний `n/a` |
