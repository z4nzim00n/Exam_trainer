# EXAM_09_05. Простой подсчёт — Тесты

## Компиляция

```
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Подготовка тестовых файлов

Файлы создаются в папке с программой командой `printf`. Символ `\n` внутри `printf` означает перевод строки.

```
printf '100+100' > test_1.txt
printf '100+100-100' > test_3.txt
printf '1+1\n2+2' > test_4.txt
printf '1+1\n100--100\n2+2' > test_5.txt
printf '5-10' > v1.txt
printf '0+0\n0-0' > v2.txt
printf '7\n' > v3.txt
printf '1+1\n2+2\n' > v4.txt
printf '007+003' > v5.txt
printf '999999999+999999999' > v6.txt
printf '10-5+3' > v7.txt
```

## Валидные данные

| Ввод (stdin) | Содержимое файла | Результат | Команда | Пояснение |
|---|---|---|---|---|
| `test_1.txt` | `100+100` | `200` | `echo "test_1.txt" \| ./main` | сложение |
| `test_3.txt` | `100+100-100` | `100` | `echo "test_3.txt" \| ./main` | цепочка операций, слева направо |
| `test_4.txt` | `1+1`<br>`2+2` | `2, 4` | `echo "test_4.txt" \| ./main` | две строки, разделитель `, ` |
| `test_5.txt` | `1+1`<br>`100--100`<br>`2+2` | `2, n/a, 4` | `echo "test_5.txt" \| ./main` | плохая строка не ломает остальные |
| `v1.txt` | `5-10` | `-5` | `echo "v1.txt" \| ./main` | отрицательный результат допустим |
| `v2.txt` | `0+0`<br>`0-0` | `0, 0` | `echo "v2.txt" \| ./main` | нули |
| `v3.txt` | `7` и `\n` в конце файла | `7` | `echo "v3.txt" \| ./main` | одно число, `\n` в конце файла не создаёт пустую строку |
| `v4.txt` | `1+1`<br>`2+2` и `\n` в конце файла | `2, 4` | `echo "v4.txt" \| ./main` | то же для нескольких строк |
| `v5.txt` | `007+003` | `10` | `echo "v5.txt" \| ./main` | ведущие нули допустимы |
| `v6.txt` | `999999999+999999999` | `1999999998` | `echo "v6.txt" \| ./main` | максимальные 9-значные числа, нужен `long long` |
| `v7.txt` | `10-5+3` | `8` | `echo "v7.txt" \| ./main` | вычисление слева направо: (10-5)+3 |

## Некорректные данные (n/a)

Файлы для проверок:

```
printf '100++100' > test_2.txt
printf '1+' > e1.txt
printf '+1' > e2.txt
printf '1 + 1' > e3.txt
printf '1*2' > e4.txt
printf 'abc' > e5.txt
printf '1+-1' > e6.txt
printf '1234567890+1' > e7.txt
printf '' > e8.txt
printf '\n' > e9.txt
printf '1+1\n\n2+2' > p1.txt
printf '1+1\r\n2+2' > p2.txt
```

Файлы `e1`–`e9`: ошибка во всём файле, результат `n/a`.

| Ввод (stdin) | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `test_2.txt` | `n/a` | `echo "test_2.txt" \| ./main` | две операции подряд |
| `e1.txt` | `n/a` | `echo "e1.txt" \| ./main` | выражение заканчивается операцией |
| `e2.txt` | `n/a` | `echo "e2.txt" \| ./main` | выражение начинается с операции |
| `e3.txt` | `n/a` | `echo "e3.txt" \| ./main` | пробелы недопустимы |
| `e4.txt` | `n/a` | `echo "e4.txt" \| ./main` | допустимы только `+` и `-` |
| `e5.txt` | `n/a` | `echo "e5.txt" \| ./main` | в строке нет цифр |
| `e6.txt` | `n/a` | `echo "e6.txt" \| ./main` | `+-` подряд |
| `e7.txt` | `n/a` | `echo "e7.txt" \| ./main` | в числе больше 9 цифр |
| `e8.txt` | `n/a` | `echo "e8.txt" \| ./main` | пустой файл, выражений нет |
| `e9.txt` | `n/a` | `echo "e9.txt" \| ./main` | в файле одна пустая строка |
| `nofile.txt` | `n/a` | `echo "nofile.txt" \| ./main` | такого файла нет |
| (пусто) | `n/a` | `./main < /dev/null` | путь не задан |

Файлы `p1` и `p2`: плохая только одна строка, остальные считаются.

| Ввод (stdin) | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `p1.txt` | `2, n/a, 4` | `echo "p1.txt" \| ./main` | пустая строка посередине даёт `n/a` только для себя |
| `p2.txt` | `n/a, 4` | `echo "p2.txt" \| ./main` | в первой строке символ `\r` недопустим, вторая строка верна |

## Cppcheck

Статический анализ кода. Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

Проверка стиля и форматирования кода.

```
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```
clang-format -i main.c
```

## Valgrind

Проверка ошибок работы с памятью и утечек памяти. Незакрытый файл будет показан как утечка.

```
echo "test_5.txt" | valgrind --leak-check=full ./main
```

Обратите внимание: Valgrind запускается уже на скомпилированном файле.
