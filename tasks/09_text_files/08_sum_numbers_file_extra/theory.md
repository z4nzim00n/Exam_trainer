# EXAM_09_08. Сумма чисел из файла — теория

## 1. С чего начать

Шаблон тот же, что в «Выводе файла»: открыть, прочитать в цикле, закрыть. Новое: вместо символов читаем **числа**, поэтому нужен `fscanf`.

```
открыть → читать числа, пока читаются → закрыть → проверить, почему остановились → вывести
```

## 2. Каркас решения (его стоит запомнить)

1. Путь через `scanf`, `fopen`, проверка `NULL`.
2. `long sum = 0; int count = 0;`
3. `while ((status = fscanf(file, "%d", &number)) == 1) { sum += number; count++; }`
4. `fclose(file);`
5. `status != EOF || count == 0` → `n/a`, иначе печатаем сумму.

## 3. Как выразить это на C

### fscanf

```c
fscanf(file, "%d", &number)
```

Это `scanf`, у которого первым аргументом указан файл. Всё остальное так же: формат и адрес переменной (с `&`). Пробелы и переводы строк между числами пропускаются автоматически.

### Что возвращает fscanf

| Значение | Что значит |
|---|---|
| `1` | число прочитано |
| `EOF` | файл закончился |
| `0` | на месте числа что-то другое, например буква |

Цикл крутится, пока возвращается `1`.

### Почему важна проверка после цикла

Цикл останавливается и при конце файла, и при плохом символе. Различить их можно только по `status`:

- `EOF` — всё прочитано нормально;
- не `EOF` — встретилось не число, нужно `n/a`.

Файл без единого числа тоже ошибка: тогда `count == 0`.

### Почему long

Сумма нескольких больших `int` может не поместиться в `int`. Для суммы берём `long` и формат `%ld`.

## 4. Проверка на примере

Файл `1 2 3`: читаем 1, 2, 3, затем `EOF`. Цикл закончился, `status == EOF`, `count == 3`. Вывод: `6`.

Файл `1 2 x`: читаем 1, 2, затем `fscanf` возвращает `0` на букве `x`. `status != EOF`, вывод `n/a`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `while (!feof(file))` | Цикл сделает лишний проход, последнее число прочитается дважды |
| Нет `&` перед `number` | Программа упадёт |
| Не проверить `status` после цикла | `1 2 x` даст `3` вместо `n/a` |
| Не проверить `count == 0` | Пустой файл даст `0` вместо `n/a` |
| `int` для суммы | Возможно переполнение |
| Не вызвать `fclose` | Утечка, видна в Valgrind |
| `scanf` вместо `fscanf` | Читаем с клавиатуры, а не из файла |
