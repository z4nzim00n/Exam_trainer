# EXAM_09_08. Сумма чисел из файла

## Задание

| EXAM_09_08 | |
|---|---|
| **Уровень:** | 1 |
| **Темы:** | Текстовые файлы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, которая вычисляет сумму целых чисел, записанных в текстовом файле. Путь до файла задаётся на стандартном потоке ввода stdin. Числа в файле разделены пробелами или переводами строк. Сумму вывести на стандартный поток вывода stdout без переноса строки в конце.

Проверить на валидность введённые данные. Если файл не удалось открыть, в нём нет чисел или встретилось что-то, кроме целых чисел, вывести "n/a".

## Примеры

| Входные данные (stdin) | Содержимое файла | Результат работы |
|---|---|---|
| `test.txt` | `1 2 3` | `6` |
| `test.txt` | `10`<br>`20`<br>`30` | `60` |
| `test.txt` | `1 2 x` | `n/a` |

**Внимание:** Мы любезно напоминаем вам, что процедура тестирования вашей программы включает анализ стиля кода. Пожалуйста, загляните в папку "materials/". Также обязательно проверяйте вашу программу на утечки памяти (не забывайте закрывать файл).
