# EXAM_09_5. Позиционирование в файле — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Подготовка файлов

```bash
printf 'Hello' > p1.txt
printf 'abc\ndef' > p2.txt
printf 'Z' > p3.txt
: > empty.txt
```

## Валидные данные

| Ввод (`stdin`) | Содержимое файла | Результат | Пояснение |
|---|---|---|---|
| `p1.txt` затем `0` | `Hello` | `5 72` | первый символ `H` |
| `p1.txt` затем `1` | `Hello` | `5 101` | второй символ `e` |
| `p1.txt` затем `4` | `Hello` | `5 111` | последний символ |
| `p2.txt` затем `3` | `abc\ndef` | `7 10` | перевод строки |
| `p3.txt` затем `0` | `Z` | `1 90` | файл из одного байта |

## Некорректные данные

| Ввод (`stdin`) | Результат | Причина |
|---|---|---|
| `missing.txt` затем `0` | `n/a` | файла нет |
| `empty.txt` затем `0` | `n/a` | пустой файл |
| `p1.txt` затем `5` | `n/a` | позиция равна размеру |
| `p1.txt` затем `10` | `n/a` | позиция за концом файла |
| `p1.txt` затем `-1` | `n/a` | отрицательная позиция |
| `p1.txt` затем `abc` | `n/a` | позиция не число |
| только `p1.txt` | `n/a` | позиция не задана |
| пустой ввод | `n/a` | ввод отсутствует |

## Ручная проверка

```bash
printf 'abc\ndef' > p2.txt
printf 'p2.txt\n3\n' | ./main
```

Ожидаемый результат:

```text
7 10
```
