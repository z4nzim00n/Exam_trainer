# Теория — Позиционирование в файле

## 1. Указатель позиции файла

При открытии файла для чтения или записи у него есть текущая позиция.

После чтения символа указатель перемещается дальше.

Например, содержимое файла:

```text
Hello
```

Позиции символов:

| Символ | Позиция |
|---|---:|
| H | 0 |
| e | 1 |
| l | 2 |
| l | 3 |
| o | 4 |

Позиция начинается с нуля.

## 2. Перемещение указателя — `fseek()`

Функция `fseek()` позволяет переместить указатель позиции файла.

```c
fseek(file, offset, origin);
```

Аргументы:

- `file` — указатель на открытый файл.
- `offset` — смещение.
- `origin` — точка отсчёта.

Основные точки отсчёта:

| Константа | Значение |
|---|---|
| `SEEK_SET` | Начало файла |
| `SEEK_CUR` | Текущая позиция |
| `SEEK_END` | Конец файла |

### Примеры

Переместиться в начало:

```c
fseek(file, 0, SEEK_SET);
```

Переместиться в конец:

```c
fseek(file, 0, SEEK_END);
```

Переместиться на третий байт от начала:

```c
fseek(file, 2, SEEK_SET);
```

При успехе `fseek()` возвращает `0`, при ошибке — ненулевое значение.

## 3. Получение позиции — `ftell()`

Функция `ftell()` возвращает текущую позицию указателя в файле.

```c
long position = ftell(file);
```

Если указатель находится в начале файла, результат будет `0`.

Если указатель находится в конце файла, для обычного файла в бинарном режиме результат соответствует его размеру в байтах.

При ошибке возвращается `-1L`.

## 4. Получение размера файла

Размер файла можно получить через сочетание `fseek()` и `ftell()`.

```c
fseek(file, 0, SEEK_END);

long file_size = ftell(file);
```

Как это работает:

1. `fseek()` перемещает указатель в конец файла.
2. `ftell()` возвращает текущую позицию.
3. Эта позиция соответствует размеру файла в байтах для обычного файла в бинарном режиме.

## 5. Чтение символа с определённой позиции

Чтобы прочитать символ с конкретной позиции:

```c
fseek(file, position, SEEK_SET);

int current_char = fgetc(file);
```

Сначала перемещаем указатель на нужную позицию, затем считываем символ.

Например, для файла `Hello`:

```c
fseek(file, 1, SEEK_SET);

int current_char = fgetc(file);
```

Результатом будет символ `e`.

## 6. Числовой код символа

Символы хранятся в виде числовых кодов.

Например, в ASCII:

| Символ | Код |
|---|---:|
| A | 65 |
| B | 66 |
| C | 67 |
| a | 97 |
| b | 98 |
| c | 99 |

Если вывести переменную типа `int` через `%d`, содержащую результат `fgetc()`, будет выведен числовой код символа.

```c
int current_char = fgetc(file);

printf("%d", current_char);
```

## 7. Проверка границ файла

Перед чтением необходимо убедиться, что позиция находится внутри файла.

```c
if (position < 0 || position >= file_size) {
    printf("n/a");
}
```

Почему используется `>=`?

Потому что последняя допустимая позиция равна `file_size - 1`.

Например, файл содержит 5 байт:

```text
H e l l o
0 1 2 3 4
```

Позиция `4` допустима.

Позиция `5` уже находится за пределами содержимого файла.

## Что нужно запомнить

| Функция / константа | Назначение |
|---|---|
| `fseek()` | Переместить указатель файла |
| `ftell()` | Получить текущую позицию |
| `fgetc()` | Прочитать символ |
| `SEEK_SET` | Отсчёт от начала |
| `SEEK_CUR` | Отсчёт от текущей позиции |
| `SEEK_END` | Отсчёт от конца |

**Главная последовательность задачи:**

```c
fseek(file, 0, SEEK_END);
long file_size = ftell(file);

fseek(file, position, SEEK_SET);
int current_char = fgetc(file);
```

Она позволяет определить размер файла и прочитать символ с нужной позиции.
