# EXAM_09_05. Позиционирование в файле

| EXAM_09_05                  | |
|-----------------------------|---|
| **Уровень:**                | 3 |
| **Темы:**                   | Текстовые файлы, позиционирование в файле. |
| **Директория для решения:** | `src/` |
| **Файлы решения:**          | `main.c` |
| **Входные данные:**         | Стандартный поток ввода (`stdin`) |
| **Выходные данные:**        | Стандартный поток вывода (`stdout`) |

Написать программу, которая определяет размер текстового файла и считывает символ по указанной позиции.

На стандартном потоке ввода задаются:

1. путь к файлу отдельной строкой;
2. неотрицательное целое число `position` — позиция символа в файле, начиная с нуля.

Программа должна вывести размер файла в байтах и десятичный код символа, находящегося на указанной позиции, разделив значения одним пробелом.

Для определения размера файла использовать `fseek()` и `ftell()`. Для перехода к нужному символу также использовать `fseek()`.

Если файл не удалось открыть, позиция некорректна, файл пустой, позиция выходит за границы файла или произошла ошибка чтения/позиционирования, вывести `n/a`.

В конце вывода переноса строки нет.

## Примеры

| Входные данные (`stdin`) | Содержимое файла | Результат |
|---|---|---|
| `a.txt`<br>`0` | `Hello` | `5 72` |
| `a.txt`<br>`1` | `Hello` | `5 101` |
| `b.txt`<br>`3` | `abc`<br>`def` | `7 10` |
| `empty.txt`<br>`0` | пустой файл | `n/a` |
| `a.txt`<br>`5` | `Hello` | `n/a` |

**Примечание:** перевод строки `\n` считается одним байтом. Например, файл `abc\ndef` имеет размер 7 байт, а символ на позиции 3 — перевод строки с кодом 10.
