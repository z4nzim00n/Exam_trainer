# EXAM_09_06_ALT. Шифр Цезаря для файла 
Главное отличие - тут используется вывод в stdout.

## Задание

| EXAM_09_06_ALT | |
|---|---|

| **Темы:** | Текстовые файлы, строки. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, осуществляющую шифрование текстового файла шифром Цезаря. Путь до файла и целый ключ шифрования (сдвиг) задаются на стандартном потоке ввода stdin: сначала путь, затем ключ. Ключ может быть положительным, отрицательным и любым по величине.

Шифруются только латинские буквы, регистр сохраняется. Остальные символы (цифры, пробелы, знаки, переводы строк) выводятся без изменений. Зашифрованный текст вывести на стандартный поток вывода stdout. Сам файл не изменяется. Если файл не удалось открыть или ключ не прочитан, вывести "n/a".

Формулы: y = (x + k) mod n, x = (y - k) mod n, где mod — остаток от деления, x — исходный символ, y — зашифрованный, n — мощность алфавита (26), k — ключ.

## Примеры

| Входные данные (stdin) | Содержимое файла | Результат работы |
|---|---|---|
| `1.txt`<br>`1` | `abcdef` | `bcdefg` |
| `2.txt`<br>`2` | `abc`<br>`def` | `cde`<br>`fgh` |
| `3.txt`<br>`1` | `a-b-c` | `b-c-d` |
| `4.txt`<br>`1` | `zAB1` | `aBC1` |
