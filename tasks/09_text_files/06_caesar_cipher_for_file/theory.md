# EXAM_09_06_ALT. Шифр Цезаря для файла — теория

## 1. С чего начать

Шаблон работы с файлом: открыть, читать в цикле, закрыть. Внутри цикла каждый символ шифруется и сразу печатается. Хранить текст не нужно, а файл остаётся нетронутым.

```
прочитать путь и ключ → открыть → для каждого символа: зашифровать, напечатать → закрыть
```

## 2. Каркас решения (его стоит запомнить)

1. `scanf("%255s %d", path, &shift) != 2` → `n/a`.
2. `fopen(path, "r")`, `NULL` → `n/a`.
3. `shift = shift % 26; if (shift < 0) shift += 26;`
4. `while ((c = fgetc(file)) != EOF)`: строчная, заглавная, остальное; `putchar(c)`.
5. `fclose(file)`.

## 3. Как выразить это на C

### Формула шифра

```c
c = 'a' + (c - 'a' + shift) % 26;
```

- `c - 'a'` — номер буквы от 0 до 25;
- `+ shift` — сдвиг;
- `% 26` — зацикливает алфавит: после `z` идёт `a`;
- `'a' +` — обратно в код буквы.

Для заглавных то же самое с `'A'`. Регистр сохраняется, потому что ветки раздельные.

### Отрицательный и большой ключ

В C `-1 % 26` равно `-1`, а не `25`. Поэтому один раз приводим ключ к диапазону 0..25:

```c
shift = shift % 26;
if (shift < 0) {
    shift += 26;
}
```

Ключ `-1` становится `25`, ключ `29` становится `3`. Расшифровка это тот же шифр с ключом `-k`.

### Чтение двух значений

`scanf("%255s %d", path, &shift)`: у `path` нет `&`, у `shift` есть. Результат должен быть 2.

### Режим "r"

Файл только читается и не меняется. Режимы `"r+"` и `"w"` здесь не нужны.

### Вывод символ за символом

`putchar(c)` печатает символ как есть. Цифры, пробелы, знаки и `\n` не попадают в ветки шифра и выводятся неизменными.

## 4. Проверка на примере

Файл `zAB1`, ключ 1.

| Символ | Номер | + 1 | Результат |
|---|---|---|---|
| `z` | 25 | 26 % 26 = 0 | `a` |
| `A` | 0 | 1 | `B` |
| `B` | 1 | 2 | `C` |
| `1` | — | — | `1` |

Вывод: `aBC1`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Не нормализовать отрицательный ключ | `% 26` даст отрицательный номер и мусорный символ |
| После `z` переходить к `A` | Регистр должен сохраняться |
| Шифровать цифры и знаки | Они остаются без изменений |
| `char c` вместо `int c` | `EOF` нельзя надёжно отличить от символа |
| Записывать результат в файл | Результат выводится в stdout |
| Не вызвать `fclose` | Утечка, видна в Valgrind |
| Печатать лишний `\n` | Выводится только то, что есть в файле |
