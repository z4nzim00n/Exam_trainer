# EXAM_09_03. Копирование файла

| EXAM_09_03                  | |
|-----------------------------|---|
| **Уровень:**                | 2 |
| **Темы:**                   | Текстовые файлы, чтение и запись. |
| **Директория для решения:** | `src/` |
| **Файлы решения:**          | `main.c` |
| **Входные данные:**         | Стандартный поток ввода (`stdin`) |
| **Выходные данные:**        | Стандартный поток вывода (`stdout`), созданный файл |

Написать программу, которая копирует содержимое одного текстового файла в другой.

На стандартном потоке ввода задаются два пути, каждый на отдельной строке:

1. путь к исходному файлу;
2. путь к файлу назначения.

Содержимое исходного файла необходимо скопировать без изменений. Если файл назначения уже существует, его прежнее содержимое должно быть удалено.

При успешном копировании ничего не выводить в `stdout`. Если исходный файл не удалось открыть, файл назначения не удалось создать, произошла ошибка чтения или записи либо пути совпадают, вывести `n/a`.

Пустой исходный файл копируется как пустой файл.

## Примеры

| Входные данные (`stdin`) | Содержимое исходного файла | Результат |
|---|---|---|
| `source.txt`<br>`copy.txt` | `Hello` | В `copy.txt` записано `Hello` |
| `source.txt`<br>`copy.txt` | `Hello`<br>`World` | Обе строки скопированы без изменений |
| `empty.txt`<br>`copy.txt` | пустой файл | Создан пустой `copy.txt` |
| `missing.txt`<br>`copy.txt` | файла нет | `n/a` |

**Важно:** после успешного копирования оба файла должны быть закрыты. Исходный файл не изменяется.
