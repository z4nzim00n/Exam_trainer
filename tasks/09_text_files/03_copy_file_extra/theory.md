# Теория — Копирование файлов

## 1. Открытие двух файлов

Для копирования необходимо открыть два файла:

- Исходный файл — для чтения.
- Файл назначения — для записи.

```c
FILE *source_file = fopen(source_path, "r");
FILE *destination_file = fopen(destination_path, "w");
```

Режимы:

- `"r"` — чтение существующего файла.
- `"w"` — запись с перезаписью содержимого.

Важно: если открыть файл назначения через `"w"`, его старое содержимое будет удалено.

## 2. Чтение символов — `fgetc()`

Функция `fgetc()` читает один символ из указанного файла.

```c
int current_char = fgetc(source_file);
```

При достижении конца файла возвращается `EOF`.

Для чтения всего файла используется цикл:

```c
int current_char;

while ((current_char = fgetc(source_file)) != EOF) {
    // Обработка символа
}
```

**Почему используется `int`, а не `char`?**

Потому что `fgetc()` должен возвращать как значения символов, так и специальное значение `EOF`.

## 3. Запись символов — `fputc()`

Функция `fputc()` записывает один символ в указанный файл.

```c
fputc(current_char, destination_file);
```

При ошибке функция возвращает `EOF`.

Поэтому запись желательно проверять:

```c
if (fputc(current_char, destination_file) == EOF) {
    error = 1;
    break;
}
```

## 4. Копирование файла посимвольно

Основная логика копирования:

```c
int current_char;

while ((current_char = fgetc(source_file)) != EOF) {
    fputc(current_char, destination_file);
}
```

Алгоритм:

1. Считать символ из исходного файла.
2. Записать этот символ в файл назначения.
3. Повторять, пока не достигнут конец исходного файла.

Такой подход не требует заранее знать размер файла и создавать массив под всё содержимое.

## 5. Проверка ошибок — `ferror()`

Функция `ferror()` проверяет, произошла ли ошибка при работе с потоком.

```c
if (ferror(source_file)) {
    error = 1;
}
```

Её можно использовать для проверки ошибок чтения.

Ошибки записи дополнительно проверяются через результат `fputc()` и `fclose()`.

## 6. Сравнение строк — `strcmp()`

Для проверки совпадения путей можно использовать `strcmp()`.

```c
if (strcmp(source_path, destination_path) == 0) {
    printf("n/a");
}
```

Возвращаемое значение:

- `0` — строки полностью совпадают.
- Отрицательное значение — первая строка меньше второй.
- Положительное значение — первая строка больше второй.

Важно: `strcmp()` сравнивает именно строки. Например, `file.txt` и `./file.txt` для неё разные строки, хотя могут указывать на один файл.

## 7. Закрытие файлов — `fclose()`

После завершения копирования необходимо закрыть оба файла.

```c
fclose(source_file);
fclose(destination_file);
```

Проверка результата:

```c
if (fclose(destination_file) != 0) {
    error = 1;
}
```

Закрытие файла назначения особенно важно: при закрытии могут обнаружиться ошибки окончательной записи буферизированных данных.

## Что нужно запомнить

| Функция | Назначение |
|---|---|
| `fopen()` | Открыть файл |
| `fgetc()` | Прочитать символ |
| `fputc()` | Записать символ |
| `ferror()` | Проверить ошибку потока |
| `fclose()` | Закрыть файл |
| `strcmp()` | Сравнить строки |

**Главная конструкция задачи:**

```c
while ((current_char = fgetc(source_file)) != EOF) {
    if (fputc(current_char, destination_file) == EOF) {
        error = 1;
        break;
    }
}
```
