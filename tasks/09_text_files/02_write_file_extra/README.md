# EXAM_09_02. Запись данных в файл

| EXAM_09_02                  | |
|-----------------------------|---|
| **Уровень:**                | 1 |
| **Темы:**                   | Текстовые файлы, запись данных. |
| **Директория для решения:** | `src/` |
| **Файлы решения:**          | `main.c` |
| **Входные данные:**         | Стандартный поток ввода (`stdin`) |
| **Выходные данные:**        | Стандартный поток вывода (`stdout`), созданный файл |

Написать программу, которая записывает текст из стандартного потока ввода в файл.

Сначала на `stdin` задаётся путь к файлу отдельной строкой. После символа новой строки все оставшиеся данные `stdin` записываются в указанный файл без изменений.

Файл необходимо открыть для записи. Если файл уже существует, его прежнее содержимое должно быть удалено. Если файл не удалось открыть или произошла ошибка записи, вывести `n/a`.

При успешной записи ничего не выводить в `stdout`. Допускается пустое содержимое файла.

## Примеры

| Входные данные (`stdin`) | Результат |
|---|---|
| `out.txt`<br>`Hello` | В `out.txt` записано `Hello` |
| `out.txt`<br>`Hello`<br>`World` | В `out.txt` записано `Hello` и перевод строки, затем `World` |
| `out.txt`<br>(пусто после пути) | Создан пустой `out.txt` |

**Важно:** символ новой строки после пути не записывается в файл. Все последующие байты записываются как есть. В конце успешной работы файл должен быть закрыт.
