# Теория — Запись данных в файл

## 1. Работа с файлами в C

Для работы с файлами используется тип `FILE` из библиотеки `stdio.h`.

```c
FILE *file;
```

Переменная `file` хранит указатель на открытый файл.

### Открытие файла — `fopen()`

```c
FILE *file = fopen("data.txt", "w");
```

Функция принимает два аргумента:

- Путь к файлу.
- Режим открытия.

Основные режимы:

| Режим | Назначение |
|---|---|
| `"r"` | Открытие существующего файла для чтения |
| `"w"` | Открытие для записи. Старое содержимое удаляется |
| `"a"` | Открытие для добавления данных в конец |

Если открыть файл не удалось, `fopen()` возвращает `NULL`.

```c
if (file == NULL) {
    printf("n/a");
    return 0;
}
```

## 2. Запись данных — `fputc()`

Функция записывает один символ в файл.

```c
fputc('A', file);
```

Первый аргумент — записываемый символ.

Второй аргумент — указатель на открытый файл.

При успешной записи функция возвращает записанный символ. При ошибке возвращает `EOF`.

Поэтому запись можно проверять:

```c
if (fputc(current_char, file) == EOF) {
    printf("n/a");
}
```

## 3. Чтение символов — `getchar()`

Функция `getchar()` читает один символ из стандартного ввода `stdin`.

```c
int current_char = getchar();
```

Когда ввод заканчивается, функция возвращает `EOF`.

Для чтения всего содержимого используют цикл:

```c
int current_char;

while ((current_char = getchar()) != EOF) {
    // Обработка символа
}
```

**Почему используется `int`, а не `char`?**

Потому что `getchar()` должен возвращать как обычные значения символов, так и специальное значение `EOF`. Тип `char` не гарантирует возможность корректно различить их.

## 4. Запись всего ввода в файл

Часто требуется прочитать данные из `stdin` и записать их в файл.

```c
int current_char;

while ((current_char = getchar()) != EOF) {
    fputc(current_char, file);
}
```

Таким образом данные обрабатываются посимвольно.

Это позволяет записывать текст произвольной длины, не создавая большой буфер.

## 5. Проверка ошибок — `ferror()`

Функция позволяет проверить, произошла ли ошибка при работе с потоком.

```c
if (ferror(file)) {
    printf("n/a");
}
```

Она возвращает ненулевое значение, если при работе с потоком произошла ошибка.

Например, можно проверить ошибки чтения:

```c
if (ferror(stdin)) {
    error = 1;
}
```

## 6. Закрытие файла — `fclose()`

После завершения работы с файлом его необходимо закрыть.

```c
fclose(file);
```

Закрытие важно не только для освобождения ресурсов: буферизированные данные могут окончательно записываться на диск именно при закрытии.

Поэтому результат `fclose()` тоже необходимо проверять:

```c
if (fclose(file) != 0) {
    error = 1;
}
```

Возвращаемое значение `0` означает успешное закрытие.

## 7. Удаление символа новой строки

При чтении строки через `fgets()` символ `\n` обычно сохраняется в буфере.

Например:

```c
char path[256];

fgets(path, sizeof(path), stdin);
```

Если пользователь ввёл:

```text
data.txt
```

В буфере окажется:

```c
"data.txt\n"
```

Чтобы удалить последний символ новой строки, можно использовать `strlen()`:

```c
size_t length = strlen(path);

if (length > 0 && path[length - 1] == '\n') {
    path[length - 1] = '\0';
}
```

`strlen()` возвращает количество символов до завершающего нулевого символа `\0`.

## Что нужно запомнить

| Функция | Назначение |
|---|---|
| `fopen()` | Открыть файл |
| `fclose()` | Закрыть файл |
| `fgetc()` | Прочитать символ из файла |
| `getchar()` | Прочитать символ из stdin |
| `fputc()` | Записать символ в файл |
| `fgets()` | Прочитать строку |
| `strlen()` | Получить длину строки |
| `ferror()` | Проверить ошибку потока |

**Главная последовательность работы с файлом:**

1. Открыть файл через `fopen()`.
2. Проверить, что файл успешно открыт.
3. Выполнить чтение или запись.
4. Проверить ошибки.
5. Закрыть файл через `fclose()`.
