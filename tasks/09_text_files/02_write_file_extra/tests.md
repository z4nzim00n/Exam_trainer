# EXAM_09_02. Запись данных в файл — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

Для каждого теста проверяется, что программа ничего не выводит, а файл содержит точные ожидаемые данные.

| Ввод (`stdin`) | Ожидаемое содержимое файла | Проверка |
|---|---|---|
| `w1.txt` и `Hello` | `Hello` | обычная запись |
| `w2.txt` и `Hello\nWorld` | две строки | сохраняется перевод строки |
| `w3.txt` без данных после пути | пустой файл | разрешено пустое содержимое |
| `w4.txt` и `New` | `New` | старое содержимое заменяется |

## Некорректные данные

| Ввод (`stdin`) | Результат | Причина |
|---|---|---|
| пустой ввод | `n/a` | путь не задан |
| `/no/such/dir/out.txt` | `n/a` | файл невозможно создать |
| пустая строка вместо пути | `n/a` | путь пустой |

## Дополнительная проверка

```bash
printf 'out.txt\nHello\nWorld' | ./main
cat out.txt
```

Ожидаемое содержимое `out.txt`:

```text
Hello
World
```

```bash
printf 'out.txt\nNew' | ./main
cat out.txt
```

После второго запуска в файле должно быть только `New`, без старого содержимого.
