# EXAM_09_06. Шифр Цезаря для файла — Тесты

## Компиляция

```
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Как проверять

Программа ничего не печатает, а изменяет файл. Поэтому после запуска содержимое файла нужно посмотреть командой `cat`.

```
printf 'Hello, World!' > test.txt
printf 'test.txt\n3\n' | ./main
cat test.txt
```

Ожидается `Khoor, Zruog!`. Перед каждой проверкой файл нужно создавать заново, так как программа его перезаписывает.

## Валидные данные

| Файл до | Сдвиг | Файл после | Пояснение |
|---|---|---|---|
| `Hello, World!` | `3` | `Khoor, Zruog!` | обычный сдвиг, знаки не меняются |
| `xyz XYZ` | `3` | `abc ABC` | переход через конец алфавита, регистр сохраняется |
| `abc` | `-1` | `zab` | отрицательный сдвиг |
| `Khoor` | `-3` | `Hello` | расшифровка |
| `abc` | `26` | `abc` | полный круг |
| `abc` | `29` | `def` | сдвиг больше 26 |
| `abc` | `-27` | `zab` | отрицательный сдвиг больше 26 |
| `abc` | `0` | `abc` | нулевой сдвиг |
| `abc` и `\n` в конце | `1` | `bcd` и `\n` | перенос строки сохраняется |
| `Hello 123!` и `\n`, `Second line` | `1` | `Ifmmp 123!` и `\n`, `Tfdpoe mjof` | несколько строк, цифры и знаки не меняются |

## Некорректные данные (n/a)

| Ввод | Файл | Ожидаемый вывод | Причина |
|---|---|---|---|
| `nofile.txt` `3` | не существует | `n/a` | файл не открылся |
| `test.txt` `abc` | `abc` | `n/a` | сдвиг не число |
| `test.txt` | `abc` | `n/a` | сдвиг не задан |
| `test.txt` `3` | пустой | `n/a` | в файле нет текста |
| `test.txt` `3` | 1000 букв `a` | `n/a` | файл больше 999 байт |
| (пусто) | — | `n/a` | ввода нет |

## Cppcheck

Статический анализ кода. Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

Проверка стиля и форматирования кода.

```
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```
clang-format -i main.c
```

## Valgrind

Проверка ошибок работы с памятью и утечек. Незакрытый файл будет показан как утечка.

```
printf 'Hello' > test.txt
printf 'test.txt\n3\n' | valgrind --leak-check=full ./main
```

Обратите внимание: Valgrind запускается уже на скомпилированном файле.
