# EXAM_09_06. Шифр Цезаря для файла — теория

## 1. С чего начать

Нужно прочитать файл, сдвинуть в тексте каждую латинскую букву на `shift` позиций и записать результат **обратно в тот же файл**. На экран при успехе ничего не выводится.

Шифр Цезаря вы уже делали в строках: там текст читался из stdin и печатался. Здесь добавляется файл, а также отрицательные и очень большие сдвиги.

```
прочитать путь и сдвиг → открыть файл "r+" → прочитать в массив → зашифровать → записать обратно
```

## 2. Каркас решения (его стоит запомнить)

1. `scanf("%255s %d", path, &shift) != 2` → `n/a`.
2. `fopen(path, "r+")`, `NULL` → `n/a`.
3. `n = fread(text, 1, 1000, file)`; `n == 0` или `n == 1000` → `n/a` и `fclose`.
4. `shift = shift % 26; if (shift < 0) shift += 26;`
5. Цикл по `text`: строчная, заглавная, остальное не трогаем.
6. `rewind(file)`, `fwrite(text, 1, n, file)`, `fclose(file)`.

## 3. Как выразить это на C

### Формула шифра

Для строчной буквы:

```c
text[i] = 'a' + (text[i] - 'a' + shift) % 26;
```

- `text[i] - 'a'` — номер буквы от 0 до 25 (`a` = 0, `z` = 25);
- `+ shift` — сдвигаем номер;
- `% 26` — зацикливаем: после 25 снова 0;
- `'a' + ...` — превращаем номер обратно в код буквы.

Для заглавных то же самое с `'A'`. Регистр сохраняется, потому что строчные и заглавные обрабатываются отдельными ветками.

### Если нужен вывод в stdout

В зависимости от условия результат нужно записать в файл, вывести на экран или сделать и то и другое. В решении оба варианта:

- запись в файл: `rewind(file); fwrite(text, 1, n, file);`
- вывод на экран: `fwrite(text, 1, n, stdout);`

Для вывода используем `fwrite` с длиной `n`, а не `printf("%s")`: после `fread` в массиве нет завершающего `'\0'`.

Если нужен только вывод, файл открывают в режиме `"r"`, а `rewind` и запись в файл убирают.
### Отрицательный и большой сдвиг

В C остаток от деления отрицательного числа тоже отрицательный: `-1 % 26` равно `-1`, а не `25`. Поэтому формула из задания без нормализации ломается на отрицательном сдвиге.

```c
shift = shift % 26;
if (shift < 0) {
    shift += 26;
}
```

После этого `shift` в диапазоне 0..25. Сдвиг на `-1` становится сдвигом на `25`, а сдвиг на `29` становится сдвигом на `3`. Заодно нет переполнения при огромном `shift`.

### Чтение двух значений

```c
scanf("%255s %d", path, &shift) != 2
```

У `path` нет `&`: имя массива уже адрес. У `shift` есть. Возвращённое значение сравниваем с 2.

### Открытие "r+"

`"r+"` открывает **существующий** файл для чтения и записи. Если файла нет, `fopen` вернёт `NULL`. Режим `"w"` стёр бы файл при открытии, поэтому здесь он не подходит.

### Чтение файла: fread

```c
size_t n = fread(text, 1, 1000, file);
```

Читает до 1000 элементов по 1 байту и возвращает, сколько прочитано. Проверяем:

- `n == 0` — файл пустой;
- `n == 1000` — файл слишком большой для массива.

### Запись обратно: rewind и fwrite

```c
rewind(file);
fwrite(text, 1, n, file);
```

`rewind` возвращает позицию в начало файла. `fwrite` записывает `n` байт поверх старых. Длина текста не меняется, поэтому остатков старого текста нет.

### Что не трогаем

Цифры, пробелы, знаки и `\n` не попадают ни в одну ветку и остаются как есть, в том числе `\n` в конце файла.

## 4. Проверка на примере

Файл `Hello, World!`, сдвиг 3.

| Символ | Номер | + 3 | Результат |
|---|---|---|---|
| `H` | 7 | 10 | `K` |
| `e` | 4 | 7 | `h` |
| `W` | 22 | 25 | `Z` |
| `r` | 17 | 20 | `u` |
| `,`, пробел, `!` | — | — | без изменений |

В файле остаётся `Khoor, Zruog!`.

Сдвиг `-1` для `a`: `shift` становится 25, `(0 + 25) % 26 = 25`, это `z`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Не нормализовать отрицательный сдвиг | `% 26` даст отрицательный номер, получится мусорный символ |
| После `z` переходить к `A` | Регистр должен сохраняться, `z` переходит в `a` |
| Шифровать цифры и знаки | Они должны остаться без изменений |
| Открыть файл в режиме `"w"` | Файл очистится ещё до чтения |
| Забыть `rewind` | Запись пойдёт в конец файла, текст задвоится |
| Не закрыть файл в ветке с ошибкой | Утечка, Valgrind её покажет |
| Выводить приглашение (`Enter the shift:`) | В stdout не должно быть ничего лишнего |
| Печатать результат вместо записи в файл | По условию изменяется сам файл |
| `strlen(text)` без завершающего `\0` | Массив после `fread` не завершён нулём, длину берём из `n` |
