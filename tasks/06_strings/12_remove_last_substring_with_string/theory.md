# EXAM_06_12
# Удаление последнего вхождения подстроки — теория

## 1. С чего начать

Есть две строки. Первая — основной текст, вторая — подстрока, которую нужно найти и удалить.

```text
This is mytext
my
```

Подстрока `my` встречается один раз. После удаления:

```text
This is text
```

Если подстрока встречается несколько раз, удалить нужно **только последнее** вхождение:

```text
abcabc
abc
```

Результат: `abc` (первое остаётся, второе удаляется).

## 2. Как решать задачу по шагам

1. Прочитать обе строки и убрать из них символ `'\n'`.
2. Найти **последнее** вхождение подстроки.
3. Удалить его, сдвинув хвост строки влево.
4. Вывести результат без `'\n'` в конце.

## 3. Какие функции нам пригодятся

| Функция | Что делает | Где нужна |
| --- | --- | --- |
| `fgets(buf, size, stdin)` | читает строку вместе с `'\n'` (если он влез) | чтение ввода |
| `strcspn(s, "\n")` | возвращает индекс первого `'\n'` в `s` (или длину строки, если его нет) | обрезаем `'\n'` |
| `strlen(s)` | длина строки без `'\0'` | длина подстроки и хвоста |
| `strstr(s, sub)` | указатель на **первое** вхождение `sub` в `s` или `NULL` | поиск |
| `memmove(dst, src, n)` | копирует `n` байт, области могут пересекаться | сдвиг хвоста |

### Почему `fgets`, а не `scanf("%s")`

`scanf("%s")` останавливается на первом пробеле, а в наших строках пробелы бывают. `fgets` читает всю строку целиком.

### Почему `strcspn` для удаления `'\n'`

```c
str[strcspn(str, "\n")] = '\0';
```

Если `'\n'` есть, он заменяется на `'\0'`. Если его нет (последняя строка без переноса, конец ввода EOF), `strcspn` вернёт длину строки, и мы просто запишем `'\0'` туда, где он уже стоит. Ничего не ломается.

### Почему `memmove`, а не `memcpy` или `strcpy`

При удалении мы копируем хвост строки сам на себя, со сдвигом влево. Источник и приёмник пересекаются. `memcpy` и `strcpy` в таком случае дают неопределённое поведение, а `memmove` это гарантированно умеет.

## 4. Как найти последнее вхождение

В стандартной библиотеке есть `strstr` для **первого** вхождения и `strrchr` для последнего **символа**, но нет функции для последней подстроки. Поэтому ищем все вхождения подряд и запоминаем последнее:

```c
char *last = NULL;
char *p = str;

while ((p = strstr(p, sub)) != NULL) {
    last = p;
    p++;
}
```

Как это работает:

1. `strstr(p, sub)` ищет подстроку начиная с позиции `p`.
2. Нашли: запоминаем адрес в `last`.
3. Сдвигаем `p` на **один** символ вперёд и ищем снова.
4. Когда `strstr` вернёт `NULL`, в `last` лежит последнее вхождение.

### Почему `p++`, а не `p += len`

Чтобы находить пересекающиеся вхождения. Для `aaaa` и `aa` вхождения начинаются в позициях `0`, `1`, `2`. Если прыгать на `len`, мы увидим только `0` и `2`. Здесь результат совпал бы, но для `aaa` и `aa` прыжок пропустил бы позицию `1`, и последнее вхождение нашлось бы неверно.

### Пустая подстрока

`strstr(s, "")` всегда возвращает `s`, то есть «находит» пустую строку в каждой позиции. По условию пустая подстрока ничего не меняет, поэтому перед поиском проверяем `len > 0`.

## 5. Как удалить найденное вхождение

Пусть `last` указывает на начало вхождения, а `len` — длина подстроки. Тогда хвост, который нужно оставить, начинается в `last + len`. Копируем его на место `last`:

```c
memmove(last, last + len, strlen(last + len) + 1);
```

- `last` — куда копируем (начало удаляемого фрагмента);
- `last + len` — откуда копируем (первый символ после фрагмента);
- `strlen(last + len) + 1` — сколько байт: длина хвоста **плюс 1** на завершающий `'\0'`.

Пример: `This is mytext`, удаляем `my`:

```text
До:      T h i s _ i s _ m y t e x t \0
                         ^last
                             ^last+len (начало хвоста "text")
После:   T h i s _ i s _ t e x t \0
```

## 6. Алгоритм целиком

1. Объявить буферы под обе строки и обнулить их (на случай пустого ввода).
2. Прочитать строки через `fgets`, убрать `'\n'`.
3. Посчитать `len = strlen(sub)`.
4. Если `len > 0`, найти последнее вхождение циклом со `strstr`.
5. Если вхождение найдено, сдвинуть хвост через `memmove`.
6. Вывести строку **без** `'\n'`.

## 7. Пошаговый разбор

### Пример 1: одно вхождение

`This is mytext`, подстрока `my` (`len = 2`).

- `strstr` с начала находит `my` в позиции 8, `last = &str[8]`, `p` сдвигается на 9.
- Со следующей позиции `strstr` ничего не находит и возвращает `NULL`.
- Хвост после `my` — это `text`. `memmove` ставит его на место `my`.

Вывод: `This is text`.

### Пример 2: несколько вхождений

`abcabc`, подстрока `abc` (`len = 3`).

| Вызов `strstr` | Поиск с позиции | Нашли | `last` |
| --- | --- | --- | --- |
| 1 | 0 | позиция 0 | 0 |
| 2 | 1 | позиция 3 | 3 |
| 3 | 4 | `NULL` | 3 |

`last = 3`, хвост после вхождения пустой (только `'\0'`). `memmove` копирует один байт, и строка становится `abc`.

## 8. Особые случаи

| Ввод | Что происходит | Вывод |
| --- | --- | --- |
| обе строки пустые | `len = 0`, поиск пропущен, строка пустая | ничего |
| подстрока пустая | `len = 0`, поиск пропущен | основная строка |
| основная строка пустая, подстрока `a` | `strstr` ничего не находит | ничего |
| подстрока длиннее строки | `strstr` вернёт `NULL` | основная строка |
| строка равна подстроке | `last = str`, хвост пустой | ничего |
| `Text` и `text` | сравнение буквальное, совпадений нет | основная строка |
| `aaaa` и `aa` | вхождения 0, 1, 2; `last = 2` | `aa` |
| `abcabcabc` и `abc` | `last = 6` | `abcabc` |
| последняя строка без `'\n'` | `strcspn` вернёт длину строки | работает как обычно |

## 9. Почему решение работает

- Цикл со `strstr` и `p++` перебирает **все** позиции, где подстрока встречается, и последняя из них остаётся в `last`.
- `memmove` удаляет ровно `len` символов начиная с `last`, остальные сохраняют порядок.
- Если вхождений нет, `last == NULL`, и строка не меняется.

Время работы: `O(n × m)` в худшем случае, где `n` — длина основной строки, `m` — длина подстроки. Для наших ограничений (200 и 100 символов) это мгновенно.

Память: два статических массива, динамическая память не используется, поэтому утечек быть не может.

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Остановиться на первом `strstr` | Нужно последнее вхождение, а не первое |
| `p += len` вместо `p++` | Пропускаются пересекающиеся вхождения |
| Не проверить `len > 0` | `strstr` с пустой подстрокой «находит» её везде |
| `strcpy` вместо `memmove` | Области пересекаются, это неопределённое поведение |
| Забыть `+ 1` в `memmove` | Теряется завершающий `'\0'`, вывод мусорный |
| Не убрать `'\n'` | Подстрока с `'\n'` никогда не найдётся, а в выводе появится лишний перенос |
| `printf("%s\n", ...)` | Условие запрещает завершающий перенос строки |
| Не обнулить буферы | При пустом вводе `fgets` ничего не запишет, и в массиве будет мусор |
| `scanf("%s", ...)` | Читает только до первого пробела |
| Использовать значение `last` после `NULL` | Разыменование `NULL` приводит к падению |
