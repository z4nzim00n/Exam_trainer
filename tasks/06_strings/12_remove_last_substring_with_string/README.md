## EXAM_06_12. Удаление последнего вхождения подстроки

Нигде нет информации что использовать string.h нельзя.

### Задание

| EXAM_06_12          ||
|---------------------| ------- |
|                     | **Уровень** | 3 |
| **Темы**            | Строки, поиск подстроки, функции `<string.h>`, сдвиг символов |
| **Файл решения**    | `main.c` |
| **Входные данные**  | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Написать программу, удаляющую последнее вхождение подстроки из строки.

Через стандартный поток ввода stdin задаются две строки, каждая на отдельной строке ввода:

1. Основная строка.
2. Подстрока для поиска.

Программа должна найти последнее вхождение подстроки в основной строке и удалить его. Результат вывести на стандартный поток вывода stdout.

В конце ответа не должно быть переноса на новую строку.

## Уточнения

- Основная строка содержит не более 200 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Подстрока содержит не более 100 печатных символов ASCII.
- Каждая строка завершается символом `'\n'` или концом ввода EOF.
- Завершающие переводы строк не входят в текст и не участвуют в поиске.
- Поиск чувствителен к регистру: `Text` и `text` — разные подстроки.
- Пробелы в подстроке учитываются.
- Если подстрока в основной строке не найдена, основная строка выводится без изменений.
- Если подстрока пустая, основная строка выводится без изменений.
- Если основная строка пустая, программа ничего не выводит.
- Вхождения могут пересекаться (например, `aaaa` и `aa`): последним считается вхождение с наибольшей начальной позицией.
- Разрешено использовать функции стандартной библиотеки, в том числе `<string.h>`.

## Примеры

**Пример 1**

Входные данные:

```text
This is mytext
my
```

Результат работы:

```text
This is text
```

**Пример 2**

Входные данные:

```text
abcabc
abc
```

Результат работы:

```text
abc
```

**Пример 3**

Входные данные:

```text
Hello, World!
xyz
```

Результат работы:

```text
Hello, World!
```

**Пример 4**

Входные данные:

```text
aaa
a
```

Результат работы:

```text
aa
```

> В примере 2 удаляется именно последнее вхождение `abc`, поэтому остаётся первое. В примере 4 удаляется последняя буква `a`.

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
