# EXAM_08_07. Сравнение строк — теория

## 1. С чего начать

Нужно прочитать две строки и проверить, совпадают ли они полностью.

Строки равны, если:

1. Имеют одинаковую длину.
2. На каждой позиции содержат одинаковые символы.

Например:

```text
Hello
Hello
```

Ответ:

```text
1
```

Но:

```text
Hello
hello
```

Ответ:

```text
0
```

Заглавная `H` и строчная `h` — разные символы.

Пробелы также учитываются. Строки `Hello world` и `Hello  world` различаются.

## 2. Как строка хранится в C

Строка представляет собой массив символов, который заканчивается нулевым символом:

```c
'\0'
```

Строка `cat` хранится так:

| Индекс | Значение |
| --- | --- |
| `0` | `'c'` |
| `1` | `'a'` |
| `2` | `'t'` |
| `3` | `'\0'` |

Именно `'\0'` позволяет определить, где строка закончилась.

Элементы массива после него не являются частью строки и не должны участвовать в сравнении.

## 3. Почему нельзя просто написать `first == second`

Если `first` и `second` — массивы символов, выражение:

```c
first == second
```

не сравнивает их содержимое посимвольно. В таком выражении массивы преобразуются в указатели, и сравниваются адреса.

Для проверки текста нужно сравнивать отдельные элементы:

```c
first[i] == second[i]
```

По условию готовые функции сравнения использовать нельзя, поэтому выполняем обход самостоятельно.

## 4. Как прочитать две строки

Подготовим два массива:

```c
char first[102];
char second[102];
```

Каждый рассчитан на:

- 100 символов текста;
- возможный перевод строки `'\n'`;
- завершающий символ `'\0'`.

Для чтения используем `fgets`:

```c
fgets(str, size, stdin)
```

Она читает строку вместе с пробелами.

При успешном чтении функция записывает в массив не более `size - 1` символов и добавляет `'\0'`.

### Почему размер 102, а не 101

В массив из 101 элемента поместятся 100 символов текста и `'\0'`, но не поместится следующий за текстом `'\n'`.

Тогда перевод строки останется во входном потоке. Следующий вызов `fgets` прочитает его вместо второй строки.

Массив из 102 элементов позволяет прочитать целиком строку максимальной длины вместе с её переводом строки.

## 5. Зачем нужна функция `read_line`

Чтение и удаление завершающего перевода строки нужны для обоих массивов.

Чтобы не повторять один и тот же код, вынесем его в функцию:

```c
static void read_line(char str[], int size)
```

Параметры:

- `str` — массив, в который нужно записать строку;
- `size` — размер доступного буфера.

`void` означает, что функция не возвращает значение. Результат её работы находится в переданном массиве.

`static` перед такой функцией ограничивает её доступность текущим исходным файлом. На алгоритм чтения это не влияет.

Вызовы:

```c
read_line(first, sizeof(first));
read_line(second, sizeof(second));
```

В `main` выражение `sizeof(first)` даёт размер всего массива в байтах. Для массива `char` это также количество элементов.

Значение 102 помещается в параметр типа `int`.

### Почему размер передаётся отдельно

В параметрах функции запись:

```c
char str[]
```

обозначает указатель на элементы переданного массива. Размер исходного массива автоматически не передаётся.

Поэтому вычислять размер буфера через `sizeof(str)` внутри `read_line` нельзя: там это будет размер указателя, а не массива.

## 6. Как работает `read_line`

### Чтение

```c
if (fgets(str, size, stdin) == NULL) {
    str[0] = '\0';
}
```

При успешном чтении массив содержит строку с завершающим `'\0'`.

Если прочитать символы не удалось, записываем `'\0'` в первый элемент. Получается пустая строка.

Это не полноценная проверка ошибочного ввода: по условию ввод корректен. Такая ветка также позволяет безопасно представить пустую строку, завершённую EOF до первого символа.

### Поиск конца текста

```c
int i = 0;

while (str[i] != '\0' && str[i] != '\n') {
    i++;
}
```

Останавливаемся на:

- переводе строки;
- либо нулевом символе, если перевода строки нет.

### Удаление перевода строки

```c
str[i] = '\0';
```

Если в этой позиции был `'\n'`, заменяем его на конец строки.

Если там уже был `'\0'`, повторное присваивание ничего не меняет.

Например:

```text
До:    'c' 'a' 't' '\n' '\0'
После: 'c' 'a' 't' '\0' '\0'
```

Теперь в сравнении участвует только текст.

Удалять пробелы по краям нельзя — они являются частью строки.

## 7. Как сравнивать символы

Начинаем с индекса `0`:

```c
int i = 0;
```

Двигаемся дальше, пока:

- первая строка ещё не закончилась;
- текущие символы совпадают.

```c
while (first[i] != '\0' && first[i] == second[i]) {
    i++;
}
```

Цикл останавливается:

1. На первом несовпадении.
2. На конце первой строки.

После цикла остаётся проверить:

```c
first[i] == second[i]
```

### Если строки равны

Они заканчиваются одновременно.

В текущей позиции:

```c
first[i] == '\0'
second[i] == '\0'
```

Символы равны, результат — `1`.

### Если различаются символы

Цикл остановился на несовпадении.

Сравнение даёт `0`.

### Если различается длина

Одна строка содержит `'\0'`, а другая — очередной символ текста.

Сравнение также даёт `0`.

Отдельно считать длины строк не требуется.

## 8. Почему не нужна отдельная проверка конца второй строки в условии цикла

Условие выглядит так:

```c
first[i] != '\0' && first[i] == second[i]
```

Если вторая строка закончилась раньше первой, то:

- `second[i]` равно `'\0'`;
- `first[i]` содержит непрерывно прочитанный символ текста, отличный от `'\0'`;
- сравнение символов ложно.

Цикл остановится до увеличения индекса.

Если первой закончилась первая строка, цикл остановится по первой части условия.

Таким образом, программа не продолжает обход за концом более короткой строки.

## 9. Вывод результата

В C оператор сравнения `==` возвращает целое значение:

- `1`, если операнды равны;
- `0`, если различаются.

Поэтому результат можно вывести напрямую:

```c
printf("%d", first[i] == second[i]);
```

Дополнительный `if` для вывода не нужен.

Перенос строки не добавляем.

## 10. Алгоритм решения

1. Подготовить два массива.
2. Прочитать первую строку.
3. Удалить её завершающий перевод строки, если он есть.
4. Повторить чтение и обработку для второй строки.
5. Сравнивать символы с одинаковыми индексами.
6. Остановиться на первом различии или конце первой строки.
7. Вывести результат сравнения символов в позиции остановки.

## 11. Пошаговый разбор

### Одинаковые строки

```text
cat
cat
```

| Индекс | Первая строка | Вторая строка | Действие |
| --- | --- | --- | --- |
| `0` | `'c'` | `'c'` | Продолжаем |
| `1` | `'a'` | `'a'` | Продолжаем |
| `2` | `'t'` | `'t'` | Продолжаем |
| `3` | `'\0'` | `'\0'` | Цикл завершён |

В позиции остановки символы равны. Ответ — `1`.

### Одна строка — начало другой

```text
cat
cats
```

| Индекс | Первая строка | Вторая строка | Действие |
| --- | --- | --- | --- |
| `0` | `'c'` | `'c'` | Продолжаем |
| `1` | `'a'` | `'a'` | Продолжаем |
| `2` | `'t'` | `'t'` | Продолжаем |
| `3` | `'\0'` | `'s'` | Цикл завершён |

Символы различаются. Ответ — `0`.

Совпадения общего начала недостаточно: строки должны закончиться одновременно.

## 12. Особые случаи

### Две пустые строки

В обоих массивах первый элемент — `'\0'`.

Цикл не выполняется. Итоговое сравнение даёт `1`.

### Только одна строка пустая

В одной строке первый элемент — `'\0'`, в другой — символ текста.

Ответ — `0`.

### Строки только из пробелов

Они равны, только если количество пробелов одинаково.

### Вторая строка без завершающего перевода

`fgets` добавит `'\0'` после прочитанного текста. Функция `read_line` дойдёт до него и оставит без изменений.

Поэтому одинаковый текст сравнивается как равный независимо от наличия последнего `'\n'`.

### Разный регистр

`'A'` и `'a'` сравниваются как разные символы.

Преобразовывать регистр не нужно.

## 13. Почему решение работает

Пока цикл продолжается, все уже пройденные пары символов совпадают.

После остановки возможны два случая:

- найдено различие — строки не равны;
- первая строка закончилась — строки равны только тогда, когда вторая закончилась в той же позиции.

Эти случаи покрывают и различие содержимого, и различие длины.

Чтение двух строк занимает `O(n + m)`, где `n` и `m` — их длины.

Само сравнение останавливается на первом различии и требует не более `O(min(n, m) + 1)` проверок.

В реализации выделяются два фиксированных массива по 102 элемента. Динамическая память не используется.

## 14. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Написать `first == second` | Сравниваются адреса, а не текст |
| Читать через `scanf("%s", ...)` | Будут потеряны строки с пробелами и пустые строки |
| Оставить завершающий `'\n'` | Одинаковый текст может считаться разным, если вторая строка завершена EOF |
| Выделить 101 элемент и не обработать оставшийся `'\n'` | При максимальной длине нарушится чтение второй строки |
| Сравнить только общий префикс | `abc` и `abcd` ошибочно окажутся равными |
| Удалять пробелы по краям | Пробелы являются частью сравниваемого текста |
| Использовать `sizeof(str)` внутри функции как размер массива | В параметре функции `str` является указателем |
| Проверять элементы после `'\0'` | Они не входят в строку и могут быть неинициализированы |
| Использовать `strcmp` | Это запрещено условием |
| Добавить перенос строки при выводе | Формат ответа требует только `0` или `1` |
