## EXAM_06_10. Сравнение строк

### Задание

| EXAM_08_07 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, массивы, циклы, сравнение символов. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, проверяющую, совпадают ли две строки.

Через стандартный поток ввода stdin задаются две строки, каждая на отдельной строке ввода.

Строки считаются одинаковыми, если имеют равную длину и все символы на соответствующих позициях совпадают.

Если строки одинаковые, вывести на стандартный поток вывода stdout `1`, иначе вывести `0`.

В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод двух строк.
- Каждая строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Первая строка обязательно завершается символом `'\n'`.
- Вторая строка завершается символом `'\n'` или концом ввода EOF.
- Завершающие переводы строк не участвуют в сравнении.
- Регистр учитывается: `'A'` и `'a'` считаются разными символами.
- Все пробелы, включая пробелы в начале и конце строк, участвуют в сравнении.
- Строки могут быть пустыми. Две пустые строки считаются одинаковыми.
- Использовать функции библиотеки `<string.h>` для сравнения строк или участков памяти запрещено.
- Можно использовать обычные массивы `char`. Динамическая память не требуется.

### Примеры

**Пример 1**

Входные данные:

```text
Hello
Hello
```

Результат работы:

```text
1
```

**Пример 2**

Входные данные:

```text
Hello
hello
```

Результат работы:

```text
0
```

**Пример 3**

Входные данные:

```text
abc
abcd
```

Результат работы:

```text
0
```

**Пример 4**

Входные данные:

```text
Hello world
Hello  world
```

Результат работы:

```text
0
```

> В последнем примере строки различаются количеством пробелов между словами.

> **Внимание:** Процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
