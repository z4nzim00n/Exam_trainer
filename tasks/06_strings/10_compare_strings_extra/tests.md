# EXAM_08_07. Сравнение строк — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

В командах `\n` обозначает перевод строки, разделяющий входные строки.

| Первая строка | Вторая строка | Результат | Команда | Пояснение |
| --- | --- | --- | --- | --- |
| `Hello` | `Hello` | `1` | `printf 'Hello\nHello\n' \| ./main` | Строки полностью совпадают |
| `Hello` | `hello` | `0` | `printf 'Hello\nhello\n' \| ./main` | Регистр учитывается |
| `abc` | `abcd` | `0` | `printf 'abc\nabcd\n' \| ./main` | Первая строка короче |
| `abcd` | `abc` | `0` | `printf 'abcd\nabc\n' \| ./main` | Вторая строка короче |
| `abc` | `xbc` | `0` | `printf 'abc\nxbc\n' \| ./main` | Различие в начале |
| `abc` | `axc` | `0` | `printf 'abc\naxc\n' \| ./main` | Различие в середине |
| `abc` | `abx` | `0` | `printf 'abc\nabx\n' \| ./main` | Различие в конце |
| `Hello world` | `Hello world` | `1` | `printf 'Hello world\nHello world\n' \| ./main` | Строки с пробелами |
| `School21!` | `School21!` | `1` | `printf 'School21!\nSchool21!\n' \| ./main` | Буквы, цифры и знаки препинания |

## Важные случаи

В таблице ниже строки записаны в двойных кавычках, чтобы показать пустые строки и пробелы по краям. Сами кавычки не входят во входные данные.

| Первая строка | Вторая строка | Результат | Команда | Пояснение |
| --- | --- | --- | --- | --- |
| `""` | `""` | `1` | `printf '\n\n' \| ./main` | Две пустые строки равны |
| `""` | `"a"` | `0` | `printf '\na\n' \| ./main` | Первая строка пустая |
| `"a"` | `""` | `0` | `printf 'a\n\n' \| ./main` | Вторая строка пустая |
| `"a"` | `"a"` | `1` | `printf 'a\na\n' \| ./main` | Одинаковые одиночные символы |
| `"a"` | `"b"` | `0` | `printf 'a\nb\n' \| ./main` | Разные одиночные символы |
| `" "` | `" "` | `1` | `printf ' \n \n' \| ./main` | По одному пробелу |
| `" "` | `""` | `0` | `printf ' \n\n' \| ./main` | Пробел не равен пустой строке |
| `" abc"` | `"abc"` | `0` | `printf ' abc\nabc\n' \| ./main` | Начальный пробел учитывается |
| `"abc "` | `"abc"` | `0` | `printf 'abc \nabc\n' \| ./main` | Конечный пробел учитывается |
| `"Hello world"` | `"Hello  world"` | `0` | `printf 'Hello world\nHello  world\n' \| ./main` | Разное количество пробелов |
| `"same"` | `"same"` | `1` | `printf 'same\nsame' \| ./main` | Вторая строка завершается EOF |

> Строки должны совпадать целиком. Совпадения только общего начала недостаточно. Завершающие переводы строк не участвуют в сравнении.

## Максимальная длина

Две одинаковые строки по 100 символов. Ожидаемый результат — `1`:

```bash
awk 'BEGIN {
    for (row = 0; row < 2; row++) {
        for (i = 0; i < 100; i++) printf "a";
        printf "\n";
    }
}' | ./main
```

Две строки по 100 символов, различающиеся последним символом. Ожидаемый результат — `0`:

```bash
awk 'BEGIN {
    for (i = 0; i < 100; i++) printf "a";
    printf "\n";
    for (i = 0; i < 99; i++) printf "a";
    printf "b\n";
}' | ./main
```

Первая строка содержит 100 символов `a`, вторая — 99. Ожидаемый результат — `0`:

```bash
awk 'BEGIN {
    for (i = 0; i < 100; i++) printf "a";
    printf "\n";
    for (i = 0; i < 99; i++) printf "a";
    printf "\n";
}' | ./main
```

## Проверка формата вывода

Посмотреть точные байты результата:

```bash
printf 'Hello\nHello\n' | ./main | od -An -t x1
```

Ожидается:

```text
31
```

`31` — шестнадцатеричный код символа `1`.

Для несовпадающих строк:

```bash
printf 'Hello\nhello\n' | ./main | od -An -t x1
```

Ожидается:

```text
30
```

`30` — шестнадцатеричный код символа `0`.

> В обоих случаях должен выводиться ровно один символ. Дополнительных пробелов (`20`) и перевода строки (`0a`) быть не должно.

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Проверка одинаковых строк:

```bash
printf 'Hello world\nHello world\n' | valgrind --leak-check=full ./main
```

Проверка строк разной длины:

```bash
printf 'abcd\nabc\n' | valgrind --leak-check=full ./main
```

Проверка пустых строк:

```bash
printf '\n\n' | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
