# Разворот строки

## Задание

| Параметр | Значение |
| --- | --- |
| **Уровень** | 2 |
| **Темы** | Строки, массивы, индексы, циклы |
| **Файл решения** | `main.c` |
| **Входные данные** | Стандартный поток ввода (stdin) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Написать программу, выводящую символы строки в обратном порядке.

Строка задаётся на стандартном потоке ввода stdin. Необходимо вывести её символы от последнего к первому на стандартный поток вывода stdout.

Развороту подлежат все символы строки, включая пробелы, цифры и знаки препинания. Регистр букв изменять нельзя.

В конце ответа не должно быть переноса на новую строку.

## Уточнения

- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ перевода строки `'\n'` или конец ввода EOF.
- Завершающий перевод строки не входит в обрабатываемый текст и не выводится.
- Строка может быть пустой. В этом случае программа ничего не выводит.
- Пробелы нельзя удалять или добавлять. Пробелы в начале исходной строки окажутся в конце результата, и наоборот.
- Разворачивать саму строку внутри массива необязательно: достаточно вывести символы в обратном порядке.
- Использовать функции библиотеки `<string.h>` запрещено.

## Примеры

| Входные данные | Результат работы |
| --- | --- |
| `Hello!` | `!olleH` |
| `abc def` | `fed cba` |
| `12345` | `54321` |
| `a` | `a` |

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
