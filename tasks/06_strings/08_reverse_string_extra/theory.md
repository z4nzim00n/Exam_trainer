# EXAM_08_04. Разворот строки — теория

## 1. Что значит развернуть строку

Нужно вывести символы в обратном порядке:

```text
abc def → fed cba
```

Разворачиваются не только слова, а все символы:

- буквы;
- цифры;
- пробелы;
- знаки препинания.

Исходные начальные пробелы становятся конечными, а конечные — начальными.

## 2. Почему удобно использовать массив

Для вывода первого символа результата нужен последний символ исходной строки.

Поэтому удобно сначала прочитать всю строку, а затем пройти по ней справа налево.

```c
char text[102];
```

Массив вмещает 100 символов текста, возможный перевод строки и нулевой терминатор.

## 3. Чтение и определение длины

```c
fgets(text, sizeof(text), stdin)
```

Функция читает строку вместе с пробелами.

Затем считаем символы до `'\n'` или `'\0'`:

```c
while (text[length] != '\0' && text[length] != '\n') {
    length++;
}
```

Перевод строки не является частью разворачиваемого текста.

Если вход пустой и `fgets` вернула `NULL`, длина остаётся равной нулю.

## 4. Где находится последний символ

Индексация начинается с нуля.

Для строки из трёх символов:

```text
Индекс:  0   1   2
Символ:  a   b   c
```

Длина — `3`, но последний индекс — `2`.

Общая формула:

```text
последний индекс = длина - 1
```

На позиции `length` уже находится `'\n'` или `'\0'`, а не символ текста.

## 5. Обратный проход

```c
while (length > 0) {
    length--;
    putchar(text[length]);
}
```

Сначала уменьшаем индекс, затем обращаемся к массиву.

Для длины `3` будут выведены:

```text
text[2]
text[1]
text[0]
```

После этого `length` станет нулём, и цикл завершится.

Этот вариант не требует использовать отрицательный индекс.

## 6. Алгоритм и пример

1. Прочитать строку.
2. Определить длину текста.
3. Пока длина больше нуля:
   - уменьшить её на один;
   - вывести символ по полученному индексу.

Вход:

```text
ab!
```

| Значение до шага | Индекс после уменьшения | Символ |
| --- | --- | --- |
| `3` | `2` | `!` |
| `2` | `1` | `b` |
| `1` | `0` | `a` |

Вывод:

```text
!ba
```

Менять сам массив не требуется: условие требует обратный вывод, а не обязательно перестановку в памяти.

## 7. Особые случаи и сложность

- Пустая строка: цикл вывода не выполняется.
- Один символ: выводится этот же символ.
- Только пробелы: выводится столько же пробелов.
- Ввод без `'\n'`: длина определяется по `'\0'`.

Два прохода по строке дают время `O(n)`, а не `O(n²)`: один проход идёт после другого, а не внутри него.

Массив имеет фиксированный размер.

## 8. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Начать вывод с `text[length]` | Выведется терминатор или перевод строки |
| Условие обратного цикла `length >= 0` | Возможен доступ по отрицательному индексу |
| Удалять пробелы по краям | Нарушится сохранение символов |
| Разворачивать только порядок слов | Символы внутри слов останутся в прежнем порядке |
| Читать через `scanf("%s", ...)` | Потеряется текст после первого пробела |
| Выводить `'\n'` в конце | Нарушится формат ответа |
