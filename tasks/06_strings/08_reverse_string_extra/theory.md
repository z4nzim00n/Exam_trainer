# Разворот строки — теория

## 1. С чего начать

Нужно прочитать строку и вывести её в обратном порядке: от последнего символа к первому.

Например:

```text
abc def
```

Вывод:

```text
fed cba
```

Обратите внимание:
- пробелы сохраняются на своих местах (пробел во вводе был третьим с конца, в выводе стал третьим с начала);
- регистр символов не меняется.

По условию задачи разворачивать саму строку в памяти необязательно. Это сильно упрощает задачу: нам достаточно просто вывести прочитанный массив задом наперёд.

## 2. Как строка хранится в памяти

Строка в C — это последовательность символов, которая заканчивается специальным нулевым символом `'\0'`.

Например, строка `Hello!` длиной 6 символов в массиве из 8 элементов выглядит так:

| Индекс | Символ |
| --- | --- |
| `0` | `'H'` |
| `1` | `'e'` |
| `2` | `'l'` |
| `3` | `'l'` |
| `4` | `'o'` |
| `5` | `'!'` |
| `6` | `'\0'` |
| `7` | (мусор) |

Индексы массива всегда начинаются с `0`. Последний значащий символ находится по индексу `len - 1` (в данном случае `6 - 1 = 5`).

Символ `'\0'` обозначает конец строки. Он не выводится и не участвует в развороте.

## 3. Чтение строки посимвольно

Для чтения строки с пробелами не подходит `scanf("%s", ...)` — он остановится на первом пробеле.

Используем цикл с `getchar()`:

```c
char str[102];
int len = 0;
int ch;

while ((ch = getchar()) != EOF && ch != '\n') {
    if (len < 101) {
        str[len] = (char)ch;
        len++;
    }
}
str[len] = '\0';
```

- Буфер имеет размер `102` (под 100 символов текста, перевод строки `'\n'` и терминальный нуль `'\0'`).
- На каждой итерации читаем символ в `ch`.
- Если это не конец файла (`EOF`) и не перевод строки (`'\n'`), записываем его в массив.
- После окончания чтения вручную ставим `'\0'` на позицию `len`.

## 4. Как обойти массив с конца

Если длина строки равна `len`, последний символ находится по индексу `len - 1`. Первый — по индексу `0`.

Для вывода в обратном порядке пишем цикл `for`:

```c
for (int i = len - 1; i >= 0; i--) {
    putchar(str[i]);
}
```

- Переменная цикла `i` инициализируется индексом последнего символа `len - 1`.
- Условие продолжения цикла: `i >= 0` (работаем, пока индекс не станет отрицательным).
- Шаг цикла: `i--` (уменьшаем индекс на единицу, двигаясь к началу).

Для строки `a` (длина 1):
- `len = 1`
- `i` стартует с `1 - 1 = 0`
- Выводим `str[0]`, уменьшаем `i` до `-1`
- Цикл завершается. Всё правильно.

Для пустой строки (`len = 0`):
- `i` стартует с `-1`
- Условие `i >= 0` сразу ложно
- Цикл не выполняется. Всё правильно.

## 5. Алгоритм целиком

1. Подготовить массив символов `str` размером 102.
2. В цикле читать символы через `getchar()`.
3. Записывать символы в массив, увеличивая счётчик длины `len`. Прекратить чтение при обнаружении `'\n'` или `EOF`.
4. Записать нулевой символ `'\0'` в конец строки.
5. Запустить цикл `for` от `len - 1` до `0` с шагом `-1`.
6. На каждом шаге выводить символ `str[i]` через `putchar()`.

## 6. Особые случаи

### Пустая строка (сразу нажали Enter)
`len` равен `0`. Цикл вывода не выполняется ни разу. На выходе — пустой вывод, как и требует условие.

### Ввод без перевода строки в конце
Если входной поток завершился по `EOF` (например, при передаче файла), цикл чтения завершится корректно. Нулевой символ запишется правильно, разворот сработает.

## 7. Сложность

- Время работы: `O(n)`, где `n` — длина строки. Мы делаем один проход для чтения и один для вывода.
- Дополнительная память: `O(1)` в рамках ограничений задачи (выделяем фиксированный буфер на 102 байта).

## 8. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Сравнивать `i` с `len` при старте | Попытка вывести `str[len]` (там лежит `'\0'`), на экране ничего не появится или выведется мусор |
| Использовать условие `i > 0` | Символ по индексу `0` (самый первый во вводе) не выведется |
| Написать шаг `i++` вместо `i--` | Индекс будет бесконечно расти, программа выйдет за границы памяти и упадёт |
| Использовать `scanf("%s", ...)` | Программа прочитает строку только до первого пробела |
| Напечатать `\n` после цикла | Нарушение формата вывода (условие запрещает перенос строки в конце ответа) |
