# Разворот строки — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `Hello!` | `!olleH` | `printf 'Hello!\n' \| ./main` | Обычная строка |
| `abc def` | `fed cba` | `printf 'abc def\n' \| ./main` | Строка с пробелом посередине |
| `12345` | `54321` | `printf '12345\n' \| ./main` | Строка из цифр |
| `a` | `a` | `printf 'a\n' \| ./main` | Один символ |
| `  ab  ` | `  ba  ` | `printf '  ab  \n' \| ./main` | Пробелы по краям |

## Важные случаи

В таблице ниже входы записаны в кавычках, чтобы показать пустые строки и граничные пробелы. Кавычки не входят во входные данные.

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `"\n"` | `""` | `printf '\n' \| ./main` | Пустая строка (только перевод строки) |
| Пустой ввод | `""` | `./main < /dev/null` | EOF до первого символа |
| `"same"` | `"emas"` | `printf 'same' \| ./main` | Ввод завершается по EOF, без `\n` |
| `"!@#"` | `"#@!"` | `printf '!@#\n' \| ./main` | Знаки препинания |

## Проверка формата вывода

Посмотреть точные байты результата:

```bash
printf 'Hello!\n' | ./main | od -An -t x1
```

Ожидается:

```text
21 6f 6c 6c 65 48
```

Это символы `!olleH` в шестнадцатеричном представлении. Дополнительных байтов вроде `20` (пробел) или `0a` (перевод строки) в конце быть не должно.

### Cppcheck

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

```bash
clang-format -n -Werror main.c
```

### Valgrind

```bash
printf 'Hello!\n' | valgrind --leak-check=full ./main
```
