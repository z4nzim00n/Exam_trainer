# EXAM_06_12
# Удаление последнего вхождения подстроки — теория

## 1. С чего начать

Есть две строки. Первая — основной текст, вторая — подстрока, которую нужно найти и удалить.

Например:

```text
This is mytext
my
```

Подстрока `my` встречается один раз, между `is` и `text`. После удаления:

```text
This is text
```

Если подстрока встречается несколько раз, удалить нужно **только последнее** вхождение:

```text
abcabc
abc
```

Результат:

```text
abc
```

Первое `abc` остаётся, второе удаляется.

## 2. Как решать задачу по шагам

Задача разбивается на три части:

1. Прочитать обе строки.
2. Найти позицию последнего вхождения подстроки.
3. Вывести текст, пропуская символы этого вхождения.

Каждая часть решается отдельно и не требует сложных структур данных.

## 3. Как прочитать строку

Используем `getchar()` в цикле и записываем символы в массив, пока не встретим `'\n'` или EOF.

```c
static int read_line(char str[], int size) {
    int length = 0;
    int ch;

    while ((ch = getchar()) != EOF && ch != '\n') {
        if (length < size - 1) {
            str[length] = (char)ch;
            length++;
        }
    }

    str[length] = '\0';
    return length;
}
```

Функция возвращает длину прочитанной строки — это удобно, чтобы не считать её потом отдельно.

Символ `'\0'` в конце нужен, чтобы строка была правильной C-строкой. В нашем алгоритме мы работаем через длину, но `'\0'` не помешает.

### Почему `int` для `getchar()`

`getchar()` возвращает или код символа, или специальное значение `EOF`. Чтобы корректно различать эти случаи, результат сохраняют в `int`, а не в `char`.

### Почему проверяем `length < size - 1`

Оставляем одну позицию под завершающий `'\0'`. По условию длина не превышает размер массива, но проверка защищает от случайного выхода за границы.

## 4. Как искать подстроку

Проходим по основной строке и для каждой позиции проверяем, совпадают ли символы с подстрокой.

Если подстрока имеет длину `pattern_length`, то последняя позиция, с которой она может начаться:

```c
text_length - pattern_length
```

Например, для строки длины `10` и подстроки длины `3` позиции проверяем от `0` до `7` включительно.

```c
for (int i = 0; i <= text_length - pattern_length; i++) {
    int matched = 1;

    for (int j = 0; j < pattern_length; j++) {
        if (text[i + j] != pattern[j]) {
            matched = 0;
            break;
        }
    }

    if (matched) {
        last_match = i;
    }
}
```

### Как это работает

Для каждой позиции `i` во внешнем цикле:

- считаем, что совпадение есть (`matched = 1`);
- сравниваем `pattern_length` символов подряд;
- при первом несовпадении сбрасываем флаг и выходим из внутреннего цикла;
- если флаг остался равным `1`, запоминаем позицию.

Если позже найдётся ещё одно вхождение, значение `last_match` перезапишется. В итоге там окажется **последняя** найденная позиция.

### Что если ничего не найдено

Переменную `last_match` инициализируем значением `-1`:

```c
int last_match = -1;
```

Это условное значение, обозначающее «не найдено». Позиция в массиве не может быть отрицательной, поэтому `-1` невозможно спутать с реальной позицией.

### Особые случаи поиска

Если подстрока пустая (`pattern_length == 0`) или длиннее основной строки, искать нечего. Пропускаем цикл поиска:

```c
if (pattern_length > 0 && pattern_length <= text_length) {
    /* Цикл поиска. */
}
```

## 5. Как удалить найденную подстроку

Не нужно сдвигать символы в массиве. Достаточно при выводе пропустить те позиции, которые попадают внутрь найденного вхождения.

Если вхождение начинается в позиции `last_match` и имеет длину `pattern_length`, то удалить нужно символы с индексами:

```c
last_match, last_match + 1, ..., last_match + pattern_length - 1
```

Проверка для каждой позиции:

```c
if (last_match != -1
    && i >= last_match
    && i < last_match + pattern_length) {
    continue;
}
putchar(text[i]);
```

- `last_match != -1` — вхождение было найдено.
- `i >= last_match` — мы дошли до начала удаляемого фрагмента.
- `i < last_match + pattern_length` — мы ещё не вышли за его конец.

`continue` пропускает текущую итерацию, и символ не выводится.

Если вхождение не было найдено, первое условие ложно, и все символы выводятся.

## 6. Алгоритм целиком

1. Подготовить массивы под основную строку и подстроку.
2. Прочитать обе строки, запомнив их длины.
3. Установить `last_match = -1`.
4. Если подстрока не пустая и не длиннее основной строки, перебрать все позиции и запомнить последнюю позицию совпадения.
5. Пройти по основной строке. Символы внутри найденного вхождения пропустить, остальные вывести.

## 7. Пошаговый разбор

### Пример 1: одно вхождение

Основная строка: `This is mytext` (длина 14).
Подстрока: `my` (длина 2).

Проверяем позиции от `0` до `12`.

| `i` | Символы `text[i]`, `text[i+1]` | Совпадение |
| --- | --- | --- |
| `0` | `T`, `h` | Нет |
| `1` | `h`, `i` | Нет |
| ... | ... | ... |
| `8` | `m`, `y` | Да → `last_match = 8` |
| `9` | `y`, `t` | Нет |
| ... | ... | ... |

После цикла `last_match = 8`.

При выводе пропускаем позиции `8` и `9`:

```text
This is text
```

### Пример 2: несколько вхождений

Основная строка: `abcabc` (длина 6).
Подстрока: `abc` (длина 3).

| `i` | Совпадение |
| --- | --- |
| `0` | Да → `last_match = 0` |
| `1` | Нет |
| `2` | Нет |
| `3` | Да → `last_match = 3` |

После цикла `last_match = 3`.

При выводе пропускаем позиции `3`, `4`, `5`:

```text
abc
```

Первое вхождение осталось, последнее удалено.

## 8. Особые случаи

### Обе строки пустые

`text_length = 0`, `pattern_length = 0`. Цикл поиска не выполняется. Цикл вывода тоже не выполняется. Вывод пустой.

### Пустая подстрока

Условие `pattern_length > 0` ложно, поиск не выполняется. `last_match` остаётся равным `-1`. Основная строка выводится без изменений.

### Подстрока длиннее основной строки

`pattern_length > text_length`, поиск не выполняется. Основная строка выводится без изменений.

### Основная строка равна подстроке

Например, `abc` и `abc`. `last_match = 0`, `pattern_length = 3`. При выводе пропускаются все три символа. Вывод пустой.

### Разный регистр

`Text` и `text`. Сравнение символов буквальное: `'T' != 't'`. Совпадений нет, строка выводится без изменений.

### Вхождения пересекаются

Например, строка `aaaa` и подстрока `aa`. Позиции совпадений: `0`, `1`, `2`. `last_match = 2`. Удаляются символы с индексами `2` и `3`:

```text
aa
```

Алгоритм не рассматривает уже удалённые символы как отсутствующие — он ищет по исходной строке, а удаляет только выбранное последнее вхождение.

## 9. Почему решение работает

- Поиск проверяет все возможные позиции начала подстроки. Последняя из подходящих запоминается в `last_match`.
- Вывод пропускает ровно `pattern_length` символов, начиная с `last_match`. Остальные символы выводятся в исходном порядке.
- Если совпадений нет, `last_match == -1`, и первое условие пропуска ложно для всех позиций.

Время работы — `O(n × m)`, где `n` — длина основной строки, `m` — длина подстроки.

Дополнительная память — фиксированные массивы, не зависящие от длины строк в пределах заданных ограничений.

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Остановиться на первом найденном вхождении | Нужно последнее, а не первое |
| Использовать `strstr` из `<string.h>` | Функция запрещена условием |
| Инициализировать `last_match` нулём | `0` — реальная позиция, её нельзя использовать как «не найдено» |
| Проходить по позициям до `text_length` включительно | Последние `pattern_length - 1` позиций не могут вместить подстроку |
| Сдвигать символы в массиве вместо пропуска при выводе | Работает, но сложнее и легче ошибиться с границами |
| Читать строки через `scanf("%s", ...)` | Строки с пробелами будут прочитаны только до первого пробела |
| Игнорировать регистр | Условие требует точного сравнения |
| Считать пустую подстроку «найденной везде» | По условию она не изменяет строку |
| Добавить `\n` в конце | Условие запрещает завершающий перенос строки |
