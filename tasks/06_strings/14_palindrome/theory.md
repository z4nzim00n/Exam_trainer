# EXAM_06_14. Проверка на палиндром — теория

## 1. Что такое палиндром в этой задаче

Палиндром — строка, которая читается одинаково слева направо и справа налево.

В задании есть два важных правила:

1. **Регистр букв не важен.** `A` и `a` считаются одинаковыми, поэтому строку удобно сразу перевести в нижний регистр.
2. **Пробелы не игнорируются.** Пробел — обычный символ и участвует в сравнении. Если с одной стороны пробел, а с другой буква — это уже не палиндром.

```text
Mam mam  → YES   (пробел стоит ровно в середине)
ab a     → NO    (справа получается a ba, пробел не совпадает)
```

Строка содержит латинские буквы, цифры и пробелы, её длина не больше 100 символов. Ввод заканчивается `'\n'` или EOF.

## 2. План решения

1. Прочитать строку до `'\n'` или EOF.
2. Перевести все заглавные латинские буквы в строчные.
3. Поставить два указателя: `l` — на начало строки, `r` — на последний символ.
4. Двигаться к середине: если `str[l] != str[r]` — вывести `NO`.
5. Если все пары совпали — вывести `YES`.

## 3. Чтение строки

Удобнее всего прочитать строку целиком через `fgets`:

```c
char str[102];
int len = 0;

if (fgets(str, sizeof(str), stdin) != NULL) {
    for (int i = 0; str[i] != '\0' && str[i] != '\n'; i++) {
        len++;
    }
}
```

Почему буфер на 102 байта: до 100 символов самой строки, плюс `'\n'`, плюс завершающий `'\0'`.

`fgets` читает и пробелы, поэтому строка не обрезается на первом пробеле, как это было бы с `scanf("%s", ...)`.

Если ввода нет, `fgets` вернёт `NULL`, `len` останется равным `0`. Пустая строка считается палиндромом.

## 4. Приведение к нижнему регистру

Регистр не важен, поэтому заглавные буквы заменяем строчными прямо в массиве:

```c
if (str[i] >= 'A' && str[i] <= 'Z') {
    str[i] = str[i] - 'A' + 'a';
}
```

Как это работает:

- `str[i] - 'A'` — номер буквы от 0 до 25;
- `+ 'a'` — тот же номер, но среди строчных букв;
- результат записывается обратно в `str[i]`.

Цифры и пробелы не меняются. `tolower` из `<ctype.h>` не обязателен: на экзамене проще запомнить проверку по диапазону.

## 5. Проверка двумя указателями

```c
int l = 0;
int r = len - 1;

while (l < r) {
    if (str[l] != str[r]) {
        printf("NO");
        return 0;
    }
    l++;
    r--;
}

printf("YES");
```

- `l` начинается с первого символа;
- `r` — с последнего (`len - 1`);
- на каждом шаге сравниваются символы на одинаковом расстоянии от краёв;
- после сравнения указатели сдвигаются к центру.

Цикл `l < r` останавливается, когда указатели встретились или разошлись. Центральный символ (если длина нечётная) сравнивать с самим собой не нужно.

## 6. Полная программа

```c
#include <stdio.h>

int main(void) {
    char str[102];
    int len = 0;

    if (fgets(str, sizeof(str), stdin) != NULL) {
        for (int i = 0; str[i] != '\0' && str[i] != '\n'; i++) {
            if (str[i] >= 'A' && str[i] <= 'Z') {
                str[i] = str[i] - 'A' + 'a';
            }
            len++;
        }
    }

    int l = 0;
    int r = len - 1;

    while (l < r) {
        if (str[l] != str[r]) {
            printf("NO");
            return 0;
        }
        l++;
        r--;
    }

    printf("YES");
    return 0;
}
```

## 7. Пошаговый разбор

### `Mam mam`

После нижнего регистра: `mam mam`, длина 7.

| Шаг | `l` | `r` | `str[l]` | `str[r]` | Совпало |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 6 | `m` | `m` | да |
| 2 | 1 | 5 | `a` | `a` | да |
| 3 | 2 | 4 | `m` | `m` | да |
| 4 | 3 | 3 | — | — | остановка |

Ответ: `YES`.

### `ab a`

После нижнего регистра: `ab a`, длина 4.

| Шаг | `l` | `r` | `str[l]` | `str[r]` | Совпало |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 3 | `a` | `a` | да |
| 2 | 1 | 2 | `b` | ` ` | нет |

Ответ: `NO`. Пробел — значимый символ.

### `Test1`

После нижнего регистра: `test1`.

Первая пара: `t` и `1` — не совпали. Ответ: `NO`.

### `Aa`

После нижнего регистра: `aa`. Пара `a` и `a` совпала. Ответ: `YES`.

## 8. Особые случаи

| Ввод | Ответ | Почему |
| --- | --- | --- |
| пустая строка | `YES` | `len == 0`, цикл не выполняется |
| `a` | `YES` | один символ всегда палиндром |
| `   ` | `YES` | три одинаковых пробела симметричны |
| `a b a` | `YES` | пробелы стоят симметрично |
| `abba ` | `NO` | лишний пробел в конце ломает симметрию |
| `12321` | `YES` | цифры участвуют наравне с буквами |
| `A man a plan a canal Panama` | `NO` | регистр не важен, но пробелы значимы |

## 9. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Игнорировать пробелы | `ab a` превратится в `aba` и даст `YES`, а правильный ответ `NO` |
| Не приводить к нижнему регистру | `Aa` даст `NO` вместо `YES` |
| Использовать `scanf("%s", ...)` | Прочитается только первое слово до пробела |
| Сравнивать строку с её копией через `strcmp` после разворота | Нужно не забыть те же правила: регистр и пробелы |
| Начинать `r` с `len` вместо `len - 1` | Первое сравнение выйдет за пределы строки |
| Добавить `\n` в вывод | Условие запрещает завершающий перенос |
| Выводить `1`/`0` или `Yes`/`No` | Нужно ровно `YES` и `NO` |
