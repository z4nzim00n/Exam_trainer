## EXAM_08_06. Удаление цифр

### Задание

| EXAM_08_06 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, символы, циклы, условные операторы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, удаляющую из строки все цифры.

Строка задаётся на стандартном потоке ввода stdin. Необходимо вывести на стандартный поток вывода stdout все её символы, кроме символов от `'0'` до `'9'`.

Порядок оставшихся символов должен совпадать с их порядком в исходной строке.

В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ `'\n'` или конец ввода EOF.
- Удаляются только цифры. Буквы, пробелы и знаки препинания сохраняются без изменений.
- Например, в записи `-12.5` удаляются цифры `1`, `2` и `5`, но сохраняются `-` и `.`.
- Пробелы нельзя удалять, добавлять или объединять.
- Если строка пустая или состоит только из цифр, программа ничего не выводит.
- Проверку принадлежности символа к цифрам необходимо реализовать самостоятельно, без функций библиотеки `<ctype.h>`.
- Изменять исходный массив необязательно: достаточно вывести нужные символы.
- Можно использовать обычный массив `char`. Динамическая память не требуется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `a1b23c` | `abc` |
| `School21` | `School` |
| `Hello, World!` | `Hello, World!` |
| `1a2-b3!` | `a-b!` |
| `-12.5` | `-.` |

**Пример с сохранением пробелов**

Входные данные:

```text
a 123 b
```

Результат работы — между буквами остаются два пробела:

```text
a  b
```

> **Внимание:** Процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
