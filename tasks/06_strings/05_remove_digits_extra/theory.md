# EXAM_08_06. Удаление цифр — теория

## 1. С чего начать

Нужно прочитать строку и вывести её без цифр.

Например:

```text
a1b23c
```

Результат:

```text
abc
```

Удаляются только символы от `'0'` до `'9'`.

Все остальные символы сохраняются:

- буквы;
- пробелы;
- знаки препинания.

Например:

```text
-12.5
```

Результат:

```text
-.
```

Программа не разбирает число `-12.5`. Она рассматривает каждый символ отдельно.

## 2. Нужно ли изменять строку в массиве

Нет. По условию достаточно вывести результат.

Можно читать символы по одному:

- цифру — пропустить;
- любой другой символ — вывести.

Это называется фильтрацией: мы сохраняем только символы, удовлетворяющие условию.

Массив, сдвиги элементов и динамическая память здесь не нужны.

## 3. Как прочитать один символ

Используем `getchar()` из `<stdio.h>`:

```c
int ch;

ch = getchar();
```

Функция читает следующий символ из стандартного потока ввода.

Пробелы она не пропускает. Это важно: они должны сохраниться в результате.

### Почему `int`, а не `char`

`getchar()` возвращает код символа или специальное значение EOF.

Тип `int` позволяет корректно различать прочитанный символ и EOF.

Поэтому сначала результат чтения сохраняется именно в `int`.

## 4. Когда заканчивать чтение

По условию строка завершается:

- переводом строки `'\n'`;
- либо концом ввода EOF.

Цикл:

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    /* Обработка символа. */
}
```

При каждой проверке:

1. Читаем следующий символ.
2. Сохраняем его в `ch`.
3. Проверяем, что это не EOF.
4. Проверяем, что это не перевод строки.
5. Обрабатываем символ.

Сам `'\n'` в тело цикла не попадает и не выводится.

## 5. Как определить цифру

Символ является цифрой, если находится в диапазоне от `'0'` до `'9'`:

```c
ch >= '0' && ch <= '9'
```

Здесь важно использовать символьные литералы:

```c
'0'
'9'
```

Это не то же самое, что целые числа `0` и `9`.

Например, в ASCII код символа `'0'` равен 48, а код символа `'9'` — 57. Запоминать эти коды не нужно: запись через символы понятнее.

## 6. Как проверить, что символ не является цифрой

Для вывода нужны символы вне диапазона:

```c
ch < '0' || ch > '9'
```

Оператор `||` означает «ИЛИ».

Символ не является цифрой, если:

- его код меньше кода `'0'`;
- или его код больше кода `'9'`.

Используем проверку так:

```c
if (ch < '0' || ch > '9') {
    putchar(ch);
}
```

`putchar(ch)` выводит один символ.

Если прочитана цифра, условие ложно, и программа ничего для неё не выводит.

### Почему не `&&`

Условие:

```c
ch < '0' && ch > '9'
```

невозможно выполнить: значение не может одновременно находиться ниже начала диапазона и выше его конца.

Здесь требуется именно `||`.

## 7. Алгоритм решения

1. Подготовить переменную для текущего символа.
2. Читать символы до `'\n'` или EOF.
3. Для каждого символа:
    - если это цифра — пропустить;
    - иначе вывести без изменений.
4. Завершить программу, не добавляя перевод строки.

## 8. Пошаговый разбор

Вход:

```text
a1 2b!
```

| Прочитано | Цифра? | Действие | Вывод к этому моменту |
| --- | --- | --- | --- |
| `a` | Нет | Выводим | `a` |
| `1` | Да | Пропускаем | `a` |
| Пробел | Нет | Выводим | `a ` |
| `2` | Да | Пропускаем | `a ` |
| `b` | Нет | Выводим | `a b` |
| `!` | Нет | Выводим | `a b!` |
| `\n` | Не проверяем | Завершаем цикл | `a b!` |

Результат:

```text
a b!
```

## 9. Что происходит с пробелами

Пробелы сохраняются в исходном количестве.

Например:

```text
a 123 b
```

В исходной строке есть два пробела: один перед `123`, другой после.

После удаления цифр оба остаются:

```text
a  b
```

Объединять их в один нельзя: условие требует удалить только цифры.

По этой же причине в результате допустимы начальные и конечные пробелы, если они были во входном тексте.

Запрещён только добавленный перевод строки в конце ответа.

## 10. Особые случаи

### Пустая строка

Первый символ — `'\n'`. Цикл не выполняется, вывод пустой.

### Пустой ввод

Сразу получаем EOF. Вывод пустой.

### Только цифры

Ни один символ не проходит условие вывода. Результат пустой.

### Цифр нет

Все символы выводятся, строка остаётся без изменений.

### Только пробелы

Все пробелы выводятся. Это не пустой результат.

### Ввод без завершающего перевода строки

После последнего символа `getchar()` возвращает EOF, цикл завершается.

## 11. Почему решение работает

Каждый символ текста обрабатывается ровно один раз.

- Цифры не выводятся.
- Непробельные и пробельные символы, не являющиеся цифрами, выводятся без изменения.
- Порядок сохраняется, потому что чтение и вывод идут слева направо.

Время работы — `O(n)`, где `n` — длина строки.

Дополнительная память — `O(1)`: используется одна переменная независимо от длины строки.

## 12. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Сравнивать `ch` с `0` и `9` | Это числа, а не коды символов цифр |
| Использовать `&&` в проверке выхода за диапазон | Условие никогда не выполнится |
| Выводить символы внутри диапазона `'0'`–`'9'` | Получится сохранение цифр вместо удаления |
| Читать через `scanf("%s", ...)` | Будет прочитано только одно слово |
| Удалять пробелы вместе с цифрами | Пробелы нужно сохранять |
| Считать минус и точку частью удаляемого числа | Задача работает с символами, а не с числовыми значениями |
| Хранить результат `getchar()` в `char` | Можно некорректно обработать EOF |
| Проверять только перевод строки | Нужно также завершаться по EOF |
| Добавить `\n` после результата | Это нарушает формат вывода |
