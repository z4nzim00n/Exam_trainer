## EXAM_06_07. Удаление лишних пробелов

### Задание

| EXAM_07_01 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Символы, строки, циклы, условные операторы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, удаляющую лишние пробелы из строки.

Программа должна:

- удалить все пробелы в начале строки;
- заменить несколько подряд идущих пробелов одним;
- удалить все пробелы в конце строки;
- сохранить остальные символы и их порядок.

Строка поступает через стандартный поток ввода stdin. Концом строки является символ перевода строки `'\n'` или конец ввода EOF. Символ перевода строки не является частью обрабатываемого текста.

Результат вывести на стандартный поток вывода stdout. В конце ответа не должно быть пробела или переноса на новую строку.

### Уточнения

- Под пробелом понимается обычный символ `' '`.
- Гарантируется, что во входной строке нет табуляций и символов `'\r'`.
- Строка может быть пустой или состоять только из пробелов. В этих случаях программа ничего не выводит.
- Остальные символы, включая цифры и знаки препинания, изменять нельзя.
- Хранить всю строку в массиве необязательно: её можно обрабатывать посимвольно.

### Примеры

**Пример 1**

Входные данные:

```text
   Hello,    World!   
```

Результат работы:

```text
Hello, World!
```

**Пример 2**

Входные данные:

```text
  1   2     3  
```

Результат работы:

```text
1 2 3
```

**Пример 3**

Входные данные:

```text
T e x t
```

Результат работы:

```text
T e x t
```

> Обратите внимание: одиночные пробелы сохраняются, двойные и более — схлопываются.
