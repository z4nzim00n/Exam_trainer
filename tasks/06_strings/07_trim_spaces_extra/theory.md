# EXAM_07_01. Удаление лишних пробелов — теория

## 1. С чего начать

Нужно прочитать строку и привести пробелы в порядок:

- в начале строки пробелов быть не должно;
- между частями текста должен остаться ровно один пробел;
- в конце строки пробелов быть не должно.

Все остальные символы сохраняются без изменений.

Например:

```text
   Hello,    World!   
```

Результат:

```text
Hello, World!
```

Но строка:

```text
T e x t
```

не меняется. Удаляем только лишние пробелы, а не все пробелы подряд.

## 2. Нужно ли хранить всю строку

Нет. Можно читать символы по одному и сразу выводить те, которые должны остаться.

Для решения достаточно помнить:

- текущий символ;
- был ли уже выведен текст;
- встретился ли после текста пробел, который пока нельзя вывести.

Массив и динамическая память не нужны.

Это позволяет обрабатывать строку без заранее заданного ограничения длины.

## 3. Главная трудность — пробел в конце

Представим, что программа прочитала:

```text
Hello   
```

Пока неизвестно, что будет дальше:

- если появится `World`, между словами нужен один пробел;
- если строка закончится, пробел выводить нельзя.

Поэтому пробел нельзя печатать сразу после чтения.

**Основная идея: запоминаем пробел, но выводим его только тогда, когда после него появился следующий непробельный символ.**

Так конечные пробелы удаляются сами собой: после них нет текста, который заставил бы вывести отложенный пробел.

## 4. Какие переменные нужны

```c
int ch;
int has_text = 0;
int pending_space = 0;
```

### `ch` — текущий символ

В эту переменную записывается результат `getchar()`.

### `has_text` — был ли уже выведен текст

- `0` — ещё не выведено ни одного непробельного символа;
- `1` — хотя бы один такой символ уже выведен.

Флаг нужен, чтобы игнорировать пробелы в начале строки.

Под текстом здесь понимается любой непробельный символ: буква, цифра, знак препинания и так далее.

### `pending_space` — отложенный пробел

- `0` — перед следующим символом пробел не нужен;
- `1` — после выведенного текста встретились пробелы.

Флаг хранит не количество пробелов, а сам факт их наличия.

Поэтому один пробел и десять пробелов подряд обрабатываются одинаково.

## 5. Алгоритм решения

1. Установить оба флага в `0`.
2. Читать символы до перевода строки или EOF.
3. Если прочитан пробел:
    - до первого текста — игнорировать его;
    - после текста — установить флаг отложенного пробела.
4. Если прочитан любой другой символ:
    - при наличии отложенного пробела вывести один пробел и сбросить флаг;
    - вывести сам символ;
    - отметить, что текст уже появился.
5. После завершения ввода ничего дополнительно не выводить.

## 6. Что понадобится из C

### Чтение символа через `getchar`

```c
ch = getchar();
```

Функция `getchar()` из `<stdio.h>` читает один символ из стандартного потока ввода.

В отличие от чтения слова через `scanf("%s", ...)`, она не пропускает пробелы. Для этой задачи важно видеть каждый из них.

### Почему для символа используется `int`

`getchar()` возвращает:

- код прочитанного символа, представленный как `unsigned char` и преобразованный в `int`;
- либо специальное значение `EOF`.

Чтобы корректно различать символы и `EOF`, результат сначала сохраняют в `int`, а не в `char`.

```c
int ch;
```

### Что такое EOF

EOF обозначает конец ввода. Это не обычный символ текста.

Например:

```bash
printf 'Hello' | ./main
```

Команда передаёт пять символов без перевода строки. После них программа получает EOF.

Поэтому нужно уметь завершать чтение и по `'\n'`, и по EOF.

### Чтение в цикле

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    /* Обработка символа. */
}
```

При каждой проверке условия:

1. `getchar()` читает следующий символ.
2. Результат записывается в `ch`.
3. Проверяется, что это не EOF.
4. Проверяется, что это не перевод строки.
5. Если обе проверки успешны, выполняется тело цикла.

Скобки вокруг присваивания важны:

```c
(ch = getchar())
```

Сначала нужно сохранить результат чтения, а затем сравнивать его.

### Символьные литералы

```c
' '
```

Обычный пробел.

```c
'\n'
```

Символ перевода строки.

Одинарные кавычки используются для символьных литералов. Двойные кавычки обозначают строки:

```c
' '   /* Символ. */
" "   /* Строка. */
```

Для сравнения с `ch` нужен именно символ:

```c
ch == ' '
```

### Вывод через `putchar`

```c
putchar(ch);
```

Функция выводит один символ.

Для вывода одного пробела:

```c
putchar(' ');
```

Сама по себе `putchar` не добавляет перевод строки.

## 7. Как обрабатываются пробелы

```c
if (ch == ' ') {
    if (has_text) {
        pending_space = 1;
    }
}
```

Если текста ещё не было, `has_text` равно `0`. Пробел игнорируется.

Если текст уже был, запоминаем, что встретился разделитель:

```c
pending_space = 1;
```

При повторных пробелах значение остаётся равным `1`. Ничего не выводится.

Таким образом:

- начальные пробелы отбрасываются;
- несколько пробелов после текста превращаются в один отложенный пробел.

## 8. Как обрабатываются остальные символы

```c
else {
    if (pending_space) {
        putchar(' ');
        pending_space = 0;
    }
    putchar(ch);
    has_text = 1;
}
```

Появился непробельный символ. Значит, если перед ним были пробелы после текста, они находились внутри строки, а не в её конце.

Теперь можно:

1. Вывести один отложенный пробел.
2. Сбросить его флаг.
3. Вывести текущий символ.
4. Установить `has_text` в `1`.

Если отложенного пробела нет, выводим только символ.

### Зачем сбрасывать `pending_space`

Если не сбросить флаг, пробел начнёт появляться перед каждым следующим символом.

Например, вместо:

```text
a bc
```

может получиться:

```text
a b c
```

### Почему `has_text` не сбрасывается

Этот флаг означает «в выводе уже есть текст», а не «мы сейчас внутри слова».

После первого выведенного символа это остаётся правдой до конца программы.

## 9. Пошаговый разбор

Вход:

```text
  a   b  
```

В таблице `␠` обозначает один пробел. В реальном вводе используется обычный пробел.

| Прочитано | Действие | `has_text` | `pending_space` | Вывод к этому моменту |
| --- | --- | --- | --- | --- |
| `␠` | Начальный пробел — пропускаем | `0` | `0` | Пусто |
| `␠` | Начальный пробел — пропускаем | `0` | `0` | Пусто |
| `a` | Выводим символ | `1` | `0` | `a` |
| `␠` | Запоминаем пробел | `1` | `1` | `a` |
| `␠` | Флаг уже установлен | `1` | `1` | `a` |
| `␠` | Флаг уже установлен | `1` | `1` | `a` |
| `b` | Выводим пробел, затем `b` | `1` | `0` | `a b` |
| `␠` | Запоминаем пробел | `1` | `1` | `a b` |
| `␠` | Флаг уже установлен | `1` | `1` | `a b` |
| `\n` | Завершаем цикл | `1` | `1` | `a b` |

После цикла `pending_space` остаётся равным `1`, но это не ошибка.

Отложенный пробел был в конце строки, поэтому выводить его не нужно.

## 10. Почему решение работает

Каждое правило условия выполняется отдельно:

- **Нет начальных пробелов:** пока не появился текст, пробелы игнорируются.
- **Нет повторных пробелов:** любое количество пробелов хранится одним флагом и выводится одним символом.
- **Нет конечных пробелов:** отложенный пробел выводится только перед следующим непробельным символом.
- **Остальные символы сохранены:** каждый непробельный символ выводится ровно один раз и в исходном порядке.
- **Нет завершающего переноса:** `'\n'` останавливает цикл и не попадает в вывод.

Каждый входной символ обрабатывается один раз:

- время работы — `O(n)`, где `n` — длина строки;
- дополнительная память — `O(1)`, потому что количество переменных не зависит от длины строки.

## 11. Особые случаи

### Пустая строка

Первый прочитанный символ — `'\n'`. Тело цикла не выполняется, вывод пустой.

### Пустой ввод

Первый вызов `getchar()` возвращает EOF. Вывод также пустой.

### Только пробелы

`has_text` всё время остаётся равным `0`. Все пробелы игнорируются.

### Нет пробелов

Каждый символ сразу выводится без изменений.

### Нет перевода строки в конце

Цикл завершается по EOF. Обработка остаётся такой же.

### Табуляции

По условию их во входе нет. Программа проверяет именно обычный пробел `' '`, а не все возможные пробельные символы.

## 12. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Читать строку через `scanf("%s", ...)` | Будет прочитано только одно слово, а не вся строка с пробелами |
| Выводить первый встретившийся пробел сразу | Он может оказаться начальным или конечным |
| Удалять все пробелы | Слова склеятся, хотя одиночные разделители нужно сохранить |
| Считать пробелы и затем выводить столько же | Повторные пробелы не будут удалены |
| Устанавливать `pending_space` до появления текста | Перед первым символом может появиться лишний пробел |
| Не сбрасывать `pending_space` после вывода | Пробелы начнут появляться внутри слов |
| Выводить отложенный пробел после цикла | В результате появится запрещённый конечный пробел |
| Хранить результат `getchar()` в `char` | Можно потерять возможность корректно отличить символ от EOF |
| Проверять только `'\n'`, забыв про EOF | Ввод без завершающего перевода строки может обрабатываться неправильно |
| Добавить `putchar('\n')` в конце | Условие запрещает завершающий перенос строки |
