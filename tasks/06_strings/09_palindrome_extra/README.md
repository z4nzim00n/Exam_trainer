## EXAM_08_05. Палиндром

### Задание

| EXAM_08_05 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, массивы, индексы, циклы, сравнение символов. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, проверяющую, является ли строка палиндромом.

Палиндром — строка, которая одинаково читается слева направо и справа налево.

Строка задаётся на стандартном потоке ввода stdin. Если она является палиндромом, вывести на стандартный поток вывода stdout `1`, иначе вывести `0`.

В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ `'\n'` или конец ввода EOF.
- Завершающий перевод строки не участвует в проверке.
- Символы сравниваются точно: `'A'` и `'a'` считаются разными.
- Пробелы и знаки препинания участвуют в проверке наравне с остальными символами. Удалять их не нужно.
- Пустая строка и строка из одного символа считаются палиндромами.
- Можно использовать обычный массив `char`. Динамическая память не требуется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `level` | `1` |
| `hello` | `0` |
| `anna` | `1` |
| `Anna` | `0` |
| `12321` | `1` |
| `a b a` | `1` |
| `a` | `1` |

> **Внимание:** Процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
