# EXAM_08_05. Палиндром — теория

## 1. С чего начать

Нужно проверить, одинаково ли строка читается слева направо и справа налево.

Такая строка называется палиндромом.

Например:

```text
level
```

В обратном порядке получается та же строка. Ответ:

```text
1
```

Для строки:

```text
hello
```

Обратный порядок даёт `olleh`. Ответ:

```text
0
```

По условию символы сравниваются точно:

- заглавные и строчные буквы различаются;
- пробелы участвуют в проверке;
- знаки препинания участвуют в проверке.

Поэтому:

```text
anna → 1
Anna → 0
a b a → 1
```

Пустая строка и строка из одного символа считаются палиндромами.

## 2. Главная идея

Необязательно переворачивать строку или создавать её копию.

Достаточно сравнить симметричные символы:

1. Первый с последним.
2. Второй с предпоследним.
3. Третий с третьим с конца.
4. Продолжать до середины строки.

Для строки:

```text
level
```

Сравниваем:

```text
l e v e l
↑       ↑
```

Затем:

```text
l e v e l
  ↑   ↑
```

Символ в середине сравнивать не нужно: он совпадает сам с собой.

Если хотя бы одна пара различается, строка не является палиндромом.

## 3. Какие переменные нужны

```c
char text[102];
int length = 0;
int palindrome = 1;
```

### `text` — массив для строки

В нём будут храниться прочитанные символы.

Размер `102` учитывает:

- до 100 символов текста;
- возможный перевод строки `'\n'`;
- завершающий нулевой символ `'\0'`.

### `length` — длина текста

Изначально равна нулю. После успешного чтения в неё записывается количество символов до `'\n'` или `'\0'`.

Завершающий перевод строки в длину не входит.

### `palindrome` — результат проверки

Сначала предполагаем, что строка является палиндромом:

```c
int palindrome = 1;
```

Если найдём несовпадающую пару, изменим значение на `0`.

Это удобный подход: начинаем с предположения и ищем то, что его опровергает.

## 4. Как строка хранится в C

Строка в C — последовательность символов в массиве, заканчивающаяся нулевым символом:

```c
'\0'
```

Например, после чтения строки `cat` с переводом строки массив содержит:

| Индекс | Символ |
| --- | --- |
| `0` | `'c'` |
| `1` | `'a'` |
| `2` | `'t'` |
| `3` | `'\n'` |
| `4` | `'\0'` |

Индексы массива начинаются с нуля.

Важно различать:

| Запись | Значение |
| --- | --- |
| `'0'` | Символ цифры ноль |
| `'\0'` | Нулевой символ — конец строки в C |
| `'\n'` | Символ перевода строки |

## 5. Чтение строки через `fgets`

```c
if (fgets(text, sizeof(text), stdin) != NULL) {
    /* Определение длины. */
}
```

Функция `fgets` объявлена в `<stdio.h>`.

Ей передаются:

- `text` — массив для записи;
- `sizeof(text)` — размер массива в байтах;
- `stdin` — стандартный поток ввода.

Для массива `char text[102]` выражение `sizeof(text)` равно `102`.

Функция читает не более 101 символа, оставляя место для завершающего `'\0'`.

Чтение заканчивается, когда:

- прочитан перевод строки;
- достигнут конец ввода;
- заполнено доступное место.

Если перевод строки прочитан, он сохраняется в массиве.

### Почему не `scanf("%s", text)`

`scanf` с `%s` читает только одно слово: пробел завершает чтение.

Для входа:

```text
a b a
```

будет прочитано только `a`.

Но по условию проверять нужно всю строку, включая пробелы. Поэтому используется `fgets`.

### Что означает проверка `!= NULL`

При успешном чтении `fgets` возвращает указатель на переданный массив.

Если читать нечего из-за EOF до первого символа или произошла ошибка чтения, возвращается `NULL`.

Проверка позволяет обрабатывать содержимое массива только после успешного чтения.

Если текст есть, но завершающего `'\n'` нет, `fgets` может успешно прочитать этот текст до EOF.

## 6. Определение длины

После успешного чтения выполняется цикл:

```c
while (text[length] != '\0' && text[length] != '\n') {
    length++;
}
```

Начинаем с позиции `0`.

Пока текущий символ не является концом строки или переводом строки, увеличиваем длину на один.

Для входа `level` с переводом строки:

| `length` | `text[length]` | Действие |
| --- | --- | --- |
| `0` | `'l'` | Увеличиваем длину |
| `1` | `'e'` | Увеличиваем длину |
| `2` | `'v'` | Увеличиваем длину |
| `3` | `'e'` | Увеличиваем длину |
| `4` | `'l'` | Увеличиваем длину |
| `5` | `'\n'` | Завершаем цикл |

Получаем:

```text
length = 5
```

Если перевод строки отсутствует, цикл остановится на `'\0'`.

### Нужно ли удалять `'\n'` из массива

В этом решении — нет.

Мы вычислили длину без перевода строки. Дальше используются только индексы от `0` до `length - 1`.

Поэтому `'\n'` не попадёт в сравнение, даже если останется в массиве.

## 7. Как найти симметричный символ

Если длина строки равна `length`, последний символ имеет индекс:

```c
length - 1
```

Символу с индексом `i` соответствует символ с другого конца:

```c
length - 1 - i
```

Для строки длины `6`:

| Индекс слева | Индекс справа |
| --- | --- |
| `0` | `5` |
| `1` | `4` |
| `2` | `3` |

Поэтому сравнение одной пары выглядит так:

```c
text[i] != text[length - 1 - i]
```

Если оно истинно, симметричные символы различаются.

## 8. Почему достаточно половины строки

Цикл проверки:

```c
for (int i = 0; i < length / 2; i++) {
    /* Сравнение пары символов. */
}
```

В выражении `length / 2` выполняется целочисленное деление:

```text
6 / 2 = 3
5 / 2 = 2
1 / 2 = 0
```

### Чётная длина

Для `abba` проверяем две пары:

- `a` и `a`;
- `b` и `b`.

### Нечётная длина

Для `level` проверяем две пары:

- `l` и `l`;
- `e` и `e`.

Центральный символ `v` не требует проверки.

Если продолжить обход после середины, мы просто повторно сравним те же пары в обратном порядке.

## 9. Что делать при несовпадении

```c
if (text[i] != text[length - 1 - i]) {
    palindrome = 0;
    break;
}
```

Одной несовпадающей пары достаточно, чтобы строка не являлась палиндромом.

Поэтому:

1. Записываем `0` в переменную результата.
2. Завершаем цикл через `break`.

`break` завершает ближайший цикл, но не всю программу.

После него выполнение продолжается с вывода результата.

Если несовпадений нет, `palindrome` остаётся равным `1`.

## 10. Алгоритм решения

1. Подготовить массив для строки.
2. Установить длину в `0`, а результат проверки — в `1`.
3. Попытаться прочитать строку через `fgets`.
4. Если чтение успешно, посчитать символы до `'\n'` или `'\0'`.
5. Проверить симметричные пары до середины строки.
6. При первом несовпадении установить результат в `0` и завершить цикл.
7. Вывести результат без переноса строки.

## 11. Пошаговый разбор

### Пример 1: палиндром

Вход:

```text
abccba
```

Длина равна `6`, поэтому проверяем три пары.

| `i` | `length - 1 - i` | Сравнение | `palindrome` |
| --- | --- | --- | --- |
| `0` | `5` | `'a' == 'a'` | `1` |
| `1` | `4` | `'b' == 'b'` | `1` |
| `2` | `3` | `'c' == 'c'` | `1` |

Все пары совпали.

Вывод:

```text
1
```

### Пример 2: не палиндром

Вход:

```text
abca
```

Длина равна `4`.

| `i` | `length - 1 - i` | Сравнение | Действие |
| --- | --- | --- | --- |
| `0` | `3` | `'a' == 'a'` | Продолжаем |
| `1` | `2` | `'b' != 'c'` | Устанавливаем `0`, выходим из цикла |

Вывод:

```text
0
```

## 12. Особые случаи

### Пустая строка

Если пользователь сразу нажал Enter, `fgets` прочитает:

```text
'\n' '\0'
```

Цикл подсчёта длины сразу остановится. `length` останется равным `0`.

Условие цикла сравнения:

```c
i < length / 2
```

при `i == 0` будет ложным.

Результат останется равным `1`.

### EOF до первого символа

Если `fgets` возвращает `NULL`, блок подсчёта длины не выполняется.

`length` остаётся равным `0`, поэтому цикл сравнения тоже не выполняется.

Программа выводит `1`, то есть рассматривает отсутствие прочитанных символов как пустую строку.

Хотя массив `text` в этом случае не заполнен, его элементы нигде не читаются.

> Отдельная диагностика ошибок ввода в этом решении не предусмотрена. Условие гарантирует корректный ввод.

### Один символ

При длине `1` выражение `length / 2` равно `0`.

Пар для проверки нет. Ответ — `1`.

### Только пробелы

Любая строка, состоящая только из обычных пробелов, является палиндромом: все её символы одинаковы.

### Разный регистр

Для строки:

```text
Anna
```

первая пара — `'A'` и `'a'`. Они различаются, поэтому ответ — `0`.

### Пробелы по краям

Пробелы не удаляются.

Например, строка из двух символов — `'a'` и `' '` — не является палиндромом.

### Почему не возникает отрицательный индекс для пустой строки

Внутри цикла используется:

```c
text[length - 1 - i]
```

Но при нулевой длине тело цикла не выполняется. Это выражение не вычисляется, обращения к массиву нет.

## 13. Вывод результата

```c
printf("%d", palindrome);
```

Переменная `palindrome` содержит:

- `1` — строка является палиндромом;
- `0` — строка не является палиндромом.

Не добавляем пробелы, пояснения или `'\n'`.

## 14. Почему решение работает

Чтобы строка одинаково читалась в обоих направлениях, каждый символ должен совпадать с симметричным ему символом.

Алгоритм проверяет все такие пары ровно по одному разу:

- если нашлось несовпадение, обратный порядок отличается от исходного;
- если несовпадений нет, обратный порядок полностью совпадает с исходным.

Время работы — `O(n)`, где `n` — длина строки:

- один проход для определения длины;
- не более половины длины для сравнения пар.

Используется фиксированный массив из 102 элементов. Дополнительная копия строки и динамическая память не нужны.

## 15. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Читать строку через `scanf("%s", ...)` | Будет прочитано только первое слово |
| Включить `'\n'` в длину текста | Перевод строки начнёт участвовать в сравнении |
| Использовать `length` как индекс последнего символа | Последний символ находится по индексу `length - 1` |
| Написать `length - i` вместо `length - 1 - i` | Симметричная позиция будет вычислена неверно |
| Проверить только первую и последнюю буквы | Внутренние пары тоже могут различаться |
| Изначально установить `palindrome = 0` и не менять при успехе | Палиндромы, включая пустую строку, получат неправильный результат |
| После несовпадения снова устанавливать флаг в `1` | Совпадение другой пары не отменяет найденного различия |
| Удалять пробелы или менять регистр | Это нарушает правила точного сравнения |
| Обращаться к массиву после неудачного чтения без проверки | Его содержимое может быть неинициализировано |
| Добавить перенос строки при выводе | Условие запрещает его в конце ответа |
