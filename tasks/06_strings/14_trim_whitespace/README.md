## EXAM_06_14. Удаление лишних пробелов и табуляций

> !ВАЖНО!
>
> В тренажёре есть похожее задание (06_07). Отличие этой версии от той —
> во входе могут встречаться табуляции. Их нужно обрабатывать так же,
> как обычные пробелы: удалять по краям и заменять одним обычным пробелом
> между словами.
>
> В выводе разделитель между словами всегда обычный пробел, даже если во
> входе была табуляция.

### Задание

| EXAM_06_14                  ||
|-----------------------------| ------- |
| **Уровень:**                | 2 |
| **Темы:**                   | Символы, строки, циклы, условные операторы. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Написать программу, убирающую лишние пробелы в начале и в конце строки, а также между словами. Между словами должен остаться ровно один пробел.

Строка поступает через стандартный поток ввода stdin. Каждая строка завершается символом перевода строки `'\n'`.

Результат вывести на стандартный поток вывода stdout. В конце ответа не должно быть пробела или переноса на новую строку.

### Уточнения

- Пробельными считаются обычный пробел `' '` и табуляция `'\t'`.
- Разделитель между словами в выводе — всегда обычный пробел, даже если во входе была табуляция.
- Пробельные символы в начале и конце строки удаляются.
- Внутри текста серии пробельных символов схлопываются в один пробел.
- Остальные символы, включая цифры и знаки препинания, изменять нельзя.
- Строка может быть пустой или состоять только из пробельных символов. В этих случаях программа ничего не выводит.
- Хранить всю строку в массиве необязательно: её можно обрабатывать посимвольно.

### Примеры

**Пример 1**

Входные данные (между `test` и `text` стоит табуляция):

```text
   test   sample test	text
```

Результат работы:

```text
test sample test text
```

**Пример 2**

Входные данные (пробелы, табуляция, слово `text`):

```text
    	text
```

Результат работы:

```text
text
```

**Пример 3**

Входные данные (пробелы, табуляция, буква `t`, пробел, табуляция):

```text
            	t 	
```

Результат работы:

```text
t
```

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
