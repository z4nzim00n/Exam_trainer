# EXAM_06_13 Проверка на палиндром — теория

## 1. С чего начать

Нужно проверить, читается ли строка одинаково в обе стороны. Но есть два усложнения:

- пробелы нужно игнорировать;
- регистр букв не важен.

Пример:

```text
Mam mam
```

Убираем пробел: `Mammam`. Приводим к нижнему регистру: `mammam`. Читаем справа налево: `mammam`. Совпадает — ответ `YES`.

Другой пример:

```text
Test1
```

Пробелов нет. Приводим к нижнему регистру: `test1`. Справа налево: `1tset`. Не совпадает — ответ `NO`.

## 2. Два этапа решения

**Первый этап — очистка строки.** Проходим по исходной строке и копируем в новый массив только буквы и цифры, сразу переводя заглавные в строчные. Пробелы пропускаем.

**Второй этап — проверка палиндрома.** Сравниваем символы очищенной строки с начала и с конца, двигаясь к середине.

## 3. Очистка строки

```c
char s[102];
int n = 0;
int ch;

while ((ch = getchar()) != EOF && ch != '\n') {
    if (ch == ' ') {
        continue;
    }

    if (ch >= 'A' && ch <= 'Z') {
        s[n++] = (char)(ch - 'A' + 'a');
    } else if ((ch >= 'a' && ch <= 'z') || (ch >= '0' && ch <= '9')) {
        s[n++] = (char)ch;
    }
}
```

Что здесь происходит:

- `ch == ' '` — пробелы пропускаем через `continue`.
- `ch >= 'A' && ch <= 'Z'` — заглавная буква. Переводим в строчную: вычитаем код `'A'` и прибавляем код `'a'`. Разница между ними в ASCII постоянна, поэтому сдвиг работает для всех букв.
- `ch >= 'a' && ch <= 'z'` — строчная буква, сохраняем без изменений.
- `ch >= '0' && ch <= '9'` — цифра, сохраняем без изменений.

После цикла `n` содержит длину очищенной строки.

### Почему не используем `tolower` и `isalnum`

В некоторых заданиях экзамена функции из `<ctype.h>` запрещены. Ручная проверка через сравнение с диапазонами символов работает всегда и не требует дополнительных библиотек.

## 4. Проверка палиндрома

```c
int l = 0;
int r = n - 1;
int ok = 1;

while (l < r) {
    if (s[l] != s[r]) {
        ok = 0;
        break;
    }
    l++;
    r--;
}
```

Два указателя:

- `l` начинает с первого символа (индекс `0`);
- `r` начинает с последнего символа (индекс `n - 1`).

На каждом шаге сравниваем `s[l]` и `s[r]`. Если не совпали — строка не палиндром, выходим из цикла. Если совпали — сдвигаем оба указателя к центру.

Цикл останавливается, когда `l >= r`. Это значит, что мы проверили все пары.

### Почему достаточно проверить до середины

Каждая пара проверяется один раз. Когда указатели встречаются или пересекаются, все симметричные позиции уже сравнены.

Для строки `mammam` (длина 6):

| Шаг | `l` | `r` | `s[l]` | `s[r]` | Совпадение |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 5 | `m` | `m` | Да |
| 2 | 1 | 4 | `a` | `a` | Да |
| 3 | 2 | 3 | `m` | `m` | Да |

Все пары совпали — `YES`.

## 5. Пустая строка после фильтрации

Если исходная строка состояла только из пробелов, после очистки `n == 0`. В этом случае выводим `NO`:

```c
if (n == 0) {
    printf("NO");
    return 0;
}
```

## 6. Вывод результата

```c
printf("%s", ok ? "YES" : "NO");
```

Тернарный оператор `? :` выбирает строку:

- `ok == 1` → `"YES"`;
- `ok == 0` → `"NO"`.

Перенос строки не добавляем.

## 7. Алгоритм целиком

1. Читать символы до `'\n'`.
2. Пробелы пропускать.
3. Буквы и цифры копировать в массив, заглавные переводить в строчные.
4. Если массив пуст — вывести `NO`.
5. Сравнить символы с начала и с конца, двигаясь к середине.
6. При несовпадении — `NO`, при полном совпадении — `YES`.

## 8. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Не удалять пробелы | `Mam mam` даст `NO` вместо `YES` |
| Не приводить к одному регистру | `M` и `m` будут считаться разными |
| Использовать `scanf("%s", ...)` | Прочитается только первое слово до пробела |
| Сравнивать сырую строку без очистки | Пробелы и регистр сломают проверку |
| Забыть про пустую строку | Обращение к `s[-1]` при `n == 0` — неопределённое поведение |
| Добавить `\n` в вывод | Условие запрещает завершающий перенос |
| Выводить `1` / `0` вместо `YES` / `NO` | Формат ответа указан в условии |
