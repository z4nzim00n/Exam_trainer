# EXAM_08_01. Длина строки — теория

## 1. Что нужно посчитать

Длина строки — количество символов текста.

Учитываются:

- буквы;
- цифры;
- пробелы;
- знаки препинания.

Завершающий перевод строки не учитывается.

```text
Hello! → 6
a b c → 5
```

## 2. Как строка хранится в C

Строка хранится в массиве `char` и заканчивается специальным символом:

```c
'\0'
```

Его называют нулевым терминатором.

Для текста `cat` в памяти находится:

```text
'c' 'a' 't' '\0'
```

Терминатор не входит в длину текста.

Не путай:

- `'\0'` — конец строки в памяти;
- `'\n'` — перевод строки;
- `'0'` — обычная цифра ноль.

## 3. Почему массив имеет размер 102

```c
char text[102];
```

По условию во входе не более 100 символов текста.

Дополнительно может понадобиться место для:

- перевода строки `'\n'`;
- нулевого терминатора `'\0'`.

Итого:

```text
100 + 1 + 1 = 102
```

## 4. Чтение через fgets

```c
fgets(text, sizeof(text), stdin)
```

Функция:

- читает строку вместе с пробелами;
- записывает не более размера массива минус один символ;
- сохраняет перевод строки, если прочитала его;
- добавляет `'\0'` при успешном чтении.

`sizeof(text)` здесь равно размеру всего массива.

Если чтение не удалось или EOF встретился до первого символа, `fgets` возвращает `NULL`. Поэтому обращаться к массиву начинаем только после успешного чтения.

## 5. Алгоритм

1. Установить длину в `0`.
2. Прочитать строку.
3. Пока текущий символ не равен `'\0'` и `'\n'`, увеличивать длину.
4. Вывести длину.

```c
while (text[length] != '\0' && text[length] != '\n') {
    length++;
}
```

Здесь `length` одновременно является:

- количеством уже посчитанных символов;
- индексом следующего проверяемого символа.

## 6. Пошаговый пример

После чтения строки `a b` массив может содержать:

```text
Индекс:   0    1    2    3     4
Символ:  'a'  ' '  'b'  '\n'  '\0'
```

| Индекс | Символ | Действие |
| --- | --- | --- |
| `0` | `a` | Длина становится `1` |
| `1` | Пробел | Длина становится `2` |
| `2` | `b` | Длина становится `3` |
| `3` | `\n` | Останавливаемся |

Ответ — `3`.

Если перевода строки нет, цикл остановится на `'\0'`.

## 7. Частые ошибки

| Ошибка | Почему неправильно |
| --- | --- |
| Использовать `sizeof(text)` как длину строки | Это размер массива, а не длина введённого текста |
| Читать через `scanf("%s", ...)` | Будет прочитано только одно слово |
| Считать `'\n'` | Ответ станет больше на один |
| Считать `'\0'` | Терминатор не является частью текста |
| Проверять `'0'` вместо `'\0'` | Цифра ноль не обозначает конец строки |
| Читать массив после неудачного `fgets` | Его содержимое может быть неинициализированным |

Время работы — `O(n)`. Массив имеет фиксированный размер.
