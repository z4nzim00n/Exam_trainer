## EXAM_06_01. Длина строки

### Задание

| EXAM_08_01 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, символы, массивы, циклы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, определяющую длину строки.

Строка задаётся на стандартном потоке ввода stdin. Необходимо посчитать количество её символов и вывести результат на стандартный поток вывода stdout.

Пробелы, цифры и знаки препинания учитываются наравне с буквами. Символ перевода строки, завершающий ввод, в длину строки не входит.

В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ `'\n'` или конец ввода EOF.
- Строка может быть пустой. В этом случае вывести `0`.
- Пробелы в начале и конце строки также входят в её длину.
- Использовать функцию `strlen` запрещено.
- Можно использовать обычный массив `char`. Динамическая память не требуется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `Hello!` | `6` |
| `School21` | `8` |
| `Hello, World!` | `13` |
| `a b c` | `5` |

**Пример с пробелами по краям**

Входные данные — два пробела, буква `a` и два пробела:

```text
  a  
```

Результат работы:

```text
5
```

> **Внимание:** Процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
