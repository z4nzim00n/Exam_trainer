## EXAM_06_06. Подсчёт слов

### Задание

| EXAM_08_03 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, символы, циклы, условные операторы, флаги. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, подсчитывающую количество слов в строке.

Строка задаётся на стандартном потоке ввода stdin. Словом считается любая непустая последовательность символов между пробелами.

Соседние слова могут разделяться одним или несколькими пробелами. Пробелы в начале и конце строки не создают дополнительных слов.

Количество слов вывести на стандартный поток вывода stdout. В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ `'\n'` или конец ввода EOF.
- Единственным разделителем слов является обычный пробел `' '`. Табуляций во входных данных нет.
- Цифры и знаки препинания могут входить в состав слова.
- Например, `Hello,` считается одним словом, `123` — одним словом, а `a-b` — одним словом.
- Для пустой строки или строки только из пробелов вывести `0`.
- Можно использовать обычный массив `char`. Динамическая память не требуется.

### Примеры

**Пример 1**

Входные данные:

```text
Hello world
```

Результат работы:

```text
2
```

**Пример 2**

Входные данные:

```text
  Hello,   world!  
```

Результат работы:

```text
2
```

**Пример 3**

Входные данные:

```text
one two three
```

Результат работы:

```text
3
```

**Пример 4**

Входные данные:

```text
School21
```

Результат работы:

```text
1
```

**Пример 5**

Входные данные:

```text
123 + 456
```

Результат работы:

```text
3
```

> В последнем примере `+` также считается словом: по условию словом является любая непустая группа непробельных символов.
