# EXAM_08_03. Подсчёт слов — теория

## 1. Что считается словом

Слово — любая непустая группа символов между пробелами.

Поэтому:

```text
Hello, → одно слово
123 → одно слово
+ → одно слово
a-b → одно слово
```

Мы не проверяем смысл текста и не выделяем только буквенные слова.

## 2. Почему нельзя просто посчитать пробелы

Формула «количество пробелов плюс один» работает не всегда.

Например:

```text
  Hello   world  
```

Пробелов много, но слов только два.

Пустая строка вообще не содержит слов.

Надёжнее считать не разделители, а начала слов.

## 3. Флаг состояния

```c
int in_word = 0;
```

Он показывает, где мы находимся:

- `0` — вне слова;
- `1` — внутри слова, которое уже посчитано.

Начальное состояние — вне слова.

При чтении пробела устанавливаем:

```c
in_word = 0;
```

При чтении непробельного символа:

- если уже внутри слова — ничего не меняем;
- если вне слова — нашли новое слово.

## 4. Как распознать начало слова

```c
else if (!in_word) {
    words++;
    in_word = 1;
}
```

Оператор `!` означает логическое отрицание.

Для нашего флага:

```text
!0 → 1
!1 → 0
```

Условие `!in_word` истинно, когда мы ещё не внутри слова.

После увеличения счётчика включаем флаг, чтобы следующие символы того же слова не считались новыми словами.

## 5. Чтение строки

```c
char text[102];
```

Размер учитывает 100 символов текста, возможный `'\n'` и терминатор `'\0'`.

```c
fgets(text, sizeof(text), stdin)
```

Читает строку вместе с пробелами.

Цикл проходит до `'\n'` или `'\0'`:

```c
for (int i = 0; text[i] != '\0' && text[i] != '\n'; i++) {
    /* Проверка символа. */
}
```

При неудачном чтении счётчик остаётся нулевым.

## 6. Алгоритм

1. Установить количество слов и флаг в `0`.
2. Прочитать строку.
3. Перебрать символы.
4. На пробеле выключить флаг.
5. На непробельном символе при выключенном флаге:
    - увеличить количество слов;
    - включить флаг.
6. Вывести количество слов.

## 7. Пошаговый пример

Вход:

```text
 a  bc 
```

| Символ | Действие | `in_word` | Слов |
| --- | --- | --- | --- |
| Пробел | Остаёмся вне слова | `0` | `0` |
| `a` | Начало слова | `1` | `1` |
| Пробел | Выходим из слова | `0` | `1` |
| Пробел | Остаёмся вне слова | `0` | `1` |
| `b` | Начало слова | `1` | `2` |
| `c` | Продолжение слова | `1` | `2` |
| Пробел | Выходим из слова | `0` | `2` |

Ответ — `2`.

Последнее слово не требует отдельной обработки после цикла: оно было посчитано в момент начала.

Время работы — `O(n)`, массив имеет фиксированный размер.

## 8. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Считать пробелы и прибавлять один | Неверный ответ при повторных и крайних пробелах |
| Увеличивать счётчик на каждой букве | Получится количество символов, а не слов |
| Не выключать флаг на пробеле | Посчитается только первое слово |
| Не включать флаг после начала слова | Каждый непробельный символ станет новым словом |
| Считать только буквенные группы | Потеряются слова из цифр и пунктуации |
| Прибавлять слово после цикла | Последнее слово может посчитаться дважды |
