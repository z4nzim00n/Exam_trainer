# EXAM_06_16. Идентификатор — теория

## 1. С чего начать

Нужно проверить, является ли строка идентификатором (как имя переменной в C).

Правила:

1. Первый символ: латинская буква (любой регистр) или `_`.
2. Остальные символы: латинские буквы, цифры или `_`.
3. Никаких других символов (пробелов, `-`, `.` и т. д.).
4. Пустая строка идентификатором не является.

```text
my_var1  -> Yes
1abc     -> No   (начинается с цифры)
a-b      -> No   (символ '-')
_        -> Yes
(пусто)  -> No
```

Длина строки не превышает 100 символов, ввод заканчивается `'\n'` или EOF.

## 2. Как решать задачу по шагам

1. Прочитать строку через `fgets`.
2. Если строка пустая — сразу ответ `No`.
3. Пройти по символам до `'\n'` или `'\0'`.
4. Если цифра стоит на первом месте или встретился недопустимый символ — ответ `No`.
5. Если нарушений нет — `Yes`.

## 3. Как прочитать строку

```c
char str[102];

if (fgets(str, sizeof str, stdin) != NULL && str[0] != '\n') {
    /* строка непустая — можно проверять */
}
```

Буфер на 102 байта: 100 символов строки, `'\n'` и завершающий `'\0'`.

`fgets` читает всю строку вместе с пробелами. Это важно: `scanf("%s", ...)` остановился бы на первом пробеле и не заметил бы его внутри строки.

Проверка `str[0] != '\n'` отсекает пустую строку: если пользователь сразу нажал Enter, `fgets` вернёт строку `"\n"`, и она не должна считаться идентификатором.

## 4. Один флаг на два смысла

Заводим флаг `is_identifier`:

- `0` — пока не доказано, что строка подходит;
- `1` — строка непустая и пока нарушений не найдено.

```c
int is_identifier = 0;

if (fgets(str, sizeof str, stdin) != NULL && str[0] != '\n') {
    is_identifier = 1;
    /* проверка символов */
}
```

Для пустого ввода `if` не выполнится, флаг останется `0`, и программа выведет `No`.

## 5. Как проверить символ

Для каждого символа вычисляем три признака:

```c
int letter = (str[i] >= 'a' && str[i] <= 'z') || (str[i] >= 'A' && str[i] <= 'Z');
int number = str[i] >= '0' && str[i] <= '9';
int under = str[i] == '_';
```

Дальше проверяем **ошибки**, а не «допустимость»:

```c
if (!letter && !under && !(number && i != 0)) {
    is_identifier = 0;
    break;
}
```

Условие читается так: символ плохой, если он одновременно:

- не буква;
- не подчёркивание;
- не цифра, стоящая не на первом месте.

То есть буква и `_` разрешены на любой позиции, цифра — только не на первой.

### Почему проверяем плохое, а не хорошее

Запись «символ хороший, если буква ИЛИ `_` ИЛИ цифра не в начале» тоже возможна, но в ней легко перепутать `i == 0` и `i != 0`. Проверка ошибки короче и сразу отсекает всё лишнее.

### Почему сравнения идут по диапазонам

В ASCII буквы `a`-`z`, `A`-`Z` и цифры `0`-`9` идут подряд, поэтому проверка `c >= 'a' && c <= 'z'` покрывает все строчные буквы. Функции из `<ctype.h>` не нужны.

## 6. Алгоритм целиком

1. Объявить `str[102]` и `is_identifier = 0`.
2. Прочитать строку через `fgets`; если ввода нет или первый символ `'\n'` — оставить флаг `0`.
3. Иначе поставить флаг `1` и пройти по символам до `'\n'` или `'\0'`.
4. Для каждого символа вычислить `letter`, `number`, `under`.
5. Если цифра стоит на позиции `0` или символ не подходит ни под один признак — поставить `0` и выйти из цикла.
6. Вывести `Yes`, если флаг равен `1`, иначе `No`.

## 7. Пошаговый разбор

### `my_var1`

| `i` | `str[i]` | letter | number | under | Ошибка? |
| --- | --- | --- | --- | --- | --- |
| 0 | `m` | 1 | 0 | 0 | нет |
| 1 | `y` | 1 | 0 | 0 | нет |
| 2 | `_` | 0 | 0 | 1 | нет |
| 3-5 | `var` | 1 | 0 | 0 | нет |
| 6 | `1` | 0 | 1 | 0 | нет (`i != 0`) |

Ошибок нет, вывод: `Yes`.

### `1abc`

| `i` | `str[i]` | letter | number | under | Ошибка? |
| --- | --- | --- | --- | --- | --- |
| 0 | `1` | 0 | 1 | 0 | **да** (цифра первая) |

`is_identifier = 0`, `break`, вывод: `No`.

### `a-b`

| `i` | `str[i]` | letter | number | under | Ошибка? |
| --- | --- | --- | --- | --- | --- |
| 0 | `a` | 1 | 0 | 0 | нет |
| 1 | `-` | 0 | 0 | 0 | **да** (недопустимый символ) |

Вывод: `No`.

## 8. Особые случаи

| Ввод | Результат | Почему |
| --- | --- | --- |
| пустая строка | `No` | `if` не выполнился, флаг остался `0` |
| `_` | `Yes` | подчёркивание допустимо первым |
| `___` | `Yes` | только подчёркивания |
| `a` | `Yes` | одна буква |
| `7` | `No` | цифра на первой позиции |
| `a1` | `Yes` | цифра не на первой позиции |
| `a b` | `No` | пробел недопустим |
| `a-b` | `No` | дефис недопустим |
| `Abc_9` | `Yes` | регистр не важен |
| последняя строка без `'\n'` | работает как обычно | цикл остановится на `'\0'` |

## 9. Почему решение работает

- `fgets` читает всю строку целиком, включая пробелы.
- Цикл проверки смотрит каждый символ ровно один раз и снимает флаг при первом нарушении.
- Одно условие ошибки покрывает все запрещённые случаи: цифра в начале и любой символ вне набора «буква, цифра, `_`».
- Пустая строка отсекается до цикла проверки.

Время работы `O(n)`, память: один массив на 102 байта, динамической памяти нет, утечек быть не может.

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Не проверить `fgets` на `NULL` | При пустом вводе массив не заполнен, читать его нельзя |
| Не проверить `str[0] != '\n'` | Пустая строка получит `Yes` |
| Объявить `is_identifier = 1` сразу | Пустая строка даст `Yes`, а нужно `No` |
| Не проверить цифру в начале | `1abc` будет принят |
| Забыть `_` | `my_var1` будет отвергнут |
| Забыть про заглавные буквы | `MyVar` будет отвергнут |
| `printf("Yes\n")` | Условие запрещает завершающий перенос строки |
| Писать `yes`, `YES` | Нужно ровно `Yes` и `No` |
| `scanf("%s")` | Остановится на пробеле и не заметит его в строке `a b` |
| Писать `i > 0` там, где нужно `i == 0` | Правило ошибки и правило допустимости записываются противоположно |
| Не выйти из цикла после ошибки | Работает, но лишний перебор |
