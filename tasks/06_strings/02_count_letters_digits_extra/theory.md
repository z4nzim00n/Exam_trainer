# EXAM_08_02. Подсчёт букв и цифр — теория

## 1. Что нужно посчитать

Нужны два независимых результата:

- сколько в строке латинских букв;
- сколько в строке цифр.

Заглавные и строчные буквы учитываются вместе.

```text
School21! → 6 2
```

Знак `!` не относится ни к одной из нужных групп.

## 2. Подготовка

```c
char text[102];
int letters = 0;
int digits = 0;
```

Массив вмещает:

- 100 символов текста;
- возможный перевод строки;
- нулевой терминатор.

Счётчики начинаются с нуля: пока ни одного символа не обработано.

## 3. Как прочитать строку

```c
fgets(text, sizeof(text), stdin)
```

В отличие от `scanf("%s", ...)`, эта функция сохраняет пробелы и читает всю строку в пределах буфера.

При успешном чтении массив заканчивается `'\0'`. Если был прочитан `'\n'`, он тоже находится в массиве.

Поэтому цикл останавливается на любом из этих символов:

```c
for (int i = 0; text[i] != '\0' && text[i] != '\n'; i++) {
    /* Обработка text[i]. */
}
```

## 4. Проверка буквы

В ASCII латинские буквы образуют два отдельных диапазона:

```text
A ... Z
a ... z
```

Проверка:

```c
(ch >= 'A' && ch <= 'Z') || (ch >= 'a' && ch <= 'z')
```

Внутри диапазона используется `&&`: обе границы должны выполняться.

Между диапазонами используется `||`: достаточно принадлежать любому из них.

Нельзя проверять просто `'A'..'z'`, потому что между `Z` и `a` в ASCII находятся знаки препинания.

## 5. Проверка цифры

```c
ch >= '0' && ch <= '9'
```

Здесь сравниваются символы цифр, а не числовые значения от 0 до 9.

Запись `123` содержит три символа:

```text
'1' '2' '3'
```

Поэтому счётчик цифр увеличится три раза.

Буква не может одновременно быть цифрой, поэтому удобно использовать `else if`.

## 6. Алгоритм и пример

1. Прочитать строку.
2. Перебрать её символы.
3. Для буквы увеличить `letters`.
4. Иначе для цифры увеличить `digits`.
5. Остальные символы пропустить.
6. Вывести счётчики через один пробел.

Для строки:

```text
A2 !
```

| Символ | Буквы | Цифры |
| --- | --- | --- |
| `A` | `1` | `0` |
| `2` | `1` | `1` |
| Пробел | `1` | `1` |
| `!` | `1` | `1` |

Ответ:

```text
1 1
```

Время работы — `O(n)`, массив имеет фиксированный размер.

## 7. Частые ошибки

| Ошибка | Почему неправильно |
| --- | --- |
| Проверять буквы диапазоном `'A'..'z'` | В него входят некоторые знаки препинания |
| Сравнивать символ с `0` и `9` без кавычек | Это не коды символов `'0'` и `'9'` |
| Считать запись `123` одной цифрой | Требуется количество цифровых символов |
| Забыть инициализацию счётчиков | Получатся неопределённые значения |
| Использовать `&&` между двумя буквенными диапазонами | Символ не может одновременно находиться в обоих |
| Выводить поясняющий текст | Нужны только два числа |
