## EXAM_08_02. Подсчёт букв и цифр

### Задание

| EXAM_08_02 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Строки, символы, циклы, условные операторы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, подсчитывающую количество латинских букв и количество цифр в строке.

Строка задаётся на стандартном потоке ввода stdin.

Необходимо вывести на стандартный поток вывода stdout два целых числа через один пробел:

1. Количество латинских букв.
2. Количество цифр.

Заглавные и строчные латинские буквы учитываются вместе. Пробелы и знаки препинания не учитываются.

В конце ответа не должно быть пробела или переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Строка содержит не более 100 печатных символов ASCII: латинские буквы, цифры, пробелы и знаки препинания.
- Концом строки является символ `'\n'` или конец ввода EOF.
- Буквами считаются символы от `'A'` до `'Z'` и от `'a'` до `'z'`.
- Цифрами считаются символы от `'0'` до `'9'`.
- Каждая цифра учитывается отдельно: запись `123` содержит три цифры.
- Для пустой строки вывести `0 0`.
- Проверки символов необходимо реализовать самостоятельно, без функций библиотеки `<ctype.h>`.
- Можно использовать обычный массив `char`. Динамическая память не требуется.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `School21!` | `6 2` |
| `Hello, World!` | `10 0` |
| `12345` | `0 5` |
| `a1 B2 c3!` | `3 3` |
| `!? --` | `0 0` |

> **Внимание:** Процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
