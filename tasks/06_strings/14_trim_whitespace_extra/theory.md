# EXAM_06_14. Удаление лишних пробелов и табуляций — теория

## 1. С чего начать

Задача похожа на обычное удаление лишних пробелов, но с одним отличием: **между словами может стоять не только пробел, но и табуляция** (символ `'\t'`).

Например:

```text
   test   sample test	text
```

Между `test` и `text` стоит табуляция. В результате нужно получить:

```text
test sample test text
```

Все разделители — и пробелы, и табуляции — в выводе становятся **одним обычным пробелом**.

Правила те же:

- удалить все пробельные символы в начале строки;
- заменить любую последовательность пробельных символов внутри строки одним пробелом;
- удалить все пробельные символы в конце строки;
- остальные символы сохранить.

## 2. Что такое пробельный символ

В этой задаче пробельными считаются два символа:

- обычный пробел `' '` — код 32 в ASCII;
- табуляция `'\t'` — код 9 в ASCII.

В коде мы объединяем их одной проверкой:

```c
if (ch == ' ' || ch == '\t') {
    /* Пробельный символ. */
}
```

Оператор `||` означает «ИЛИ». Условие истинно, если `ch` — пробел или табуляция.

## 3. Почему нельзя выводить пробел сразу

Представим, что программа прочитала:

```text
hello   
```

Три пробела. Что делать с ними?

- Если после них будет `world` — нужно вывести один пробел.
- Если строка закончится — пробелы выводить нельзя.

Пока мы не знаем, что будет дальше, вывести пробел мы не можем.

**Решение:** запоминаем, что «встретился разделитель», но выводим его только тогда, когда появится следующий непробельный символ.

## 4. Два флага

Нам достаточно двух флагов:

```c
int has_text = 0;
int pending_space = 0;
```

- `has_text` — был ли уже выведен хотя бы один непробельный символ.
- `pending_space` — есть ли отложенный разделитель, который нужно вывести перед следующим непробельным символом.

Эти два флага полностью описывают состояние программы.

### Начало строки

Оба флага равны `0`. Пробельные символы игнорируются:

```c
if (ch == ' ' || ch == '\t') {
    if (has_text) {
        pending_space = 1;
    }
    /* Иначе — просто пропускаем. */
}
```

`has_text == 0`, поэтому вложенный `if` не сработает. Пробельные символы в начале «испаряются».

### Первый непробельный символ

Появляется, например, буква `h`. Условие `ch == ' ' || ch == '\t'` ложно, попадаем в `else`:

```c
if (pending_space) {
    putchar(' ');
    pending_space = 0;
}
putchar(ch);
has_text = 1;
```

`pending_space == 0`, пробел не выводим. Выводим `h` и ставим `has_text = 1`.

### Пробельные символы между словами

Идут после текста. `has_text == 1`, поэтому:

```c
if (has_text) {
    pending_space = 1;
}
```

Флаг устанавливается. Если пробельных символов несколько подряд — флаг просто остаётся равным `1`, ничего не меняется.

Это важное свойство: **не важно, сколько подряд пробелов, табуляций или их смеси** — все они превращаются в один отложенный разделитель.

### Следующее слово

При первом непробельном символе после разделителей:

```c
if (pending_space) {
    putchar(' ');   /* Всегда обычный пробел. */
    pending_space = 0;
}
putchar(ch);
```

Выводим ровно один обычный пробел, даже если во входе стояла табуляция или их смесь. Затем выводим символ слова.

### Пробельные символы в конце строки

После них не появится непробельный символ — цикл закончится по `'\n'` или EOF.

`pending_space` останется равным `1`, но код после цикла его не проверяет. Отложенный разделитель просто игнорируется.

Именно так конечные пробельные символы «испаряются».

## 5. Полное решение

```c
#include <stdio.h>

int main(void) {
    int ch;
    int has_text = 0;
    int pending_space = 0;

    while ((ch = getchar()) != EOF && ch != '\n') {
        if (ch == ' ' || ch == '\t') {
            if (has_text) {
                pending_space = 1;
            }
        } else {
            if (pending_space) {
                putchar(' ');
                pending_space = 0;
            }
            putchar(ch);
            has_text = 1;
        }
    }

    return 0;
}
```

Всё умещается в один цикл. Массив не нужен, длина строки не ограничена алгоритмом.

## 6. Что понадобится из C

### Чтение символа

```c
ch = getchar();
```

Функция `getchar()` из `<stdio.h>` читает один символ из стандартного потока ввода.

В отличие от `scanf("%s", ...)`, она не пропускает пробельные символы. Для этой задачи важно видеть каждый из них.

### Почему для символа используется `int`

`getchar()` возвращает:

- код прочитанного символа;
- либо специальное значение `EOF`.

Чтобы корректно различать символы и `EOF`, результат сохраняют в `int`, а не в `char`.

### Символьные литералы

| Запись | Значение |
| --- | --- |
| `' '` | Обычный пробел |
| `'\t'` | Табуляция |
| `'\n'` | Перевод строки |

Одинарные кавычки — символьные литералы. Двойные — строки:

```c
' '   /* Символ. */
" "   /* Строка. */
```

### Вывод символа

```c
putchar(ch);
```

Функция выводит один символ. Сама по себе не добавляет перевод строки.

Для вывода одного пробела:

```c
putchar(' ');
```

## 7. Пошаговый разбор

Вход (`·` — пробел, `→` — табуляция, `¶` — перевод строки):

```text
··a··→b·¶
```

| Прочитано | Действие | `has_text` | `pending_space` | Вывод |
| --- | --- | --- | --- | --- |
| `·` | Начальный пробел, игнорируем | 0 | 0 | пусто |
| `·` | Начальный пробел, игнорируем | 0 | 0 | пусто |
| `a` | Выводим | 1 | 0 | `a` |
| `·` | Запоминаем разделитель | 1 | 1 | `a` |
| `·` | Флаг уже установлен | 1 | 1 | `a` |
| `→` | Табуляция — тот же флаг | 1 | 1 | `a` |
| `b` | Выводим пробел, потом `b` | 1 | 0 | `a b` |
| `·` | Запоминаем разделитель | 1 | 1 | `a b` |
| `¶` | Завершаем цикл | 1 | 1 | `a b` |

Отложенный разделитель в конце не выводится. Результат:

```text
a b
```

## 8. Отличие от базовой версии (06_07)

Базовая версия задачи проверяла только пробелы:

```c
if (ch == ' ') { ... }
```

Здесь мы добавили табуляцию:

```c
if (ch == ' ' || ch == '\t') { ... }
```

И на выход всегда пишем обычный пробел:

```c
putchar(' ');
```

Всё остальное — та же логика с двумя флагами.

## 9. Почему решение работает

- **Начальные пробельные символы удаляются:** пока `has_text == 0`, они игнорируются.
- **Повторные разделители схлопываются:** любое их количество представлено одним флагом `pending_space`.
- **Конечные разделители удаляются:** отложенный флаг никогда не приводит к выводу, если после него не появился непробельный символ.
- **Между словами всегда один пробел:** `putchar(' ')` жёстко зафиксирован.
- **Табуляции превращаются в пробелы:** независимо от того, что запомнилось в `pending_space`, выводится `' '`.

Время работы — `O(n)`, где `n` — длина строки. Дополнительная память — константа.

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Проверять только `ch == ' '` | Табуляции останутся в выводе или сломают логику |
| Выводить `putchar(ch)` для табуляции | На выходе окажется `\t` вместо пробела |
| Не сбрасывать `pending_space` | Пробел появится перед каждым символом слова |
| Устанавливать `pending_space` до первого текста | Появится начальный пробел |
| Считать пробелы отдельно | Много подряд идущих не схлопнутся |
| Читать через `scanf("%s", ...)` | Прочитается только первое слово |
| Добавить `\n` в конце | Условие запрещает завершающий перенос |
