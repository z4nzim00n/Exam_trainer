## EXAM_06_07. Удаление лишних пробелов

### Задание

| EXAM_06_07                  ||
|-----------------------------| ------- |
| **Уровень:**                | 2 |
| **Темы:**                   | Символы, строки, циклы, условные операторы. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Написать программу, убирающую лишние пробелы из строки. Несколько подряд идущих пробелов должны быть заменены одним пробелом.

Строка поступает через стандартный поток ввода stdin. Концом строки является символ перевода строки `'\n'` или конец ввода EOF.

Результат вывести на стандартный поток вывода stdout. В конце ответа не должно быть пробела или переноса на новую строку.

## Уточнения

- Под пробелом понимается обычный символ `' '`.
- Пробелы в начале и конце строки удаляются.
- Внутри текста серии пробелов схлопываются в один.
- Остальные символы, включая цифры и знаки препинания, изменять нельзя.
- Строка может быть пустой или состоять только из пробелов. В этих случаях программа ничего не выводит.

## Примеры

Входные данные:

```text
1    2    3    4    5
```

Результат работы:

```text
1 2 3 4 5
```
