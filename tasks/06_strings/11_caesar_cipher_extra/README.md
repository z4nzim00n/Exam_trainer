## EXAM_06_11. Шифр Цезаря

### Задание

| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, шифрующую строку с помощью шифра Цезаря.

В первой строке входных данных задаётся целое число K — величина сдвига. Во второй строке задаётся текст.

Каждую латинскую букву необходимо заменить буквой, расположенной на K позиций дальше в алфавите. После последней буквы алфавита отсчёт продолжается с первой.

Регистр букв должен сохраняться:

- маленькие буквы заменяются маленькими;
- большие буквы заменяются большими.

Все остальные символы, включая пробелы, цифры и знаки препинания, необходимо вывести без изменений.

Результат вывести на стандартный поток вывода stdout. В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Гарантируется, что K — целое число от `0` до `25` включительно.
- Первая строка содержит только число K и завершающий перевод строки.
- Текст состоит из печатных символов ASCII.
- Концом текста является символ `'\n'` или конец ввода EOF.
- Текст может быть пустым. В этом случае программа ничего не выводит.
- Требуется только шифрование. Реализовывать расшифровку не нужно.

Например, при сдвиге `3`:

```text
a → d
x → a
Z → C
```

### Примеры

**Пример 1**

Входные данные:

```text
3
Hello, World!
```

Результат работы:

```text
Khoor, Zruog!
```

**Пример 2**

Входные данные:

```text
1
xyz XYZ 123
```

Результат работы:

```text
yza YZA 123
```

**Пример 3**

Входные данные:

```text
0
School21
```

Результат работы:

```text
School21
```
