# EXAM_07_02. Шифр Цезаря — теория

## 1. Что нужно сделать

Каждую латинскую букву нужно сдвинуть по алфавиту на заданное количество позиций.

При сдвиге `3`:

```text
a → d
b → e
x → a
y → b
z → c
```

Заглавные буквы остаются заглавными. Пробелы, цифры и знаки препинания не меняются.

## 2. Нужно ли хранить строку

Нет. Преобразование одного символа не зависит от остальных.

Можно читать символ, при необходимости менять его и сразу выводить.

Для этого достаточно переменных:

```c
int shift;
int ch;
```

`ch` имеет тип `int`, потому что `getchar()` возвращает код символа или специальное значение EOF.

## 3. Как устроена формула

Для строчной буквы:

```c
ch = 'a' + (ch - 'a' + shift) % 26;
```

Разберём её по частям.

### Получаем номер буквы

```c
ch - 'a'
```

В ASCII латинские буквы расположены подряд:

```text
a → 0
b → 1
...
z → 25
```

### Прибавляем сдвиг

```c
ch - 'a' + shift
```

Номер может выйти за пределы `0..25`.

### Возвращаемся в алфавит

```c
(ch - 'a' + shift) % 26
```

Остаток от деления на `26` обеспечивает переход от конца алфавита к его началу.

### Получаем символ

Прибавляем `'a'` и превращаем номер обратно в код буквы.

Для заглавных букв используется та же формула, но с `'A'`.

## 4. Особенность ввода

Сначала читаем число:

```c
scanf("%d", &shift);
```

После этого перевод строки остаётся во входном потоке.

По условию сразу после числа находится `'\n'`, поэтому его можно забрать одним вызовом:

```c
getchar();
```

Только после этого начинается чтение текста:

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    /* Преобразование символа. */
}
```

Один вызов `getchar()` подходит именно благодаря гарантированному формату первой строки.

## 5. Алгоритм

1. Прочитать сдвиг.
2. Прочитать оставшийся после числа перевод строки.
3. Читать текст посимвольно.
4. Строчные буквы сдвигать внутри диапазона `'a'..'z'`.
5. Заглавные буквы сдвигать внутри диапазона `'A'..'Z'`.
6. Выводить каждый полученный символ.
7. Остановиться на `'\n'` или EOF, не добавляя перенос строки.

## 6. Пошаговый пример

Сдвиг:

```text
3
```

Текст:

```text
Az!
```

| Символ | Вычисление | Результат |
| --- | --- | --- |
| `A` | `(0 + 3) % 26 = 3` | `D` |
| `z` | `(25 + 3) % 26 = 2` | `c` |
| `!` | Не является буквой | `!` |

Вывод:

```text
Dc!
```

Время работы — `O(n)`, дополнительная память — `O(1)`.

## 7. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Просто прибавить сдвиг к символу | После `z` получатся не буквы начала алфавита |
| Забыть `% 26` | Не будет циклического перехода |
| Обрабатывать большие и маленькие буквы вместе | Нарушится регистр |
| Менять все символы | Изменятся пробелы, цифры и пунктуация |
| Не убрать перевод строки после числа | Цикл сразу завершится |
| Использовать `scanf("%s", ...)` | Прочитается только одно слово |
