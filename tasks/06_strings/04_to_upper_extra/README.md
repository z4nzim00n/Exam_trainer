## EXAM_06_04. Перевод в верхний регистр

### Задание

| EXAM_07_04 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Символы, строки, условные операторы, регистр букв. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, переводящую все строчные латинские буквы входной строки в заглавные.

Например:

```text
a → A
b → B
z → Z
```

Заглавные латинские буквы, цифры, пробелы и знаки препинания необходимо оставить без изменений.

Строка поступает через стандартный поток ввода stdin. Концом строки является символ перевода строки `'\n'` или конец ввода EOF.

Результат вывести на стандартный поток вывода stdout. В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Строка состоит из печатных символов ASCII.
- Необходимо самостоятельно реализовать преобразование регистра. Использовать функции библиотеки `<ctype.h>`, включая `toupper`, запрещено.
- Пробелы сохраняются в исходном количестве и на исходных местах.
- Строка может быть пустой. В этом случае программа ничего не выводит.
- Хранить всю строку в массиве необязательно.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `Hello, World! Im Student School21` | `HELLO, WORLD! IM STUDENT SCHOOL21` |
| `ABC xyz 123!` | `ABC XYZ 123!` |
| `ALREADY UPPERCASE` | `ALREADY UPPERCASE` |
| `school21` | `SCHOOL21` |
