# EXAM_07_04. Перевод в верхний регистр — теория

## 1. Что требуется

Нужно заменить все строчные латинские буквы заглавными:

```text
a → A
b → B
...
z → Z
```

Заглавные буквы, пробелы, цифры и знаки препинания сохраняются.

Например:

```text
Hello, World! → HELLO, WORLD!
```

## 2. Как определить строчную букву

По условию символы относятся к ASCII. Строчные латинские буквы расположены в этой кодировке подряд.

Проверка:

```c
ch >= 'a' && ch <= 'z'
```

Она истинна только для символов от `'a'` до `'z'` включительно.

Нужен оператор `&&`: символ должен одновременно удовлетворять нижней и верхней границе.

## 3. Как изменить регистр

```c
ch = ch - 'a' + 'A';
```

Сначала получаем номер буквы:

```text
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
```

Затем прибавляем этот номер к `'A'`:

```text
'A' + 0 = 'A'
'A' + 1 = 'B'
'A' + 2 = 'C'
```

Так сохраняется позиция буквы в алфавите, но меняется регистр.

Преобразование выполняется только после проверки диапазона.

## 4. Алгоритм

1. Читать символы по одному.
2. Завершить чтение на `'\n'` или EOF.
3. Если символ — строчная латинская буква, преобразовать его.
4. Вывести символ.
5. Повторять до конца строки.

Каждый символ независим от остальных. Хранить строку в массиве не требуется.

## 5. Чтение и вывод в C

```c
int ch;
```

Используем `int`, потому что результат `getchar()` должен вмещать как код символа, так и EOF.

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    /* Обработка. */
}
```

`getchar()` не пропускает пробелы. Это позволяет сохранить их в исходном количестве.

```c
putchar(ch);
```

Выводит один символ без дополнительных пробелов и переносов.

Функцию `toupper` использовать нельзя: преобразование реализуем самостоятельно.

## 6. Пошаговый пример

Вход:

```text
z-A1
```

| Символ | Действие | Результат |
| --- | --- | --- |
| `z` | Позиция 25 переносится в заглавный диапазон | `Z` |
| `-` | Не строчная буква | `-` |
| `A` | Уже заглавная | `A` |
| `1` | Цифра | `1` |

Вывод:

```text
Z-A1
```

Пустой ввод даёт пустой вывод.

Время работы — `O(n)`, дополнительная память — `O(1)`.

## 7. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Использовать формулу без проверки диапазона | Изменятся небуквенные символы |
| Прибавлять разницу регистров вместо вычитания | Получатся неверные символы |
| Использовать `||` в проверке диапазона | Проверка будет пропускать лишние символы |
| Читать только одно слово | Потеряется оставшаяся часть строки |
| Убирать повторные пробелы | Это не требуется условием |
| Выводить завершающий перевод строки | Нарушится формат ответа |
