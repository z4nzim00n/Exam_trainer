## EXAM_06_15. Идентификатор

### Задание
| EXAM_06_15                  ||
|-----------------------------| ------- |
| **Уровень:**                | 3 |
| **Темы:**                   | Строки. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Написать программу, которая проверяет, что введённая через стандартный ввод stdin строка, заканчивающаяся символом новой строки «\n», является идентификатором. Идентификатор должен начинаться с латинской буквы в любом регистре или со знака нижнего подчёркивания, а также не содержать других символов, кроме букв латинского алфавита, цифр и знака подчёркивания. Программа должна выводить на стандартный поток вывода stdout строку «Yes», если строка является идентификатором, и «No» в противном случае. В конце ответа не должно быть переноса на новую строку.

Примечание: длина входной строки не превышает 100 символов.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| my_var1 | Yes |
| 1abc | No |
