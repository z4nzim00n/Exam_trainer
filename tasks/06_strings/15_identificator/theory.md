# EXAM_06_15. Идентификатор — теория

## 1. С чего начать

Нужно проверить, что строка - корректное имя (как имя переменной в C):
- первый символ: латинская буква или `_`;
- остальные символы: латинская буква, цифра или `_`;
- пустая строка идентификатором не является.

## 2. Чтение строки

Читаем по одному символу в массив, как в других строковых задачах:

```c
char s[102];
int n = 0;
int ch;

while ((ch = getchar()) != EOF && ch != '\n') {
    s[n++] = (char)ch;
}
```

`getchar()` возвращает `int`, а не `char`: нужно отличать символ от `EOF`.

## 3. Как проверить символ без ctype.h

В таблице ASCII буквы и цифры идут подряд, поэтому хватает сравнений:

```c
(s[i] >= 'a' && s[i] <= 'z') || (s[i] >= 'A' && s[i] <= 'Z')   // буква
s[i] >= '0' && s[i] <= '9'                                      // цифра
s[i] == '_'                                                     // подчёркивание
```

## 4. Одно правило на все позиции

Вместо отдельной проверки первого символа запоминаем простое правило:
- буква и `_` подходят **везде**;
- цифра подходит **везде, кроме `i == 0`**.

```c
if (!(letter || s[i] == '_' || (digit && i > 0))) {
    ok = 0;
    break;
}
```

## 5. Пустая строка

`int ok = n > 0;` - если символов нет, `ok` сразу 0, и цикл не меняет результат.

## 6. Вывод

```c
printf("%s", ok ? "Yes" : "No");
```

Без `\n` в конце.

## 7. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Разрешить цифру первым символом | `1abc` - не идентификатор |
| Написать `char ch = getchar()` | Нельзя надёжно сравнить с `EOF` |
| `printf("Yes\n")` | Лишний перенос строки в конце ответа |
| Забыть про пустую строку | Пустая строка - это `No` |
| `isalpha` на символах вне ASCII | Неопределённое поведение при отрицательном `char` |
