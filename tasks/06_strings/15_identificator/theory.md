# EXAM_06_15
# Идентификатор — теория

## 1. С чего начать

Нужно проверить, является ли строка идентификатором (как имя переменной в C).

Правила:

1. Первый символ: латинская буква (любой регистр) или `_`.
2. Остальные символы: латинские буквы, цифры или `_`.
3. Никаких других символов (пробелов, `-`, `.` и т. д.).
4. Пустая строка идентификатором не является.

```text
my_var1  -> Yes
1abc     -> No   (начинается с цифры)
a-b      -> No   (символ '-')
_        -> Yes
(пусто)  -> No
```

## 2. Как решать задачу по шагам

1. Прочитать строку через `getchar()` до `'\n'` или EOF.
2. Запомнить, прочитан ли хотя бы один символ.
3. Пройти по символам и проверить каждый по правилам.
4. Вывести `Yes` или `No` без `'\n'` в конце.

## 3. Как прочитать строку

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    s[n++] = ch;
    is_identifier = 1;
}
```

- `ch` имеет тип `int`: `getchar()` возвращает код символа или `EOF`, и в `char` их нельзя надёжно различить.
- `s[n++] = ch;` записывает символ и увеличивает длину. Сначала используется старое `n`, потом оно растёт.
- `is_identifier = 1;` включается на первой итерации: если цикл хоть раз выполнился, строка непустая.
- Массив `s` мы не используем как C-строку, поэтому `'\0'` в конец не пишем. Длина хранится в `n`.

## 4. Один флаг на два смысла

Переменная `is_identifier` работает как ответ «пока всё хорошо»:

| Момент | Значение | Смысл |
| --- | --- | --- |
| до чтения | `0` | ничего нет |
| после чтения непустой строки | `1` | строка есть, можно проверять |
| нашли плохой символ | `0` | не идентификатор |

Для пустой строки цикл чтения не выполняется, флаг остаётся `0`, и цикл проверки (`i < n`, где `n = 0`) тоже не запускается. Результат: `No`.

## 5. Как проверить символ

```c
int letter = (s[i] >= 'a' && s[i] <= 'z') || (s[i] >= 'A' && s[i] <= 'Z');
int digit = s[i] >= '0' && s[i] <= '9';

if (!(letter || s[i] == '_' || (digit && i > 0))) {
    is_identifier = 0;
    break;
}
```

Символ допустим, если выполняется **хотя бы одно**:

| Условие | Где разрешено |
| --- | --- |
| `letter` | на любой позиции |
| `s[i] == '_'` | на любой позиции |
| `digit && i > 0` | везде, кроме первой позиции |

Если не выполняется ни одно, это ошибка. Знак `!` перед скобкой как раз означает «ни одно».

### Почему сравнения идут по диапазонам

В таблице ASCII буквы `a`-`z`, `A`-`Z` и цифры `0`-`9` идут подряд, поэтому проверка `c >= 'a' && c <= 'z'` покрывает все строчные буквы. Функции из `<ctype.h>` не нужны.

### Почему `i > 0` решает задачу с первой цифрой

Цифра допустима везде, кроме начала. Условие `digit && i > 0` ложно для цифры в позиции `0`, и тогда срабатывает ошибка. Отдельная проверка первого символа не требуется.

## 6. Алгоритм целиком

1. Объявить `s`, `n = 0`, `ch`, `is_identifier = 0`.
2. Читать символы до `'\n'` или EOF, записывая в `s` и включая флаг.
3. Для каждого `s[i]` проверить правило. При нарушении поставить `is_identifier = 0` и выйти из цикла.
4. Вывести `Yes`, если флаг равен `1`, иначе `No`.

## 7. Пошаговый разбор

### `my_var1`

`n = 7`, `is_identifier = 1` после чтения.

| `i` | `s[i]` | letter | digit | допустим? |
| --- | --- | --- | --- | --- |
| 0 | `m` | 1 | 0 | да |
| 1 | `y` | 1 | 0 | да |
| 2 | `_` | 0 | 0 | да (`_`) |
| 3-5 | `var` | 1 | 0 | да |
| 6 | `1` | 0 | 1 | да (`i > 0`) |

Ошибок нет, вывод: `Yes`.

### `1abc`

| `i` | `s[i]` | letter | digit | допустим? |
| --- | --- | --- | --- | --- |
| 0 | `1` | 0 | 1 | **нет** (`i == 0`) |

`is_identifier = 0`, `break`, вывод: `No`.

## 8. Особые случаи

| Ввод | Результат | Почему |
| --- | --- | --- |
| пустая строка | `No` | флаг не включился |
| `_` | `Yes` | подчёркивание допустимо первым |
| `___` | `Yes` | только подчёркивания |
| `a` | `Yes` | одна буква |
| `7` | `No` | цифра на первой позиции |
| `a1` | `Yes` | цифра не на первой позиции |
| `a b` | `No` | пробел недопустим |
| `a-b` | `No` | дефис недопустим |
| `Abc_9` | `Yes` | регистр не важен |
| последняя строка без `'\n'` | работает как обычно | цикл остановится на EOF |

## 9. Почему решение работает

- Цикл чтения собирает всю строку и длину `n`.
- Цикл проверки смотрит каждый символ ровно один раз и снимает флаг при первом нарушении.
- Пустая строка отсекается тем, что флаг изначально `0` и включается только при чтении символа.

Время работы `O(n)`, память: один массив на 102 байта, динамической памяти нет, утечек быть не может.

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `char ch` вместо `int ch` | `EOF` нельзя надёжно отличить от символа |
| Объявить `is_identifier = 1` сразу | Пустая строка даст `Yes`, а нужно `No` |
| Разрешить цифру на любой позиции | `1abc` не идентификатор |
| Забыть `_` | `my_var1` будет отвергнут |
| Забыть про заглавные буквы | `MyVar` будет отвергнут |
| `printf("Yes\n")` | Условие запрещает завершающий перенос строки |
| Писать `yes`, `YES` | Нужно ровно `Yes` и `No` |
| `scanf("%s")` | Остановится на пробеле и не заметит его в строке `a b` |
| Не выйти из цикла после ошибки | Работает, но лишний перебор |
