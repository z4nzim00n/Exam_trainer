# EXAM_07_03. Перевод в нижний регистр — теория

## 1. Что требуется

Нужно заменить каждую заглавную латинскую букву соответствующей строчной:

```text
A → a
B → b
...
Z → z
```

Другие символы не меняются.

Например:

```text
Hello, World! → hello, world!
```

Все заглавные буквы обрабатываются одинаково, включая первую букву строки.

## 2. Символы и ASCII

Символы в C можно сравнивать и использовать в арифметических выражениях.

По условию используется ASCII. В этой кодировке:

- буквы от `'A'` до `'Z'` расположены подряд;
- буквы от `'a'` до `'z'` также расположены подряд;
- порядок букв в обоих диапазонах одинаков.

Поэтому достаточно определить позицию буквы в одном диапазоне и перенести её в другой.

## 3. Проверка заглавной буквы

```c
if (ch >= 'A' && ch <= 'Z') {
    /* Здесь ch — заглавная латинская буква. */
}
```

Оператор `&&` означает, что должны выполняться обе проверки:

- символ не меньше `'A'`;
- символ не больше `'Z'`.

Знаки препинания и цифры в этот диапазон не попадают.

## 4. Формула преобразования

```c
ch = ch - 'A' + 'a';
```

Для буквы `C`:

```text
'C' - 'A' = 2
'a' + 2 = 'c'
```

Можно было бы использовать разность кодов строчных и заглавных букв, но выражение через `'A'` и `'a'` понятнее, чем число `32`.

Функция `tolower` здесь не нужна и запрещена условием.

## 5. Алгоритм и ввод

1. Прочитать очередной символ.
2. Если это EOF или перевод строки — закончить.
3. Если это заглавная латинская буква — преобразовать её.
4. Вывести символ.
5. Повторить.

Чтение:

```c
while ((ch = getchar()) != EOF && ch != '\n') {
    /* Обработка. */
}
```

`getchar()` читает в том числе пробелы. Результат храним в `int`, чтобы корректно проверять EOF.

Вывод:

```c
putchar(ch);
```

Функция не добавляет перевод строки.

Массив не требуется: каждый символ обрабатывается независимо.

## 6. Пошаговый пример

Вход:

```text
A-z9!
```

| Символ | Действие | Вывод |
| --- | --- | --- |
| `A` | Заглавная буква — преобразуем | `a` |
| `-` | Не буква нужного диапазона | `-` |
| `z` | Уже строчная буква | `z` |
| `9` | Цифра | `9` |
| `!` | Знак препинания | `!` |

Результат:

```text
a-z9!
```

Время работы — `O(n)`, дополнительная память — `O(1)`.

## 7. Частые ошибки

| Ошибка | Почему неправильно |
| --- | --- |
| Преобразовывать каждый символ | Испортятся цифры, пробелы и пунктуация |
| Использовать `||` вместо `&&` в проверке диапазона | Условие станет истинным для символов вне диапазона |
| Проверять только первую букву | Нужно обработать всю строку |
| Читать через `scanf("%s", ...)` | Прочитается только первое слово |
| Удалять пробелы в конце | По условию их нужно сохранить |
| Добавлять `'\n'` в вывод | Перенос в конце ответа запрещён |
