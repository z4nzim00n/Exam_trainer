# EXAM_05_04. Удаление повторов — Тесты

## Компиляция

Решение собирается с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `1 1 2 2 3 -1` | `1 2 3` | `echo "1 1 2 2 3 -1" \| ./main` | соседние повторы |
| `1 2 1 3 1 4 -1` | `1 2 3 4` | `echo "1 2 1 3 1 4 -1" \| ./main` | повторы в разных местах |
| `5 2 5 1 2 -1` | `5 2 1` | `echo "5 2 5 1 2 -1" \| ./main` | сохранение порядка первых вхождений |
| `7 7 7 -1` | `7` | `echo "7 7 7 -1" \| ./main` | все элементы одинаковые |
| `0 1 0 -1` | `0 1` | `echo "0 1 0 -1" \| ./main` | ноль — допустимый элемент |
| `42 -1` | `42` | `echo "42 -1" \| ./main` | один элемент |
| `-1` | Пустой вывод | `echo "-1" \| ./main` | пустая последовательность допустима |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
| --- | --- | --- | --- |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| `1 2 abc -1` | `n/a` | `echo "1 2 abc -1" \| ./main` | ошибка после прочитанных элементов |
| `1 -2 -1` | `n/a` | `echo "1 -2 -1" \| ./main` | отрицательный элемент |
| `1 2 3` | `n/a` | `echo "1 2 3" \| ./main` | нет завершающего -1 |
| Пустой ввод | `n/a` | `printf '' \| ./main` | нет данных и признака конца |

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Проверка успешного выполнения:

```bash
echo "1 2 1 3 1 4 -1" | valgrind --leak-check=full ./main
```

Проверка освобождения памяти при ошибке ввода:

```bash
echo "1 2 abc -1" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
