# EXAM_05_05. Реверс последовательности — теория

## 1. С чего начать

Нужно вывести числа в обратном порядке:

```text
Вход:  1 2 3 4 5 -1
Вывод: 5 4 3 2 1
```

Особенности задачи:

- элементы — целые неотрицательные числа;
- `-1` завершает последовательность и не входит в неё;
- количество элементов заранее неизвестно;
- одинаковые числа сохраняются;
- для входа `-1` ничего не выводим;
- между числами ставим пробел, в конце перенос строки не добавляем.

## 2. Зачем сохранять последовательность

Первым нужно вывести последний элемент. Но пока не прочитана вся последовательность, мы не знаем, какое число будет последним.

Поэтому сначала сохраняем числа в массив, а затем обходим его с конца.

Переставлять элементы в памяти не требуется: достаточно изменить порядок их чтения при выводе.

## 3. Как хранить неизвестное количество чисел

Начинаем с пустого массива:

```c
int *array = NULL;
int size = 0;
```

- `array` — указатель на выделенную память;
- `size` — количество сохранённых элементов.

При чтении нового числа увеличиваем массив на один элемент:

```c
int *temp = realloc(array, (size + 1) * sizeof(int));
```

`realloc` принимает размер в байтах:

```text
Количество элементов × размер одного элемента
```

При `array == NULL` функция выделяет новый блок, как `malloc`.

При расширении существующего блока прежние элементы сохраняются, но адрес памяти может измениться.

### Почему нужен `temp`

Если выделение ненулевого блока не удалось, `realloc` возвращает `NULL`, а старый блок остаётся выделенным.

Поэтому нельзя терять прежний указатель до проверки результата:

```c
if (temp == NULL) {
    free(array);
    printf("n/a");
    return 0;
}
```

После успешной проверки:

```c
array = temp;
```

Теперь `array` указывает на блок нужного размера.

## 4. Как добавить элемент

В решении используется:

```c
array[size++] = value;
```

Постфиксный оператор `++` даёт старое значение `size` для индекса, а затем увеличивает счётчик.

Здесь запись равнозначна двум отдельным действиям:

```c
array[size] = value;
size++;
```

Например, если сохранено три элемента, их индексы — `0`, `1`, `2`.

Новое число записывается по индексу `3`, после чего `size` становится равным `4`.

## 5. Как вывести массив с конца

Индексация начинается с нуля. Поэтому последний элемент находится по индексу `size - 1`, а не `size`.

```c
for (int i = size - 1; i >= 0; i--) {
    printf("%d", array[i]);
}
```

Для пяти элементов индексы идут так:

```text
4 → 3 → 2 → 1 → 0
```

Условие `i >= 0` включает первый элемент массива.

### Что происходит с пустым массивом

Если сразу введено `-1`, значение `size` остаётся равным нулю:

```text
i = size - 1 = -1
```

Условие `i >= 0` сразу ложно, поэтому обращения к массиву не происходит и ничего не выводится.

Здесь `i` имеет знаковый тип `int`. Для беззнакового индекса такой цикл напрямую переносить нельзя: он не сможет стать отрицательным.

## 6. Как расставить пробелы

Первым выводится элемент с индексом `size - 1`. Перед ним пробел не нужен.

Перед всеми последующими элементами ставим пробел:

```c
if (i < size - 1) {
    printf(" ");
}

printf("%d", array[i]);
```

В результате между числами ровно один пробел, а в начале и конце пробелов нет.

`\n` не добавляем.

## 7. Как проверить ввод

### Проверка каждого элемента

Читаем по одному целому числу:

```c
while (scanf("%d", &value) == 1 && value != -1)
```

`scanf` должна вернуть `1` — количество успешно прочитанных и записанных значений.

Если прочитано `-1`, тело цикла не выполняется.

Другие отрицательные значения проверяем внутри:

```c
if (value < 0) {
    free(array);
    printf("n/a");
    return 0;
}
```

### Проверка конца последовательности

Цикл может закончиться не только из-за `-1`, но и при ошибке чтения.

Например:

```text
1 2 abc
```

Поэтому после цикла нужна проверка:

```c
if (value != -1) {
    free(array);
    printf("n/a");
    return 0;
}
```

Начальное значение `value = 0` позволяет выполнить её безопасно, даже если первое чтение не удалось.

Пустой поток и пустая последовательность — разные случаи:

```text
Нет данных вообще → n/a
Введено -1 → пустой вывод
```

> Этот простой вариант предполагает, что числа помещаются в `int`, а счётчик и размер выделения памяти не переполняются. Чтение через `%d` не обеспечивает строгую проверку произвольного текста, например символов после завершающего `-1`.

## 8. Алгоритм решения

1. Подготовить пустой динамический массив и счётчик элементов.
2. Читать числа до `-1`.
3. Отвергать другие отрицательные числа.
4. Для каждого элемента расширять массив и сохранять значение.
5. При ошибке выделения памяти освободить прежний блок и вывести `n/a`.
6. После чтения проверить наличие завершающего `-1`.
7. Вывести элементы от индекса `size - 1` до `0`.
8. Освободить память.

Вывод начинается только после проверки ввода, чтобы при поздней ошибке не получить числа вперемешку с `n/a`.

## 9. Пошаговый разбор

Вход:

```text
7 0 4 -1
```

После чтения:

| Индекс | Значение |
| --- | --- |
| `0` | `7` |
| `1` | `0` |
| `2` | `4` |

Количество элементов:

```text
size = 3
```

Обратный обход:

| Индекс i | Действие |
| --- | --- |
| `2` | Вывести `4` без начального пробела |
| `1` | Вывести пробел и `0` |
| `0` | Вывести пробел и `7` |
| `-1` | Завершить цикл |

Результат:

```text
4 0 7
```

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Начать с индекса `size` | Это позиция за последним элементом массива |
| Использовать условие `i > 0` | Элемент с индексом `0` не будет выведен |
| Увеличивать индекс при обратном обходе | Нужно двигаться к началу массива |
| Считать ноль концом последовательности | Ноль — допустимый элемент, конец обозначает `-1` |
| Удалять одинаковые числа | Повторы нужно сохранить |
| Присваивать результат `realloc` сразу в `array` | При ошибке можно потерять адрес прежнего блока |
| Не проверить наличие `-1` после чтения | Ошибка ввода может быть принята за нормальное завершение |
| Забыть `free(array)` при выходе | Выделенная память не будет явно освобождена |
