# EXAM_05_01. Скалярное произведение — теория

## 1. С чего начать

**Скалярное произведение** векторов — это сумма произведений их соответствующих координат:

```text
a = [1, 2, 3]
b = [4, 5, 6]

Скалярное произведение = (1 × 4) + (2 × 5) + (3 × 6)
                       = 4 + 10 + 18
                       = 32
```

На входе даётся:
1. Число `n` — размерность (сколько координат у каждого вектора).
2. `n` чисел — координаты первого вектора.
3. `n` чисел — координаты второго вектора.

По условию `n` — целое положительное число (`n > 0`). Если введено `0`, отрицательное число или мусор — выводим `n/a`.

## 2. Зачем нужен динамический массив

Размерность `n` неизвестна на этапе написания кода — её вводит пользователь. В примечании сказано: *«Последовательность может быть любого размера»*.

Создать обычный статический массив фиксированного размера (например, `int a[100];`) нельзя: если введут `n = 1000`, программа выйдет за пределы массива.

Поэтому память выделяется динамически во время работы программы через функцию `malloc()` из библиотеки `<stdlib.h>`.

## 3. Маленькая хитрость: нужен ли второй массив?

Можно выделить память под оба вектора (`int *a` и `int *b`). Но это лишний расход памяти.

Достаточно сохранить в массив только **первый** вектор. Когда мы читаем координаты **второго** вектора, мы можем брать их по одной в обычную переменную `temp`, сразу умножать на `a[i]` и прибавлять к общей сумме.

## 4. Алгоритм решения

1. Прочитать `n`. Проверить, что `scanf` вернул `1` и `n > 0`.
2. Выделить память под `n` целых чисел: `malloc(n * sizeof(int))`.
3. Проверить указатель на `NULL`.
4. В цикле от `0` до `n - 1` прочитать координаты первого вектора в массив `a`. Если ввод оборвался — освободить память `free(a)`, вывести `n/a` и выйти.
5. Завести переменную суммы `long long sum = 0;`.
6. Во втором цикле от `0` до `n - 1` читать по одному числу в переменную `temp`. При ошибке ввода — `free(a)`, `n/a` и выйти.
7. Прибавлять к сумме `(long long)a[i] * temp`.
8. Освободить массив `free(a)`.
9. Вывести `sum` через спецификатор `%lld` без переноса строки.

## 5. Что понадобится из C

### `malloc()` и `sizeof`

Функция `malloc` выделяет указанное количество байт в динамической памяти (куче, heap):

```c
int *a = malloc(n * sizeof(int));
```

- `sizeof(int)` возвращает размер одного `int` в байтах (обычно 4 байта).
- `n * sizeof(int)` — суммарный размер массива в байтах.
- `int *a` — указатель, хранящий адрес начала выделенной памяти.

После вызова `malloc` **всегда** проверяем результат:

```c
if (a == NULL) {
    printf("n/a");
    return 0;
}
```

Если памяти в системе не хватило, `malloc` вернёт `NULL` (нулевой указатель).

### Освобождение памяти: `free()`

Всю память, полученную через `malloc`, нужно обязательно вернуть системе с помощью `free(a)`:

```c
free(a);
```

**Критически важно:** если программа завершается раньше времени из-за ошибки ввода координат, память нужно освободить **до** вызова `return 0;`, иначе возникнет утечка памяти (memory leak), которую поймает `valgrind`:

```c
if (scanf("%d", &a[i]) != 1) {
    free(a);        /* Освободили перед выходом! */
    printf("n/a");
    return 0;
}
```

### Зачем писать `(long long)a[i] * temp`

Если перемножить два больших числа типа `int` (например, `100 000 * 100 000 = 10 000 000 000`), результат не поместится в обычный 32-битный `int` (максимум ~2 млрд) и переполнится.

Си считает операцию по типу участвующих в ней переменных:
- Если написать `a[i] * temp`, произойдёт умножение `int` на `int`, число сломается, и мусор запишется в `sum`.
- Запись `(long long)a[i]` заранее расширяет первое число до 64 бит. Тогда Си выполняет само умножение уже в типе `long long`, и результат сохраняется без потерь.

Для вывода `long long` в `printf` используется формат `%lld`.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Забыть `free(a)` при ошибке ввода | Утечка памяти, Verter и Valgrind забракуют решение |
| Использовать массив после `free(a)` | Обращение к освобождённой памяти (use-after-free) |
| `malloc(n)` вместо `malloc(n * sizeof(int))` | Выделится `n` байт вместо `n` целых чисел |
| Не проверить `n <= 0` | Размерность вектора не может быть нулевой или отрицательной |
| Написать `sum += (long long)(a[i] * temp)` | Скобки стоят не там: умножение произойдёт в `int`, а результат переполнения приведётся к `long long` |
| Использовать `%d` вместо `%lld` в `printf` | Неправильный формат для типа `long long` |
| Добавить `\n` в `printf` | Условие требует: *«В конце ответа не должно быть переноса на новую строку»* |
