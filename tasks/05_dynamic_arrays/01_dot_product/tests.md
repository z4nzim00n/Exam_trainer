# EXAM_05_01. Скалярное произведение — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
|---|---:|---|---|
| `1 7 3` | `21` | `echo "1 7 3" \| ./main` | `7 · 3 = 21` |
| `3 1 2 3 1 2 3` | `14` | `echo "3 1 2 3 1 2 3" \| ./main` | `1·1 + 2·2 + 3·3 = 14` |
| `2 5 10 2 3` | `40` | `echo "2 5 10 2 3" \| ./main` | `5·2 + 10·3 = 40` |
| `3 -1 2 -3 4 -5 6` | `-12` | `echo "3 -1 2 -3 4 -5 6" \| ./main` | `(-1)·4 + 2·(-5) + (-3)·6 = -32` |
| `4 1 1 1 1 1 1 1 1` | `4` | `echo "4 1 1 1 1 1 1 1 1" \| ./main` | сумма четырёх единиц |
| `3 0 0 0 5 6 7` | `0` | `echo "3 0 0 0 5 6 7" \| ./main` | все произведения равны `0` |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `0` | `n/a` | `echo "0" \| ./main` | `n` должно быть положительным |
| `-1` | `n/a` | `echo "-1" \| ./main` | `n` должно быть положительным |
| `abc` | `n/a` | `echo "abc" \| ./main` | `n` не является целым числом |
| `3 1 2` | `n/a` | `echo "3 1 2" \| ./main` | не хватает координат |
| `3 1 2 3 1 2` | `n/a` | `echo "3 1 2 3 1 2" \| ./main` | не хватает координаты второго вектора |

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Нужен для поиска проблем с памятью во время выполнения программы.

```bash
echo "3 1 2 3 1 2 3" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
