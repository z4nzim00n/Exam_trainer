# EXAM_05_03. Вывод последовательности — Тесты

## Компиляция

Решение собирается с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `1 2 3 -1` | `1 3 2` | `echo "1 2 3 -1" \| ./main` | нечётное количество элементов |
| `1 2 3 4 5 6 -1` | `1 6 2 5 3 4` | `echo "1 2 3 4 5 6 -1" \| ./main` | чётное количество элементов |
| `42 -1` | `42` | `echo "42 -1" \| ./main` | один элемент |
| `0 5 0 -1` | `0 0 5` | `echo "0 5 0 -1" \| ./main` | нули допустимы (неотрицательные числа) |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
| --- | --- | --- | --- |
| `-1` | `n/a` | `echo "-1" \| ./main` | пустая последовательность |
| `1 2 -5 3 -1` | `n/a` | `echo "1 2 -5 3 -1" \| ./main` | отрицательное число в данных |
| `1 2 abc -1` | `n/a` | `echo "1 2 abc -1" \| ./main` | буква вместо числа |
| `1 2 3` | `n/a` | `echo "1 2 3" \| ./main` | нет терминатора -1 |

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти (особенно важно для `realloc` и `free`).

Проверка успешного выполнения:

```bash
echo "1 2 3 4 5 6 -1" | valgrind --leak-check=full ./main
```

Проверка ветки с ошибкой ввода:

```bash
echo "1 2 -5 -1" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
