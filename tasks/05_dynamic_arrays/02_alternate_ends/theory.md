# EXAM_05_03. Вывод последовательности — теория

## 1. С чего начать

Нужно прочитать последовательность чисел и вывести их, чередуя начало и конец:

```text
Вход:  1  2  3  4  5  6
       ↓              ↓
Шаг 1: 1              6
          ↓        ↓
Шаг 2:    2        5
             ↓  ↓
Шаг 3:       3  4

Вывод: 1 6 2 5 3 4
```

Особенности задачи:
- Признак конца ввода — число `-1` (оно в последовательность **не входит**).
- Элементы должны быть неотрицательными (`>= 0`).
- Длина последовательности заранее неизвестна — нужен динамический массив.
- В конце вывода **не должно быть пробела** и переноса строки.

## 2. Динамическое расширение массива: `realloc()`

Так как размер заранее неизвестен, мы не можем выделить массив сразу через `malloc(n * sizeof(int))`.

Вместо этого мы начинаем с пустого указателя `int *array = NULL;` и при чтении каждого нового числа расширяем массив на 1 элемент с помощью `realloc`:

```c
int *temp = realloc(array, (size + 1) * sizeof(int));
```

### Почему обязательно использовать `temp`?
Если памяти не хватит, `realloc` вернёт `NULL`. Если написать `array = realloc(array, ...)`, указатель `array` перезапишется нулём, а адрес старой памяти будет безвозвратно потерян — возникнет утечка памяти.

Поэтому результат сначала пишется в `temp`, проверяется, и только потом присваивается в `array`.

## 3. Метод двух указателей (`left` и `right`)

Для вывода элементов навстречу друг другу заведём два индекса:
- `left = 0` (указывает на первый элемент);
- `right = size - 1` (указывает на последний элемент).

На каждом шаге цикла:
1. Печатаем `array[left]`.
2. Если `left != right`, печатаем `array[right]`.
3. Сдвигаем: `left++`, `right--`.
4. Цикл продолжается, пока `left <= right`.

Если в массиве нечётное количество элементов (например, 3 элемента: `1 2 3`), то на последнем шаге `left == right` (оба укажут на `2`). Условие `if (left != right)` защитит от повторного вывода центрального числа.

## 4. Как избежать лишнего пробела в конце

Частая ошибка — печатать пробел **после** каждого числа:
```c
printf("%d ", x); /* В конце останется висеть лишний пробел! */
```

Правильный подход — ставить пробел **перед** числом, пропуская его только для самого первого элемента. Для этого используется флаг:
```c
int first = 1;
/* ... */
if (!first) {
    printf(" ");
}
printf("%d", array[left]);
first = 0;
```

## 5. Проверка корректности ввода

В цикле `while (scanf("%d", &value) == 1 && value != -1)` выход может случиться по двум причинам:
1. Всё хорошо: прочитали `-1`.
2. Ошибка: наткнулись на букву (`abc`) или поток ввода закончился (EOF) без числа `-1`.

Поэтому сразу после цикла проверяем:
```c
if (value != -1 || size == 0) {
    free(array);
    printf("n/a");
    return 0;
}
```
Если `value != -1` — значит, корректного конца последовательности не было.
Если `size == 0` — значит, последовательность пуста (сразу ввели `-1`).

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `array = realloc(array, ...)` напрямую | При нехватке памяти указатель затрётся, и память утечёт |
| Не проверять `value < 0` внутри цикла | По условию числа должны быть неотрицательными |
| Вывести центральный элемент дважды при нечётном размере | При `left == right` нужно вывести число только один раз |
| Пробел в самом конце строки | Условие строго запрещает завершающий пробел |
| Забыть `free(array)` | Утечка памяти |
