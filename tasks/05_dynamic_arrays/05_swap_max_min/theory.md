# EXAM_05_05. Перестановка наибольшего и наименьшего — теория

## 1. С чего начать

Числа идут до `-1`, и сколько их будет, неизвестно. Чтобы переставить элементы, их нужно **хранить**. Поэтому массив растёт по мере чтения.

```
читать числа в растущий массив → найти индексы min и max → поменять местами → вывести
```

## 2. Каркас решения (его стоит запомнить)

1. `int* array = NULL; int size = 0; int value = 0;`
2. `while (scanf("%d", &value) == 1 && value != -1)`: `realloc` на `size + 1`, проверка `temp`, запись, `size++`.
3. `if (value != -1 || size == 0)` → `free`, `n/a`.
4. Цикл с `min` и `max` (строгие `<` и `>`).
5. Обмен через `swap`.
6. Печать, пробел перед всеми, кроме первого. `free`.

## 3. Как выразить это на C

### Растущий массив

```c
int* array = NULL;
...
int* temp = realloc(array, (size + 1) * sizeof(int));
if (temp == NULL) {
    free(array);
    printf("n/a");
    return 0;
}
array = temp;
```

- `realloc(NULL, ...)` работает как `malloc`, поэтому начинаем с `NULL`;
- растим на один элемент за раз: просто и без лишних переменных;
- результат кладём в `temp`, а не сразу в `array`: если памяти не хватит, старый `array` нужно освободить.

### Условие чтения

```c
while (scanf("%d", &value) == 1 && value != -1)
```

`scanf` возвращает 1, если число прочитано. Только после этого `value` сравнивается с `-1`.

### Проверка после цикла

```c
if (value != -1 || size == 0)
```

- `value != -1`: цикл остановился не на `-1` (буква или конец ввода);
- `size == 0`: сразу пришло `-1`, чисел нет.

`value` нужно задать начальное значение `0`, иначе при пустом вводе в нём мусор.

### Первые вхождения

```c
if (array[i] < array[min]) min = i;
if (array[i] > array[max]) max = i;
```

Знаки строгие, поэтому при равных значениях индекс не меняется. Начинаем с `min = max = 0`, цикл с `i = 1`.

### Обмен

```c
int swap = array[min];
array[min] = array[max];
array[max] = swap;
```

## 4. Проверка на примере

`5 1 1 1 5 9 9 9 5 -1`: минимум 1 впервые на индексе 1, максимум 9 впервые на индексе 5. После обмена: `5 9 1 1 5 1 9 9 5`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `<=` или `>=` при поиске | Индекс уйдёт на последнее вхождение |
| Записать `-1` в массив | `-1` не элемент последовательности |
| `array = realloc(array, ...)` | При ошибке потеряется старая память |
| Не задать `value = 0` | При пустом вводе в `value` мусор |
| Нет проверки `value != -1` после цикла | Ввод без `-1` не даст `n/a` |
| Нет `size == 0` | Для одиночного `-1` нужно `n/a` |
| Нет `free` перед `return` в ветке ошибки | Утечка |
| Пробел после каждого числа | Лишний пробел в конце |
