# EXAM_04_06. Биномиальные коэффициенты — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `3` | `1 3 3 1` | `echo "3" \| ./main` | пример из условия |
| `0` | `1` | `echo "0" \| ./main` | единственный коэффициент |
| `1` | `1 1` | `echo "1" \| ./main` | минимальный случай с пробелом |
| `4` | `1 4 6 4 1` | `echo "4" \| ./main` | чётное n, один центральный элемент |
| `5` | `1 5 10 10 5 1` | `echo "5" \| ./main` | нечётное n, два центральных |
| `21` | `1 21 210 1330 5985 20349 54264 116280 203490 293930 352716 352716 293930 203490 116280 54264 20349 5985 1330 210 21 1` | `echo "21" \| ./main` | при n > 20 факториал в `unsigned long long` переполнился бы |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
| --- | --- | --- | --- |
| `-1` | `n/a` | `echo "-1" \| ./main` | отрицательное n |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| пустая строка | `n/a` | `echo "" \| ./main` | нет числа |
| `3 x` | `n/a` | `echo "3 x" \| ./main` | лишние символы после числа |

### Cppcheck

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

```bash
echo "5" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
