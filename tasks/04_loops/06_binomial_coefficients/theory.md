# EXAM_04_06. Биномиальные коэффициенты — теория

## 1. С чего начать

Нужно вывести строку из `n + 1` чисел: `C(n, 0), C(n, 1), ..., C(n, n)`. Например, для `n = 4`: `1 4 6 4 1`.

По определению `C(n, k) = n! / (k! * (n - k)!)`, но считать через факториалы не стоит.

## 2. Почему не факториалы

`21!` уже не помещается в `unsigned long long`. Сами коэффициенты при этом ещё небольшие, а программа выдаст мусор. Поэтому считаем иначе.

## 3. Следующий коэффициент из предыдущего

```c
c = c * (n - k) / (k + 1);
```

Начинаем с `c = 1` (это `C(n, 0)`). Для `n = 4`:

| k | c до шага | вычисление | c после |
| --- | --- | --- | --- |
| 0 | 1 | 1 * 4 / 1 | 4 |
| 1 | 4 | 4 * 3 / 2 | 6 |
| 2 | 6 | 6 * 2 / 3 | 4 |
| 3 | 4 | 4 * 1 / 4 | 1 |
| 4 | 1 | 1 * 0 / 5 | 0 (не выводится) |

Сначала умножаем, потом делим: так деление всегда получается без остатка.

## 4. Вывод

```c
for (int k = 0; k <= n; k++) {
    if (k > 0) {
        printf(" ");
    }
    printf("%llu", c);
    c = c * (n - k) / (k + 1);
}
```

- Пробел ставим **перед** числом, кроме первого. Тогда после последнего пробела нет.
- Тип `unsigned long long` печатается через `%llu`.
- `\n` в конце не нужен.

## 5. Проверка ввода

- `scanf("%d", &n) != 1` - ввели не число.
- `n < 0` - по условию `n` неотрицательное.
- Цикл с `getchar()` отсекает лишние символы после числа.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Считать через факториалы | Переполнение при n > 20 |
| Сначала делить, потом умножать: `c / (k + 1) * (n - k)` | Деление может дать остаток и потерять часть значения |
| `printf("%d", c)` для `unsigned long long` | Нужен `%llu` |
| Пробел после каждого числа | Лишний пробел в конце строки |
| Не вывести ничего при `n = 0` | Ответ `1` |
| `printf("\n")` в конце | Лишний перенос строки |
