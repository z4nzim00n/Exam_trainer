# EXAM_07_06. Число без пары — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

Для проверки эталона замените имя исходного файла на `solution.c` или `solution_commented.c`.

## Проверочные случаи

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `1 2 1 -1` | `2` | `printf '1 2 1 -1\n' \| ./main` | Одинокое число в середине |
| `4 7 4 9 7 -1` | `9` | `printf '4 7 4 9 7 -1\n' \| ./main` | Пары не расположены рядом |
| `5 -1` | `5` | `printf '5 -1\n' \| ./main` | Единственный элемент |
| `0 -1` | `0` | `printf '0 -1\n' \| ./main` | Единственный элемент — ноль |
| `0 3 3 -1` | `0` | `printf '0 3 3 -1\n' \| ./main` | Ноль без пары |
| `0 7 0 -1` | `7` | `printf '0 7 0 -1\n' \| ./main` | Нули образуют пару |
| `8 2 5 2 5 -1` | `8` | `printf '8 2 5 2 5 -1\n' \| ./main` | Ответ в начале |
| `2 5 2 5 8 -1` | `8` | `printf '2 5 2 5 8 -1\n' \| ./main` | Ответ в конце |
| `30000 42 30000 -1` | `42` | `printf '30000 42 30000 -1\n' \| ./main` | Более крупные значения |

## Разные разделители

```bash
printf '4\n7 4\n9\n7 -1' | ./main
```

Ожидается:

```text
9
```

## Проверка завершения последовательности

```bash
printf '5 -1 99\n' | ./main
```

Ожидается `5`: после `-1` обработка заканчивается.

## Точный формат вывода

```bash
printf '5 -1\n' | ./main | od -An -t x1
```

Ожидается:

```text
35
```

Пробелов и байта `0a` нет.

> Пустая последовательность, отсутствие числа без пары и три повторения одного значения не входят в условия задачи. Проверять эти гарантии программа не обязана.

## Cppcheck

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

```bash
clang-format -n -Werror main.c
```

Исправление форматирования:

```bash
clang-format -i main.c
```

## Valgrind

```bash
printf '4 7 4 9 7 -1\n' | valgrind --leak-check=full --track-origins=yes ./main
```

Valgrind запускается на скомпилированной программе.
