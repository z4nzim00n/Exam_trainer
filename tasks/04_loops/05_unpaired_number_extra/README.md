## EXAM_04_05. Число без пары

### Задание

| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, находящую число без пары в последовательности неотрицательных целых чисел.

Гарантируется, что одно из значений встречается в последовательности ровно один раз, а каждое из остальных значений — ровно два раза.

Последовательность задаётся через стандартный поток ввода stdin. Числа разделяются пробелами или переводами строк.

Концом последовательности является число `-1`. Оно не является её элементом и не участвует в поиске.

Найденное число вывести на стандартный поток вывода stdout. В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод и наличие завершающего числа `-1`.
- Последовательность содержит хотя бы один элемент.
- Все её элементы — неотрицательные целые числа, представимые типом `int`.
- Одинаковые числа необязательно расположены рядом.
- Проверять выполнение гарантии о количестве повторений не требуется.
- Хранить всю последовательность в массиве необязательно.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `1 2 1 -1` | `2` |
| `4 7 4 9 7 -1` | `9` |
| `5 -1` | `5` |
| `0 3 3 -1` | `0` |
| `8 2 5 2 5 -1` | `8` |
