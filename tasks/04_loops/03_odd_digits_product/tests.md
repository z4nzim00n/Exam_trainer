# EXAM_04_05. Произведение нечётных цифр — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash id="6nq1pm"
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход    | Результат | Команда                  | Пояснение                 |
| ------- | --------- | ------------------------ | ------------------------- |
| `1234`  | `3`       | `echo "1234" \| ./main`  | `1 · 3 = 3`               |
| `24`    | `0`       | `echo "24" \| ./main`    | нечётных цифр нет         |
| `-3`    | `3`       | `echo "-3" \| ./main`    | знак `-` не учитывается   |
| `13579` | `945`     | `echo "13579" \| ./main` | `1 · 3 · 5 · 7 · 9 = 945` |
| `2468`  | `0`       | `echo "2468" \| ./main`  | все цифры чётные          |
| `11`    | `1`       | `echo "11" \| ./main`    | `1 · 1 = 1`               |
| `0`     | `0`       | `echo "0" \| ./main`     | нечётных цифр нет         |

## Некорректные данные (`n/a`)

| Вход    | Ожидаемый результат | Команда                  | Причина                           |
| ------- | ------------------- | ------------------------ | --------------------------------- |
| `abc`   | `n/a`               | `echo "abc" \| ./main`   | значение не является целым числом |
| `12abc` | `n/a`               | `echo "12abc" \| ./main` | некорректный ввод                 |
| `1.5`   | `n/a`               | `echo "1.5" \| ./main`   | введено не целое число            |

> Знак `-` не влияет на результат: для отрицательного числа рассматриваются только его цифры.

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash id="w4v7pn"
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash id="2zq6ym"
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash id="5s8r3k"
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Нужен для поиска проблем с памятью во время выполнения программы.

```bash id="c1j5yx"
echo "1234" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
