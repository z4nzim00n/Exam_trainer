# EXAM_04_05. Произведение нечётных цифр — теория

## 1. С чего начать

Нужно выделить цифры числа и перемножить только нечётные:

```text
1, 3, 5, 7, 9
```

Чётные цифры пропускаем:

```text
0, 2, 4, 6, 8
```

Например:

```text
1234 → 1 × 3 = 3
```

Если нечётных цифр нет, выводим `0`:

```text
24 → нет нечётных цифр → 0
```

Знак числа не участвует в произведении:

```text
-35 → 3 × 5 = 15
```

## 2. Как выделять цифры

Используем остаток от деления и целочисленное деление:

- `% 10` — получить последнюю цифру положительного числа;
- `/ 10` — убрать последнюю цифру.

Для числа `1234`:

```text
1234 % 10 = 4
1234 / 10 = 123

123 % 10 = 3
123 / 10 = 12

12 % 10 = 2
12 / 10 = 1

1 % 10 = 1
1 / 10 = 0
```

Получаем цифры справа налево: `4`, `3`, `2`, `1`.

Для произведения порядок множителей не важен, поэтому разворачивать цифры не нужно.

## 3. Как определить нечётную цифру

Нечётное число не делится на `2` без остатка:

```c
digit % 2 != 0
```

Например:

```text
3 % 2 = 1 → нечётная
4 % 2 = 0 → чётная
```

Если цифра нечётная, включаем её в произведение. Иначе пропускаем.

Ноль — чётная цифра. Он не должен обнулять произведение:

```text
305 → 3 × 5 = 15
```

## 4. Почему произведение начинается с единицы

Начальное значение:

```c
int product = 1;
```

Единица не меняет результат умножения:

```text
1 × 3 = 3
3 × 5 = 15
```

Если начать с нуля, результат всегда будет нулевым:

```text
0 × 3 × 5 = 0
```

Для накопления суммы обычно начинают с `0`, а для накопления произведения — с `1`.

## 5. Зачем нужен флаг `has_odd`

Если нечётных цифр нет, переменная `product` останется равной `1`. Но по условию в таком случае нужно вывести `0`.

Используем отдельный флаг:

```c
int has_odd = 0;
```

Его значения:

- `0` — нечётные цифры ещё не встретились;
- `1` — найдена хотя бы одна нечётная цифра.

При обработке нечётной цифры:

```c
product *= digit;
has_odd = 1;
```

После цикла флаг позволяет выбрать результат.

### Почему нельзя проверять только `product == 1`

Произведение может законно равняться единице:

```text
111 → 1 × 1 × 1 = 1
```

По одному значению `product` нельзя отличить отсутствие нечётных цифр от произведения нескольких единиц. Поэтому нужен флаг.

## 6. Как обработать отрицательное число

У отрицательного числа остаток от деления может быть отрицательным:

```text
-35 % 10 = -5
```

Сделаем положительным только выделенный остаток:

```c
digit = n % 10;
if (digit < 0) {
    digit = -digit;
}
```

После этого проверяем нечётность и выполняем умножение.

Само число продолжаем делить на `10`:

```text
-35 / 10 = -3
 -3 / 10 = 0
```

Целочисленное деление в современном C отбрасывает дробную часть в сторону нуля.

> Менять знак всего числа через `n = -n` небезопасно для минимального значения `int`: его положительная противоположность не помещается в этот тип. Отдельный остаток находится между `-9` и `9`, поэтому менять его знак безопасно.

## 7. Алгоритм решения

1. Прочитать целое число.
2. Если чтение не удалось — вывести `n/a` и завершить программу.
3. Установить произведение равным `1`, а флаг наличия нечётных цифр — `0`.
4. Выполнить хотя бы один раз:
  - выделить последнюю цифру;
  - сделать её положительной, если нужно;
  - если цифра нечётная — умножить на неё произведение и установить флаг;
  - убрать последнюю цифру из числа.
5. Повторять, пока число не станет нулём.
6. Если нечётные цифры встретились — вывести произведение, иначе — `0`.

## 8. Что понадобится из C

### Чтение числа

Для чтения `int` используется `%d`:

```c
if (scanf("%d", &n) != 1) {
    printf("n/a");
    return 0;
}
```

`&n` — адрес переменной, куда записывается число.

`scanf` возвращает количество успешно прочитанных и записанных значений. Здесь ожидается `1`.

> Такая проверка не проверяет весь ввод целиком: например, `123abc` может быть прочитано как `123`. Также она не защищает от ввода числа за пределами диапазона `int`.

### Цикл `do ... while`

```c
do {
    /* Обработка очередной цифры. */
} while (n != 0);
```

Этот цикл выполняет тело хотя бы один раз. Поэтому для входа `0` его единственная цифра тоже будет обработана:

```text
Цифра 0 — чётная.
Флаг остаётся равным 0.
Вывод: 0.
```

Условие `n != 0` подходит и для положительных, и для отрицательных чисел.

После `while` в этой конструкции обязательна точка с запятой.

### Сокращённые присваивания

```c
product *= digit;
```

То же самое, что:

```c
product = product * digit;
```

А запись:

```c
n /= 10;
```

означает:

```c
n = n / 10;
```

### Вывод по флагу

```c
if (has_odd) {
    printf("%d", product);
} else {
    printf("0");
}
```

Условие `if (has_odd)` истинно, когда значение флага ненулевое.

Не добавляем `\n`, пробелы и пояснения.

## 9. Пошаговый разбор

Вход:

```text
-3057
```

Начальные значения:

```text
product = 1
has_odd = 0
```

| Цифра после обработки знака | Действие | product | has_odd |
| --- | --- | --- | --- |
| `7` | Нечётная — умножаем | `7` | `1` |
| `5` | Нечётная — умножаем | `35` | `1` |
| `0` | Чётная — пропускаем | `35` | `1` |
| `3` | Нечётная — умножаем | `105` | `1` |

Нечётные цифры найдены, поэтому выводим:

```text
105
```

## 10. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Начать с `product = 0` | Любое последующее умножение даст ноль |
| Перемножать все цифры | По условию нужны только нечётные |
| Считать ноль нечётной цифрой | Ноль делится на `2` без остатка |
| Не использовать флаг | Нельзя отличить отсутствие нечётных цифр от произведения, равного `1` |
| Сбрасывать флаг при встрече чётной цифры | Уже найденные нечётные цифры никуда не исчезают |
| Умножать на отрицательный остаток | Знак исходного числа не должен влиять на результат |
| Забыть `n /= 10` | Ненулевое число не меняется, цикл не завершается |
| Добавить перенос строки | Условие запрещает его в конце ответа |
