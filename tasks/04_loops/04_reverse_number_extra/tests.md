# EXAM_07_07. Разворот числа — Тесты

## Компиляция

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

Для проверки эталона замените имя исходного файла на `solution.c` или `solution_commented.c`.

## Проверочные случаи

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `123` | `321` | `printf '123\n' \| ./main` | Обычный разворот |
| `120` | `21` | `printf '120\n' \| ./main` | Ведущий ноль результата исчезает |
| `1000` | `1` | `printf '1000\n' \| ./main` | Несколько конечных нулей |
| `7` | `7` | `printf '7\n' \| ./main` | Одна цифра |
| `0` | `0` | `printf '0\n' \| ./main` | Нулевое число |
| `10203` | `30201` | `printf '10203\n' \| ./main` | Внутренние нули |
| `1221` | `1221` | `printf '1221\n' \| ./main` | Симметричная запись |
| `123456789` | `987654321` | `printf '123456789\n' \| ./main` | Девять цифр |
| `999999999` | `999999999` | `printf '999999999\n' \| ./main` | Верхняя граница |
| `100000000` | `1` | `printf '100000000' \| ./main` | Девять цифр, завершение по EOF |

## Точный формат вывода

```bash
printf '120\n' | ./main | od -An -t x1
```

Ожидается:

```text
32 31
```

Это `21` без ведущего нуля, пробела и перевода строки.

> Отрицательные числа и значения больше `999999999` находятся вне условий задачи.

## Cppcheck

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

```bash
clang-format -n -Werror main.c
```

Исправление форматирования:

```bash
clang-format -i main.c
```

## Valgrind

```bash
printf '10203\n' | valgrind --leak-check=full --track-origins=yes ./main
```

> Дополнительно проверьте исходник: строки и массивы для хранения цифр запрещены.
