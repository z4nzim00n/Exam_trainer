# EXAM_07_07. Разворот числа — теория

## 1. Что нужно получить

Цифры числа должны оказаться в обратном порядке:

```text
123 → 321
10203 → 30201
```

Результат выводится как число, поэтому ведущие нули не сохраняются:

```text
120 → 21
1000 → 1
```

Используем арифметику, а не строку.

## 2. Как получить последнюю цифру

```c
number % 10
```

Оператор `%` вычисляет остаток от деления.

Для неотрицательных целых чисел:

```text
123 % 10 = 3
120 % 10 = 0
7 % 10 = 7
```

Так мы получаем цифры справа налево.

## 3. Как удалить последнюю цифру

```c
number /= 10;
```

Это сокращение:

```c
number = number / 10;
```

При целочисленном делении дробная часть отбрасывается:

```text
123 / 10 = 12
12 / 10 = 1
1 / 10 = 0
```

Когда число стало нулём, необработанных цифр больше нет.

## 4. Как добавить цифру справа

```c
reversed = reversed * 10 + digit;
```

Например:

```text
32 * 10 + 1 = 321
```

Умножение на `10` сдвигает уже собранные цифры на один десятичный разряд влево. После этого новая цифра добавляется справа.

В решении получение цифры записано сразу внутри выражения:

```c
reversed = reversed * 10 + number % 10;
```

## 5. Алгоритм

1. Прочитать число.
2. Установить результат в `0`.
3. Пока исходное число больше нуля:
    - взять его последнюю цифру;
    - добавить её справа к результату;
    - удалить последнюю цифру исходного числа.
4. Вывести результат.

## 6. Пошаговый пример

Вход:

```text
120
```

| Число до шага | Последняя цифра | Новый результат | Остаток числа |
| --- | --- | --- | --- |
| `120` | `0` | `0 * 10 + 0 = 0` | `12` |
| `12` | `2` | `0 * 10 + 2 = 2` | `1` |
| `1` | `1` | `2 * 10 + 1 = 21` | `0` |

Вывод:

```text
21
```

Начальный ноль не сохраняется, потому что результат хранится как число.

## 7. Особые случаи и границы

### Исходное число равно нулю

Цикл не выполняется. Начальное значение `reversed` уже равно `0`, поэтому вывод правильный.

### В числе есть внутренние нули

Они обрабатываются как обычные цифры и занимают свой разряд:

```text
102 → 201
```

### Переполнение

По условию число содержит не более девяти цифр. Развёрнутое значение также не превышает `999999999` и помещается в 32-битный знаковый `int`.

Для произвольного большого `int` такой гарантии уже не было бы.

Время работы — `O(d)`, где `d` — количество цифр. Дополнительная память — `O(1)`.

## 8. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Прибавлять цифры без умножения результата на 10 | Получится сумма цифр |
| Не уменьшать исходное число | Цикл не завершится |
| Делить число до получения последней цифры | Первая извлекаемая цифра потеряется |
| Печатать цифры сразу по одной | Для `120` получится `021`, а нужен результат `21` |
| Не инициализировать результат | Используется неопределённое значение |
| Добавить перенос строки | Нарушится формат ответа |
