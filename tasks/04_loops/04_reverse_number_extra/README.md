## EXAM_04_04. Разворот числа

### Задание

| EXAM_07_07 ||
| ------ | ------- |
| **Уровень:** | 2 |
| **Темы:** | Циклы, целочисленное деление, остаток от деления, обработка цифр. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, располагающую цифры неотрицательного целого числа в обратном порядке.

Число задаётся через стандартный поток ввода stdin. Полученный результат необходимо вывести как целое число на стандартный поток вывода stdout.

Ведущие нули результата не выводятся. Если исходное число равно нулю, вывести `0`.

В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется, что на вход подаётся целое число от `0` до `999999999` включительно.
- Отрицательные числа обрабатывать не требуется.
- Решение должно использовать арифметические операции и цикл.
- Использовать строки и массивы для хранения цифр запрещено.
- Исходное число содержит не более девяти цифр, поэтому результат помещается в 32-битный знаковый тип `int`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| `123` | `321` |
| `120` | `21` |
| `1000` | `1` |
| `7` | `7` |
| `0` | `0` |
| `10203` | `30201` |
