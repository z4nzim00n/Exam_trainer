# EXAM_04_02. Поиск наибольшего — теория

> Описание задания реконструировано. Здесь разбирается приведённое решение: поиск максимума среди неотрицательных целых чисел до `-1`.

## 1. С чего начать

Нужно читать числа по одному и запоминать наибольшее.

Число `-1` обозначает конец последовательности и не является её элементом.

Например:

```text
1 2 3 4 3 2 1 -1
```

Наибольшее число здесь — `4`. Его и нужно вывести.

Количество элементов заранее неизвестно, поэтому потребуется цикл.

## 2. Нужно ли хранить всю последовательность

Нет. Достаточно двух переменных:

- `x` — очередное прочитанное число;
- `max` — текущий максимум.

После чтения каждого элемента проверяем:

```text
Если x больше max → записываем x в max.
Иначе → оставляем max без изменений.
```

Уже обработанные числа хранить не нужно: вся необходимая информация о них содержится в текущем максимуме.

## 3. Почему максимум начинается с нуля

В решении используется:

```c
int max = 0;
```

Это подходит, потому что элементы последовательности **неотрицательные**: каждый из них не меньше нуля.

- Если встретится положительное число, оно заменит начальный максимум.
- Если все элементы равны нулю, ответ останется равным нулю.

Для задачи с произвольными отрицательными элементами такой подход уже не подошёл бы:

```text
Последовательность: -8, -3, -5
Настоящий максимум: -3
Начальное значение 0 ошибочно осталось бы ответом.
```

Начальное значение нужно выбирать с учётом ограничений задачи.

## 4. Алгоритм решения

1. Установить текущий максимум равным `0`.
2. Прочитать очередное целое число.
3. Если чтение не удалось или прочитано `-1` — завершить цикл.
4. Если число больше текущего максимума — обновить максимум.
5. Повторить чтение.
6. Вывести найденный максимум без переноса строки.

## 5. Что понадобится из C

### Переменные типа `int`

Работаем с целыми числами:

```c
int x;
int max = 0;
```

`x` получает новое значение при каждом успешном чтении. `max` сохраняет наибольшее найденное значение между итерациями цикла.

### Чтение в условии цикла

```c
while (scanf("%d", &x) == 1 && x != -1) {
    /* Обработка числа. */
}
```

Перед каждой итерацией программа:

1. Пытается прочитать одно целое число.
2. Проверяет успешность чтения.
3. Проверяет, что число не равно `-1`.

Тело цикла выполняется, только если обе проверки пройдены.

Для чтения `int` используется `%d`. Запись `&x` передаёт адрес переменной, в которую нужно записать число.

При успешном чтении одного значения `scanf` возвращает `1`.

Пробелы и переводы строк между числами пропускаются при чтении через `%d`.

### Логическое «И»: `&&`

В условии:

```c
scanf("%d", &x) == 1 && x != -1
```

должны быть истинны обе части.

При этом `&&` использует короткое замыкание: если левая часть ложна, правая не вычисляется.

Поэтому при неудачном чтении программа не проверяет значение `x`, а сразу выходит из цикла.

### Почему `-1` не обрабатывается

После чтения `-1` условие:

```c
x != -1
```

становится ложным.

Тело цикла не выполняется, поэтому признак конца не сравнивается с максимумом.

Ноль, напротив, является допустимым элементом и не завершает цикл.

### Обновление максимума

```c
if (x > max) {
    max = x;
}
```

Если новое число больше сохранённого максимума, заменяем максимум.

Если число меньше или равно максимуму, ничего делать не нужно.

Не путай сравнение и присваивание:

```c
x > max;  /* Сравнение. */
max = x;  /* Запись значения x в max. */
```

### Вывод

```c
printf("%d", max);
```

Максимум имеет тип `int`, поэтому используется `%d`.

Не добавляем `\n`, пробелы или поясняющий текст.

## 6. Пошаговый разбор

Вход:

```text
2 5 3 7 0 -1
```

До начала цикла:

```text
max = 0
```

| Прочитано | Проверка или действие | Значение max |
| --- | --- | --- |
| `2` | `2 > 0` — обновляем | `2` |
| `5` | `5 > 2` — обновляем | `5` |
| `3` | `3 > 5` — ложь, не меняем | `5` |
| `7` | `7 > 5` — обновляем | `7` |
| `0` | `0 > 7` — ложь, не меняем | `7` |
| `-1` | Завершаем цикл | `7` |

Результат:

```text
7
```

После каждого обработанного элемента `max` содержит наибольшее из уже прочитанных чисел. После завершения последовательности это и есть ответ.

## 7. Что важно знать о реконструкции

Приведённый код не выводит `n/a`: такого требования в восстановленном условии нет.

Если чтение не удалось, цикл заканчивается и программа выводит накопленный максимум.

Если сразу ввести `-1`, программа выведет `0`, потому что начальное значение `max` не изменится. Это поведение кода, а не установленный ответ для пустой последовательности: в реконструкции этот случай не уточнён.

## 8. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Не инициализировать `max` | Первое сравнение будет использовать неопределённое значение |
| Записывать каждое число в `max` без сравнения | Получится последнее число, а не наибольшее |
| Использовать `x < max` | Это проверка для поиска меньшего значения |
| Завершать цикл на нуле | Ноль допустим; признак конца — `-1` |
| Читать фиксированное количество чисел | Длина последовательности заранее неизвестна |
| Забыть проверку результата `scanf` | При ошибке чтения цикл может работать неправильно |
| Добавить перенос строки | По условию его быть не должно |
