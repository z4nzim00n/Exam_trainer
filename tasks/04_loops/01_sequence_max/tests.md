# EXAM_04_02. Поиск наибольшего — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход               | Результат | Команда                             | Пояснение                       |
| ------------------ | --------- | ----------------------------------- | ------------------------------- |
| `1000 -1`          | `1000`    | `echo "1000 -1" \| ./main`          | единственный элемент — максимум |
| `1 2 3 4 3 2 1 -1` | `4`       | `echo "1 2 3 4 3 2 1 -1" \| ./main` | `4` — максимальное значение     |
| `5 5 5 -1`         | `5`       | `echo "5 5 5 -1" \| ./main`         | все числа равны                 |
| `3 -1`             | `3`       | `echo "3 -1" \| ./main`             | один элемент                    |
| `0 -1`             | `0`       | `echo "0 -1" \| ./main`             | ноль — допустимое значение      |
| `1 0 5 2 -1`       | `5`       | `echo "1 0 5 2 -1" \| ./main`       | максимум находится в середине   |

## Важные случаи

| Вход              | Результат | Команда                            | Пояснение                         |
| ----------------- | --------- | ---------------------------------- | --------------------------------- |
| `100 50 20 10 -1` | `100`     | `echo "100 50 20 10 -1" \| ./main` | максимум находится в начале       |
| `1 2 3 -1 100`    | `3`       | `echo "1 2 3 -1 100" \| ./main`    | после `-1` ввод не обрабатывается |
| `0 0 0 -1`        | `0`       | `echo "0 0 0 -1" \| ./main`        | все элементы равны нулю           |

> `-1` является сентинелом — он обозначает конец последовательности и не участвует в поиске максимума.

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Нужен для поиска проблем с памятью во время выполнения программы.

```bash
echo "1 2 3 4 -1" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
