# EXAM_03_02. Перевод в градусную меру — теория

## 1. С чего начать

Радианы и градусы — два способа измерения углов.

Нам дают угол в радианах, а вывести нужно тот же угол в градусах, округлённый до целого числа.

По условию используем соотношение:

```text
1 радиан = 57.29 градуса
```

Значит, для перевода достаточно умножить введённое число на `57.29`:

```text
градусы = радианы × 57.29
```

> В математике точный коэффициент перевода равен `180 / π`. Здесь используем приближение `57.29`, указанное в задании. Для некоторых входов замена коэффициента может изменить округлённый результат.

## 2. Алгоритм решения

1. Прочитать угол в радианах.
2. Если число не удалось прочитать — вывести `n/a` и завершить программу.
3. Умножить радианы на `57.29`.
4. Округлить результат до целого.
5. Вывести его без дробной части и без переноса строки.

**Отрицательный угол допустим.** В отличие от радиуса шара, угол может быть отрицательным. Ограничения из предыдущей задачи сюда переносить не нужно.

## 3. Что понадобится из C

### Тип `double`

Угол может быть дробным, например `0.5`. Для его хранения используем `double`:

```c
double radians;
```

Результат перевода также храним в `double`, чтобы не потерять дробную часть до округления.

### Ввод и его проверка

Для чтения `double` через `scanf` нужен формат `%lf`:

```c
scanf("%lf", &radians);
```

`&radians` — адрес переменной, в которую функция запишет число.

`scanf` возвращает количество успешно прочитанных и записанных значений. Ожидаем одно число, поэтому проверяем, что результат равен `1`:

```c
if (scanf("%lf", &radians) != 1) {
    printf("n/a");
    return 0;
}
```

`return 0;` завершает программу. Если чтение не удалось, до вычислений выполнение не дойдёт.

> Такая проверка обнаруживает неудачное чтение, но не проверяет весь ввод целиком. Например, `1abc` может быть прочитано как `1`, а `nan` и `inf` требуют отдельных проверок.

### Перевод в градусы

Формула напрямую записывается на C:

```c
double result = radians * 57.29;
```

Число `57.29` записывается через точку, не через запятую.

### Округление

Для округления используем функцию `round()` из заголовка:

```c
#include <math.h>
```

Она округляет до ближайшего целого, а точные половины — от нуля:

```text
 57.29 →  57
114.58 → 115
   2.5 →   3
  -2.5 →  -3
```

Результат `round()` остаётся значением типа `double`.

Простое преобразование в `int` не заменяет округление:

```c
(int)114.58
```

Получится `114`, потому что дробная часть отбрасывается. По условию нужен результат `115`.

### Вывод без переноса строки

```c
printf("%.0lf", round(result));
```

Формат `%.0lf` выводит число без знаков после десятичной точки.

Не добавляем `\n`, потому что условие запрещает перенос строки в конце ответа. Также не выводим знак градуса, приглашение к вводу и другой дополнительный текст.

## 4. Разбор примеров

### Вход: `1`

```text
1 × 57.29 = 57.29
После округления: 57
```

### Вход: `2`

```text
2 × 57.29 = 114.58
После округления: 115
```

### Вход: `0.5`

```text
0.5 × 57.29 = 28.645
После округления: 29
```

### Вход: `-1`

```text
-1 × 57.29 = -57.29
После округления: -57
```

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Делить на `57.29` | Для перевода из радиан в градусы нужно умножать |
| Запретить отрицательные значения | Угол может быть отрицательным; в условии запрета нет |
| Использовать `%f` в `scanf` для `double` | При чтении `double` нужен `%lf` |
| Не проверить результат `scanf` | При неудачном чтении можно использовать неинициализированную переменную |
| Преобразовать результат в `int` вместо округления | Дробная часть отбросится, а не округлится |
| Округлить радианы до перевода | Потеряется часть исходного угла |
| Добавить `\n` или поясняющий текст | Вывод не будет соответствовать условию |
