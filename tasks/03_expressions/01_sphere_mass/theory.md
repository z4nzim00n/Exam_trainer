# EXAM_03_01. Масса шара — теория

## 1. С чего начать

По условию известны:

- радиус шара `R`, который вводит пользователь;
- плотность платины `ρ = 21500 кг/м³`.

Нужно найти массу шара в килограммах.

Плотность показывает, сколько весит один кубический метр вещества. Поэтому сначала нужно вычислить объём шара, а затем умножить его на плотность:

```text
Радиус → объём → масса
```

## 2. Какие формулы нужны

Объём шара:

```text
V = (4 / 3) × π × R³
```

Плотность связана с массой и объёмом формулой:

```text
ρ = m / V
```

Выразим массу:

```text
m = ρ × V
```

Для платины:

```text
m = 21500 × V
```

Переводить единицы измерения не требуется: радиус задан в метрах, объём получится в кубических метрах, а масса — в килограммах.

## 3. Алгоритм решения

1. Прочитать радиус.
2. Проверить, удалось ли прочитать число.
3. Проверить, что радиус не отрицательный.
4. Если проверка не пройдена — вывести `n/a` и завершить программу.
5. Вычислить объём шара.
6. Умножить объём на плотность платины.
7. Округлить итоговую массу и вывести её без дробной части.

Радиус `0` не является отрицательным. В этом случае и объём, и масса будут равны нулю.

## 4. Как выразить это на C

### Тип `double`

Радиус может быть дробным, например `0.5`. Для его хранения подходит вещественный тип `double`:

```c
double radius;
```

Объём и массу тоже стоит хранить в `double`.

По сравнению с `float` этот тип обычно обеспечивает большую точность. Здесь она важна: погрешность вычислений может повлиять на итоговое округление.

### Ввод через `scanf`

Для чтения `double` используется спецификатор `%lf`:

```c
scanf("%lf", &radius);
```

Знак `&` позволяет передать адрес переменной. По этому адресу `scanf` записывает прочитанное значение.

Сама функция возвращает количество значений, которые удалось прочитать и записать. Мы ожидаем одно число, поэтому успешный результат — `1`:

```c
if (scanf("%lf", &radius) != 1) {
    printf("n/a");
    return 0;
}
```

Если число не прочитано, использовать `radius` в вычислениях нельзя.

### Проверка радиуса

Отрицательный радиус недопустим:

```c
radius < 0
```

Проверку чтения и проверку знака можно объединить:

```c
if (scanf("%lf", &radius) != 1 || radius < 0) {
    printf("n/a");
    return 0;
}
```

Оператор `||` означает логическое «ИЛИ»: достаточно хотя бы одного из двух условий.

В C правая часть `||` не вычисляется, если левая уже истинна. Поэтому при неудачном чтении проверка `radius < 0` не выполняется.

> Эта простая проверка обнаруживает неудачное чтение и отрицательный радиус, но не проверяет весь ввод целиком. Например, `scanf` может прочитать число из начала строки `1abc`; специальные значения `nan` и `inf` также требуют отдельных проверок. Точные требования к таким случаям в условии не расписаны.

### Деление `4 / 3`

В C результат деления зависит от типов операндов:

```c
4 / 3
```

Оба числа целые, поэтому выполняется целочисленное деление. Результат — `1`, а дробная часть отбрасывается.

Для формулы объёма нужно вещественное деление:

```c
4.0 / 3.0
```

Результат будет примерно равен `1.333333`.

Важно: запись результата в `double` не исправит уже выполненное целочисленное деление:

```c
double coefficient = 4 / 3;  /* Получится 1.0 */
```

### Куб радиуса

Куб числа — это произведение трёх одинаковых множителей:

```c
radius * radius * radius
```

Для такой небольшой степени обычного умножения достаточно.

**Оператор `^` в C не означает возведение в степень.** Это оператор побитового исключающего ИЛИ.

### Число π

В условии рекомендуется использовать `M_PI`:

```c
#include <math.h>
```

Тогда выражение для объёма выглядит так:

```c
double V = (4.0 / 3.0) * M_PI * (radius * radius * radius);
```

> `M_PI` — распространённая константа, но стандарт ISO C не гарантирует её наличие. Доступность зависит от среды и режима компиляции.

### Вычисление массы

Когда объём известен, остаётся умножить его на плотность:

```c
double m = 21500.0 * V;
```

Отдельные переменные для объёма и массы помогают сопоставить код с формулами и проверить каждый этап.

### Округление и вывод

Функция `round()` из `<math.h>` округляет число до ближайшего целого:

```text
12.3 → 12
12.5 → 13
12.8 → 13
```

При точном попадании на половину она округляет от нуля. Возвращаемый тип при этом остаётся `double`.

Округлять нужно итоговую массу:

```c
round(m)
```

Не стоит округлять объём перед умножением на плотность: так потеряется точность промежуточного результата.

Для вывода используем формат из условия:

```c
printf("%.0lf", round(m));
```

Здесь `.0` задаёт вывод без знаков после десятичной точки.

Не нужно добавлять пояснения вроде `Масса:` или `кг`: программа должна выводить только требуемый результат либо `n/a`.

## 5. Проверка на примере

Пусть радиус равен `1` метру.

Объём:

```text
V = (4 / 3) × π × 1³
V ≈ 4.188790205 м³
```

Масса:

```text
m = 21500 × V
m ≈ 90058.989403 кг
```

После округления:

```text
90059
```

Для радиуса `10` масса будет в `1000` раз больше до округления, потому что:

```text
10³ = 1000
```

Итоговый вывод:

```text
90058989
```

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Написать `4 / 3` | Получится целое число `1` |
| Использовать `%f` в `scanf` для `double` | При чтении `double` нужен `%lf` |
| Забыть `&` перед переменной в `scanf` | Функции нужен адрес, куда записать число |
| Не проверить результат `scanf` | При неудачном чтении можно использовать неинициализированную переменную |
| Написать `radius ^ 3` | В C это не возведение в степень |
| Округлить объём перед вычислением массы | Потеряется точность, необходимая для итогового результата |
| Вывести дополнительный текст | Формат вывода не совпадёт с условием |
