# EXAM_03_05. Логическое выражение — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash id="1shz4e"
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход    | Результат | Команда                  | Пояснение                  |
| ------- | --------- | ------------------------ | -------------------------- |
| `1 1 1` | `1`       | `echo "1 1 1" \| ./main` | `x = 1` и `y \|\| z = 1`   |
| `0 0 0` | `0`       | `echo "0 0 0" \| ./main` | `x = 0`, выражение ложно   |
| `1 0 0` | `0`       | `echo "1 0 0" \| ./main` | `x = 1`, но `y \|\| z = 0` |
| `0 1 1` | `0`       | `echo "0 1 1" \| ./main` | `x = 0`, выражение ложно   |
| `1 1 0` | `1`       | `echo "1 1 0" \| ./main` | `x = 1` и `y = 1`          |
| `1 0 1` | `1`       | `echo "1 0 1" \| ./main` | `x = 1` и `z = 1`          |
| `0 0 1` | `0`       | `echo "0 0 1" \| ./main` | `x = 0`, выражение ложно   |

## Некорректные данные (`n/a`)

| Вход      | Ожидаемый результат | Команда                    | Причина                      |
| --------- | ------------------- | -------------------------- | ---------------------------- |
| `100 0 1` | `n/a`               | `echo "100 0 1" \| ./main` | `x` не равен `0` или `1`     |
| `abc`     | `n/a`               | `echo "abc" \| ./main`     | значения не являются числами |
| `1 2 0`   | `n/a`               | `echo "1 2 0" \| ./main`   | `y` не равен `0` или `1`     |
| `1 0 -1`  | `n/a`               | `echo "1 0 -1" \| ./main`  | `z` не равен `0` или `1`     |

> По условию каждая переменная должна принимать только значение `0` или `1`.

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash id="h0uz9m"
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash id="3c0cvq"
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash id="b5n6eb"
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Нужен для поиска проблем с памятью во время выполнения программы.

```bash id="d5fl2h"
echo "1 1 1" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
