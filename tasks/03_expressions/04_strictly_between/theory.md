# EXAM_03_04. Число внутри отрезка — теория

## 1. С чего начать

Нужно определить, находится ли число `C` строго между `A` и `B`.

Если находится — вывести `1`, иначе — `0`.

Например:

```text
A = 0, B = 9, C = 4

0 < 4 < 9 → вывести 1
```

Слово **«строго»** означает, что границы не включаются:

```text
C = A → 0
C = B → 0
```

Порядок границ не задан. `A` может быть как меньше, так и больше `B`.

## 2. Как составить условие

Возможны два подходящих случая.

### Случай 1: A меньше B

Число `C` должно быть больше `A` и меньше `B`:

```c
a < c && c < b
```

Оператор `&&` означает логическое «И»: оба сравнения должны быть истинными.

### Случай 2: B меньше A

Число `C` должно быть больше `B` и меньше `A`:

```c
b < c && c < a
```

### Объединяем случаи

Подходит первый **или** второй случай:

```c
(a < c && c < b) || (b < c && c < a)
```

Оператор `||` означает логическое «ИЛИ»: достаточно, чтобы хотя бы одна часть была истинной.

Так проверка работает при любом порядке границ.

## 3. Как обойтись без `if`

По условию `if` разрешён только для обработки ошибок. Для выбора между `1` и `0` он не нужен.

В C операторы сравнения и логические операторы возвращают целое значение:

- `1` — истина;
- `0` — ложь.

Поэтому результат условия можно сразу передать в `printf`:

```c
printf("%d", (a < c && c < b) || (b < c && c < a));
```

Программа напечатает именно то, что требуется: `1` или `0`.

## 4. Алгоритм решения

1. Прочитать три целых числа: `A`, `B`, `C`.
2. Если прочитать все три числа не удалось — вывести `n/a` и завершить программу.
3. Проверить два возможных порядка: `A < C < B` или `B < C < A`.
4. Вывести результат логического выражения без переноса строки.

## 5. Что понадобится из C

### Чтение трёх целых чисел

Для хранения используем тип `int`:

```c
int a, b, c;
```

Для чтения каждого числа нужен `%d` и адрес соответствующей переменной:

```c
scanf("%d %d %d", &a, &b, &c);
```

Числа можно разделять пробелами или переводами строк.

### Проверка чтения

`scanf` возвращает количество успешно прочитанных и записанных значений. Здесь ожидаем `3`:

```c
if (scanf("%d %d %d", &a, &b, &c) != 3) {
    printf("n/a");
    return 0;
}
```

Если введено `0 abc 4`, функция не сможет прочитать второе целое число. Проверка обнаружит ошибку, и программа завершится до сравнений.

Это допустимое использование `if`: он обрабатывает ошибку ввода.

> Такая проверка подтверждает чтение трёх чисел, но не проверяет отсутствие лишнего текста после них. Например, ввод `0 9 4abc` может быть принят как три числа.

### Строгие сравнения

Используем `<`, а не `<=`:

```c
a < c
```

Оператор `<` не допускает равенства. Благодаря этому число на границе не считается находящимся строго внутри.

### Почему нельзя написать `a < c < b`

Математическая запись:

```text
A < C < B
```

не переносится в C напрямую.

Выражение:

```c
a < c < b
```

вычисляется как:

```c
(a < c) < b
```

Сначала получается `0` или `1`, а затем это значение сравнивается с `b`.

Например, при `a = 0`, `c = 10`, `b = 9`:

```text
0 < 10 → 1
1 < 9  → 1
```

Получилась истина, хотя `10` не находится между `0` и `9`.

Правильная запись:

```c
a < c && c < b
```

### Вывод

Используем `%d`, потому что логическое выражение даёт целое значение:

```c
printf("%d", (a < c && c < b) || (b < c && c < a));
```

Не добавляем `\n`, пробелы и пояснения: по условию нужен только результат без переноса строки.

## 6. Разбор примеров

### Вход: `0 9 4`

```text
0 < 4 и 4 < 9 → истина
Результат: 1
```

### Вход: `9 0 4`

Границы идут в обратном порядке, поэтому срабатывает вторая часть условия:

```text
0 < 4 и 4 < 9 → истина
Результат: 1
```

### Вход: `0 1 4`

```text
4 не находится между 0 и 1
Результат: 0
```

### Вход: `0 9 9`

`C` совпадает с границей `B`. Строгое сравнение `c < b` ложно:

```text
Результат: 0
```

### Вход: `0 0 0`

Границы совпадают. Между ними нет чисел:

```text
Результат: 0
```

## 7. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Проверить только `a < c && c < b` | Не учитывается обратный порядок границ |
| Использовать `<=` вместо `<` | Число на границе ошибочно будет считаться подходящим |
| Написать `a < c < b` | В C это последовательные сравнения, а не проверка диапазона |
| Написать `a < c || c < b` | Выполнения только одного сравнения недостаточно |
| Использовать `if` для выбора между `1` и `0` | По условию `if` разрешён только для обработки ошибок |
| Проверить результат `scanf` на равенство `1` | Нужно успешно прочитать три значения |
