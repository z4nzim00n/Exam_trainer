# EXAM_03_03. Перестановка цифр — Тесты

## Компиляция

Все файлы решения собираются с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход   | Результат | Команда                 | Пояснение                                 |
| ------ | --------- | ----------------------- | ----------------------------------------- |
| `159`  | `951`     | `echo "159" \| ./main`  | первая и последняя цифры меняются местами |
| `120`  | `021`     | `echo "120" \| ./main`  | ведущий ноль сохраняется                  |
| `-123` | `-321`    | `echo "-123" \| ./main` | знак `-` остаётся на месте                |
| `777`  | `777`     | `echo "777" \| ./main`  | все цифры одинаковые                      |
| `951`  | `159`     | `echo "951" \| ./main`  | перестановка возвращает исходное число    |
| `100`  | `001`     | `echo "100" \| ./main`  | два ведущих нуля сохраняются              |
| `-101` | `-101`    | `echo "-101" \| ./main` | первая и последняя цифры одинаковые       |

## Некорректные данные

> По условию на вход гарантированно подаётся трёхзначное число, поэтому эти тесты находятся за пределами гарантированного ввода.

| Вход   | Ожидаемый результат | Команда                 | Причина                        |
| ------ | ------------------- | ----------------------- | ------------------------------ |
| `10`   | —                   | `echo "10" \| ./main`   | не является трёхзначным числом |
| `1234` | —                   | `echo "1234" \| ./main` | четырёхзначное число           |
| `abc`  | —                   | `echo "abc" \| ./main`  | не является целым числом       |

### Cppcheck

Статический анализ кода.

Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Нужен для поиска проблем с памятью во время выполнения программы.

```bash
echo "159" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
