# EXAM_03_03. Перестановка цифр — теория

## 1. С чего начать

Нужно поменять местами первую и последнюю цифры трёхзначного числа. Средняя цифра остаётся на месте:

```text
159 → 951
```

При этом важно:

- сохранить ведущие нули: `120 → 021`;
- сохранить знак отрицательного числа: `-123 → -321`;
- не добавлять перенос строки в конце ответа.

По условию на входе всегда целое трёхзначное число. Проверять количество цифр не требуется.

## 2. Как получить отдельные цифры

Для положительного целого числа используем две операции:

- `% 10` — получить последнюю цифру;
- `/ 10` — убрать последнюю цифру.

Например:

```text
159 % 10 = 9
159 / 10 = 15
```

Почему это работает?

При делении на `10` остаток — это количество единиц, то есть последняя цифра. А целочисленное деление отбрасывает дробную часть, оставляя число без последней цифры.

Повторяем эти действия:

| Текущее число | Действие | Результат |
| --- | --- | --- |
| `159` | `159 % 10` | `9` — последняя цифра |
| `159` | `159 / 10` | `15` — оставшаяся часть |
| `15` | `15 % 10` | `5` — средняя цифра |
| `15` | `15 / 10` | `1` — оставшаяся часть |
| `1` | `1 % 10` | `1` — первая цифра |

Полученные цифры нужно вывести в порядке:

```text
последняя → средняя → первая
```

## 3. Что делать с отрицательным числом

Минус — не цифра. Его не нужно переставлять: он должен остаться перед результатом.

Удобно разделить работу:

1. Сохранить исходное число для проверки знака.
2. Выделять цифры из его положительной копии.
3. Перед цифрами вывести минус, если исходное число отрицательное.

Для входа `-123`:

```text
Исходное число: -123
Положительная копия: 123
Цифры в обратном порядке: 321
Результат со знаком: -321
```

Так не придётся работать с отрицательными остатками от деления.

## 4. Алгоритм решения

1. Прочитать число в переменную `n`.
2. Записать в `value` его положительное значение.
3. Получить последнюю цифру через `% 10`.
4. Убрать последнюю цифру через `/ 10`.
5. Получить среднюю цифру через `% 10`.
6. Снова убрать последнюю цифру через `/ 10`.
7. Получить первую цифру.
8. Если `n` отрицательное — вывести минус.
9. Вывести последнюю, среднюю и первую цифры без разделителей.

## 5. Что понадобится из C

### Чтение целого числа

Для хранения числа подходит тип `int`:

```c
int n;
```

Чтение выполняется через `%d`:

```c
scanf("%d", &n);
```

`&n` — адрес переменной, куда `scanf` запишет значение.

При успешном чтении одного числа функция возвращает `1`:

```c
if (scanf("%d", &n) != 1) {
    return 1;
}
```

Если прочитать число не удалось, программа завершается до вычислений. Вывод `n/a` в этой задаче не требуется: условие гарантирует корректный ввод.

### Положительная копия числа

```c
int value;
if (n < 0) {
    value = -n;
} else {
    value = n;
}
```

Если `n` равно `-123`, выражение `-n` даст `123`.

Если `n` уже положительное, просто копируем его.

Исходное `n` не меняем — его знак понадобится при выводе.

### Выделение цифр

```c
int last = value % 10;
value = value / 10;
```

Первая строка сохраняет последнюю цифру. Вторая изменяет `value`, убирая эту цифру.

Таким же способом получаем остальные цифры.

Здесь целочисленное деление полезно:

```text
159 / 10 = 15
```

Вещественное деление на `10.0` для выделения цифр не нужно.

### Вывод минуса

```c
if (n < 0) {
    putchar('-');
}
```

`putchar()` выводит один символ. Символ `'-'` записывается в одинарных кавычках.

### Сохранение ведущих нулей

Если собрать переставленные цифры в обычное целое число, ведущие нули не сохранятся:

```text
Для 120 переставленные цифры: 0, 2, 1
Как целое число это 21
Но по условию нужен вывод 021
```

Простой способ сохранить нули — вывести каждую цифру отдельно:

```c
printf("%d%d%d", last, middle, first);
```

Каждый `%d` выводит соответствующую цифру, даже если это `0`.

Между спецификаторами нет пробелов, поэтому цифры выводятся подряд. В конце нет `\n`, как и требует условие.

## 6. Разбор примера с минусом и нулями

Пусть введено `-100`.

Сохраняем положительную копию:

```text
value = 100
```

Выделяем цифры:

```text
last = 100 % 10 = 0
value = 100 / 10 = 10

middle = 10 % 10 = 0
value = 10 / 10 = 1

first = 1 % 10 = 1
```

Исходное число отрицательное, поэтому сначала выводим минус. Затем выводим три цифры:

```text
-001
```

Знак минус не входит в количество цифр.

## 7. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Перепутать `% 10` и `/ 10` | Первая операция получает последнюю цифру, вторая убирает её |
| Выделять цифры прямо из отрицательного числа | Остатки могут быть отрицательными; проще отдельно обработать знак |
| Изменить `n` и потерять первоначальный знак | При выводе нужно знать, было ли исходное число отрицательным |
| Собрать результат в число и вывести обычным `%d` | Ведущие нули не отобразятся |
| Вывести пробелы между цифрами | Требуется одно число без разделителей |
| Добавить `\n` в конце | Условие запрещает завершающий перенос строки |
