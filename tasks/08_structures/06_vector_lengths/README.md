# EXAM_08_06. Сумма длин векторов

## Задание

| EXAM_08_06                  | |
|-----------------------------|---|
| **Уровень:**                | 4 |
| **Темы:**                   | Структуры, динамические массивы, математические функции. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Описать структуру «вектор» с полями x, y, z (целые числа). Написать программу, осуществляющую заполнение массива из N векторов, где N задаётся на стандартном потоке ввода stdin. Для каждого вектора вводятся три числа: x, y, z.

После заполнения массива вводится длина D (целое или вещественное число). Необходимо посчитать сумму длин всех векторов массива, длина которых **строго больше** D. Найденную сумму математически округлить до целого и вывести на стандартный поток вывода stdout. Если таких векторов нет, вывести 0. Переноса строки в конце быть не должно. Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Длина вектора: sqrt(x * x + y * y + z * z).

Примечание: В этом задании важна точность, поэтому советуем использовать double. Для корня и округления используйте функции sqrt и round из библиотеки <math.h>.

## Примеры

| Входные данные | Результат работы |
|---|---|
| `2`<br>`0 0 0`<br>`5 5 5`<br>`2` | `9` |
| `3`<br>`1 1 1`<br>`2 2 2`<br>`3 3 3`<br>`4` | `5` |
| `2`<br>`1 1 1`<br>`2 2 2`<br>`0` | `5` |
