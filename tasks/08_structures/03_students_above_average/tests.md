# EXAM_08_03. Студенты выше среднего балла — Тесты

## Компиляция

```
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

Многострочный ввод удобно подавать через `printf`: `\n` внутри него означает перевод строки.

| Вход | Результат | Команда | Пояснение |
|---|---|---|---|
| `3` `Andrey` `15` `Sergey` `20` `Anton` `10` | `Sergey` | `printf '3\nAndrey\n15\nSergey\n20\nAnton\n10\n' \| ./main` | Andrey равен среднему (15), он не выводится |
| `4` `Alice` `50` `Bob` `80` `Carol` `60` `Dave` `90` | `Bob, Dave` | `printf '4\nAlice\n50\nBob\n80\nCarol\n60\nDave\n90\n' \| ./main` | среднее 70; порядок вывода как при вводе |
| `2` `A` `5` `B` `5` | (пусто) | `printf '2\nA\n5\nB\n5\n' \| ./main` | все равны среднему, никто не выше |
| `1` `Solo` `50` | (пусто) | `printf '1\nSolo\n50\n' \| ./main` | единственный студент равен среднему |
| `3` `A` `0` `B` `0` `C` `10` | `C` | `printf '3\nA\n0\nB\n0\nC\n10\n' \| ./main` | среднее 3.33: проверка, что деление не целочисленное |

## Некорректные данные (n/a)

| Вход | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `0` | `n/a` | `echo "0" \| ./main` | студентов не может быть 0 |
| `-1` | `n/a` | `echo "-1" \| ./main` | отрицательное количество |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| `2` `A` `5` | `n/a` | `printf '2\nA\n5\n' \| ./main` | данных второго студента нет |
| `1` `A` `x` | `n/a` | `printf '1\nA\nx\n' \| ./main` | оценка не число |

## Cppcheck

Статический анализ кода. Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

Проверка стиля и форматирования кода.

```
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```
clang-format -i main.c
```

## Valgrind

Проверка ошибок работы с памятью. В этом решении нет `malloc`, но проверка полезна для контроля выхода за границы массива.

```
printf '3\nAndrey\n15\nSergey\n20\nAnton\n10\n' | valgrind --leak-check=full ./main
```

Обратите внимание: Valgrind запускается уже на скомпилированном файле.
