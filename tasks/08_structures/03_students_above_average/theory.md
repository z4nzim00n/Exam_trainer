# Студенты выше среднего балла — теория

## 1. С чего начать

Нужно вывести имена студентов, чья оценка выше среднего. Чтобы узнать среднее, надо сначала прочитать **всех**, и только потом сравнивать. Поэтому данные хранятся в массиве структур.

```
прочитать n → прочитать всех, копя сумму → среднее → вывести подходящих
```

## 2. Каркас решения (его стоит запомнить)

1. `typedef struct { char name[100]; int rate; } Student;`
2. `scanf("%d", &n)` и проверка `n < 1`.
3. `Student students[n];` и `long sum = 0;`
4. Цикл чтения: имя, оценка, `sum += rate`.
5. `double avg = (double)sum / n;`
6. Цикл вывода: `if (rate > avg)`, `, ` перед всеми, кроме первого.

## 3. Как выразить это на C

### Структура

```c
typedef struct {
    char name[100];
    int rate;
} Student;
```

Структура объединяет поля в один тип, `typedef` даёт ему имя `Student`. Для имени в 99 символов нужен массив на 100: одно место занимает `'\0'`.

### Массив структур

```c
Student students[n];
```

Обращение к полям через точку: `students[i].name`, `students[i].rate`.

### Чтение

```c
scanf("%99s", students[i].name);
scanf("%d", &students[i].rate);
```

- у строки нет `&`: имя массива уже адрес;
- у числа `&` есть;
- `99` защищает массив от переполнения;
- `%s` и `%d` сами пропускают пробелы и переводы строк между значениями.

### Среднее

```c
double avg = (double)sum / n;
```

Без `(double)` деление целочисленное: `17 / 2` даст `8`, а не `8.5`.

### Выше среднего

`rate > avg` — строго выше. Студент с оценкой, равной среднему, не попадает в вывод.

### Запятая только между именами

```c
if (!first) printf(", ");
printf("%s", students[i].name);
first = 0;
```

## 4. Проверка на примере

```
3
Andrey
15
Sergey
20
Anton
10
```

Сумма 45, среднее 15. Andrey 15 не выше, Sergey 20 выше, Anton 10 не выше. Вывод: `Sergey`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `scanf("%s", &students[i].name)` | Лишний `&`, ошибка компиляции с `-Werror` |
| `%s` без ширины | Длинное имя переполнит массив |
| Забыть `&` перед `rate` | Программа упадёт |
| `avg = sum / n` с целыми | Дробная часть потеряется |
| Считать среднее до окончания чтения | Среднее будет неверным |
| `>=` вместо `>` | Студент, равный среднему, попадёт в вывод |
| `, ` после каждого имени | Лишняя запятая в конце |
| `students[i]->rate` | После `[i]` нужна точка |
