# Звёзды Голливуда — теория

## 1. С чего начать

Ввод: количество людей, затем у каждого имя, фамилия и рост. В самом конце имя, по которому ищем.

Вывести нужно фамилии всех, чьё имя совпало, затем `:` и средний рост этих людей. Искомое имя приходит **после** всех людей, значит сначала читаем всех в массив, потом ищем.

```
прочитать n → прочитать всех → прочитать искомое имя → посчитать → вывести
```

## 2. Каркас решения (его стоит запомнить)

1. `#include <math.h>`, `#include <string.h>` и структура `Person`.
2. `scanf("%d", &n)` и проверка `n < 1`.
3. `Person people[n];` и цикл чтения.
4. `scanf("%99s", search)`.
5. Цикл 1: `strcmp == 0` → `count++`, `sum += height`.
6. Цикл 2: печатаем фамилии, `, ` перед всеми, кроме первой.
7. `if (count > 0)` печатаем `: средний рост`, иначе `n/a`.

## 3. Как выразить это на C

### Структура

```c
typedef struct {
    char name[100];
    char surname[100];
    int height;
} Person;
```

### Чтение трёх значений за раз

```c
scanf("%99s %99s %d", people[i].name, people[i].surname, &people[i].height) != 3
```

`scanf` возвращает число прочитанных значений. Нужны все три. У строк нет `&`, у числа есть.

### Сравнение строк: strcmp

```c
strcmp(search, people[i].name) == 0
```

`strcmp` возвращает 0, когда строки одинаковы. Оператор `==` для строк сравнивает адреса, а не содержимое.

### Формат вывода

Фамилии через `, `, затем `: ` и число. Для `John Wick 190` и `John King 180` получается `Wick, King: 185`.

### Среднее и математическое округление

```c
printf(": %.0f", round((double)sum / count));
```

- `(double)` не даёт делению стать целочисленным;
- `round` из `math.h` округляет «как в школе»: `182.5` → `183`;
- голый `%.0f` без `round` округляет ровно половину к чётному (`182.5` → `182`), поэтому в этом задании не подходит;
- `round` требует компиляции с `-lm`.

### Что если никого не нашли

Цикл печати ничего не выведет, `count == 0`, срабатывает `else` и печатается `n/a`. Делить на `count` в этом случае нельзя, поэтому деление стоит внутри `if (count > 0)`.

## 4. Проверка на примере

```
2
John
Wick
190
John
King
180
John
```

Ищем `John`: Wick (190), King (180). `count = 2`, `sum = 370`, среднее 185.

Вывод: `Wick, King: 185`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `people[i].name == search` | Сравниваются адреса, а не строки |
| Нет `#include <string.h>` | `strcmp` не объявлен, ошибка с `-Werror` |
| Нет `-lm` при компиляции | `round` не найден при сборке |
| Только `%.0f` без `round` | `182.5` станет `182` |
| `scanf("%s", &people[i].name)` | Лишний `&`, ошибка с `-Werror` |
| Нет `&` перед `height` | Программа упадёт |
| `sum / count` с целыми | Дробная часть потеряется |
| Делить на `count` при `count == 0` | Деление на ноль |
| `, ` вместо `: ` перед ростом | Формат вывода не совпадёт |
