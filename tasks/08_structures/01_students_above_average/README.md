## EXAM_08_01. Студенты выше среднего балла

### Задание

| EXAM_08_01                  ||
|-----------------------------| ------- |
| **Уровень:**                | 3 |
| **Темы:**                   | Структуры, динамические массивы, строки. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов указывается на стандартном потоке ввода первым числом. Далее для каждого студента задаются две строки:

1. имя студента;
2. оценка (целое число).

Программа должна вычислить средний балл по всем студентам и вывести на стандартный поток вывода имена тех, чья оценка **строго выше** среднего балла, через запятую с пробелом.

Порядок вывода — в том же порядке, в котором студенты были введены.

В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Количество студентов N — целое число от 1 до 100.
- Имя студента — строка длиной до 99 символов, состоящая из латинских букв, цифр и пробелов.
- Оценка — целое число от 0 до 100.
- Средний балл вычисляется как арифметическое среднее оценок (вещественное число).
- Если ни один студент не имеет балла выше среднего, программа ничего не выводит.
- Разделитель между именами в выводе — запятая и пробел `", "`.
- После последнего имени запятой быть не должно.
- Динамическая память под массив студентов должна быть освобождена перед завершением программы.

### Пример

Входные данные:

```text
3
Andrey
15
Sergey
20
Anton
10
```

Результат работы:

```text
Sergey
```

> Средний балл: (15 + 20 + 10) / 3 = 15. Строго выше среднего только Sergey (20 > 15). Andrey (15) равен среднему и не подходит, Anton (10) ниже.

### Ещё пример

Входные данные:

```text
4
Alice
50
Bob
80
Carol
60
Dave
90
```

Результат работы:

```text
Bob, Dave
```

> Среднее: (50 + 80 + 60 + 90) / 4 = 70. Выше среднего: Bob (80) и Dave (90).

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
