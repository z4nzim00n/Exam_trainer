# EXAM_08_01. Студенты выше среднего балла

## Задание

| EXAM_08_01 | |
|---|---|
| **Уровень:** | 3 |
| **Темы:** | Структуры. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов задаётся вводом (первое число). Далее для каждого студента вводятся имя и оценка (целое число).

Вывести на стандартный поток вывода имена всех студентов, у которых оценка **выше** среднего балла, в порядке ввода, через запятую с пробелом. После последнего имени запятой и переноса строки быть не должно. Если подходящих студентов нет, ничего не выводить. Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Имя студента не содержит пробелов.

## Примеры

| Входные данные | Результат работы |
|---|---|
| `3`<br>`Andrey`<br>`15`<br>`Sergey`<br>`20`<br>`Anton`<br>`10` | `Sergey` |
| `4`<br>`Alice`<br>`50`<br>`Bob`<br>`80`<br>`Carol`<br>`60`<br>`Dave`<br>`90` | `Bob, Dave` |

Пояснение к первому примеру: средний балл (15 + 20 + 10) / 3 = 15. Строго выше только Sergey. Andrey (15) равен среднему, Anton (10) ниже.
