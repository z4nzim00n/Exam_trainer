# EXAM_08_01. Студенты выше среднего балла — теория

## 1. С чего начать

Задача разбивается на пять шагов:

1. Прочитать количество студентов N.
2. Выделить память под массив из N структур.
3. Для каждого студента прочитать имя и оценку.
4. Вычислить средний балл.
5. Пройти по массиву ещё раз и вывести имена тех, чья оценка строго выше среднего.

Здесь встречаются три важные темы C:
- **структуры** для хранения связанных данных;
- **динамическая память** для массива неизвестного заранее размера;
- **чтение строк с пробелами** через `getchar`.

## 2. Что такое структура

Структура — это способ объединить несколько переменных под одним именем:

```c
struct student {
    char name[100];
    int rate;
};
```

Теперь `struct student` — это тип. Можно создать переменную:

```c
struct student s;
s.rate = 15;
```

Обращение к полям — через точку `.` для обычных переменных и через стрелку `->` для указателей:

```c
struct student *p = &s;
p->rate = 15;
```

## 3. Почему массив, а не отдельные переменные

Количество студентов N неизвестно заранее — оно приходит на вход. Значит, нужно либо ограничить массив каким-то большим числом (например, 100), либо выделить память динамически.

**Динамическая память** — это память, выделяемая во время работы программы через `malloc`:

```c
struct student *students = malloc((size_t)n * sizeof(*students));
```

Что здесь происходит:
- `sizeof(*students)` — размер одной структуры в байтах.
- `(size_t)n * sizeof(*students)` — общий размер массива.
- `malloc` возвращает указатель на начало выделенной памяти.
- `(size_t)n` — приведение к беззнаковому типу; защита от переполнения при больших N.

Если памяти не хватило, `malloc` вернёт `NULL` — это нужно проверять:

```c
if (students == NULL) {
    return 1;
}
```

После использования память нужно освободить:

```c
free(students);
```

Иначе будет утечка памяти — Valgrind её найдёт.

## 4. Чтение количества студентов

```c
int n;
scanf("%d", &n);
```

`scanf` читает целое число, но **не читает** символ перевода строки, который пользователь нажал после числа. Этот `'\n'` остаётся в буфере ввода.

Если сразу после этого попытаться прочитать имя, первый вызов чтения строки прочитает пустую строку — тот самый оставшийся `'\n'`.

Поэтому съедаем его вручную:

```c
int ch;
while ((ch = getchar()) != EOF && ch != '\n') {
}
```

Пустое тело цикла — это нормально. Вся работа делается в условии: читаем и отбрасываем символы до `'\n'`.

## 5. Чтение имени с пробелами

Стандартный способ — `scanf("%s", ...)` — не подходит. Он останавливается на первом пробеле. Если имя `Andrey Ivanov`, будет прочитано только `Andrey`.

Правильно — читать посимвольно до `'\n'`:

```c
int len = 0;
while ((ch = getchar()) != EOF && ch != '\n') {
    if (len < NAME_MAX_LEN - 1) {
        students[i].name[len] = (char)ch;
        len++;
    }
}
students[i].name[len] = '\0';
```

Что здесь:
- Читаем по одному символу.
- Проверяем, что не вышли за границу массива.
- В конце ставим `'\0'` — так строка становится корректной C-строкой.

Функция `gets()` тоже читала строку, но её **удалили из стандарта** в C11: она небезопасна, потому что не проверяет длину. Компилятор с `-std=c11` её не примет.

`fgets()` работает и безопасна, но оставляет `'\n'` в конце строки — его нужно убирать отдельно. Наш способ через `getchar` сразу это учитывает.

## 6. Чтение оценки

```c
scanf("%d", &students[i].rate);
```

После неё снова остаётся `'\n'` в буфере — съедаем:

```c
while ((ch = getchar()) != EOF && ch != '\n') {
}
```

Это нужно, чтобы следующая итерация начала чтение имени с чистого буфера.

## 7. Средний балл

```c
long sum = 0;
for (int i = 0; i < n; i++) {
    sum += students[i].rate;
}
double avg = (double)sum / n;
```

Почему `double`, а не `int`?

Пример: оценки 10, 10, 11. Сумма 31, среднее 31/3 = 10.333...

Если считать в `int`:
```c
int avg = 31 / 3;  // = 10
```
Тогда студент с баллом 10 ошибочно окажется «равен среднему», хотя реально он ниже. Студент с баллом 11 попадёт в вывод — это правильно, но условие «строго выше среднего» будет сравниваться с округлённым значением, а не с настоящим.

С `double` получаем 10.333, и правильно определяем: 10 < 10.333, 11 > 10.333.

Приведение `(double)sum / n` заставляет деление быть вещественным. Без него — целочисленное.

## 8. Вывод через запятую

Самая частая ошибка — запятая после последнего имени:

```c
// Неправильно:
for (int i = 0; i < n; i++) {
    if (students[i].rate > avg) {
        printf("%s, ", students[i].name);  // всегда с запятой
    }
}
// Вывод: "Sergey, "  ← лишняя запятая
```

Правильный подход — **флаг первого элемента**:

```c
int first = 1;
for (int i = 0; i < n; i++) {
    if ((double)students[i].rate > avg) {
        if (!first) {
            printf(", ");
        }
        printf("%s", students[i].name);
        first = 0;
    }
}
```

Логика:
- Перед первым выведенным именем запятая не нужна — `first == 1`.
- После вывода сбрасываем `first = 0`.
- Перед всеми следующими — печатаем `", "`.

### Почему не проверять «последний ли по индексу»

Такой код кажется работающим:

```c
if (i < n - 1) {
    printf("%s, ", students[i].name);
} else {
    printf("%s", students[i].name);
}
```

Но он проверяет, последний ли студент **в массиве**, а не последний ли он **среди выводимых**.

Пример: три студента с оценками 20, 5, 5. Среднее 10. Выше среднего только первый — `A`. Он попадает в `if (i < n-1)`, выводится с запятой: `A, `. А после него больше никого не будет — получается висящая запятая.

## 9. Алгоритм целиком

1. `scanf("%d", &n)` — читаем количество.
2. Съедаем оставшийся `'\n'`.
3. `malloc((size_t)n * sizeof(*students))` — выделяем массив.
4. Проверяем `students != NULL`.
5. В цикле по N:
    - читаем имя посимвольно до `'\n'`;
    - `scanf("%d", &rate)`;
    - съедаем оставшийся `'\n'`;
    - добавляем оценку к сумме.
6. `avg = (double)sum / n`.
7. В цикле по N: если `(double)rate > avg`, выводим имя с правильным разделителем.
8. `free(students)`.

## 10. Пошаговый разбор примера

Вход:
```
3
Andrey
15
Sergey
20
Anton
10
```

**Шаг 1.** N = 3. Съедаем `'\n'`.

**Шаг 2.** Выделяем `students[3]`.

**Шаг 3.** Читаем в цикле:
- i=0: name = "Andrey", rate = 15, sum = 15
- i=1: name = "Sergey", rate = 20, sum = 35
- i=2: name = "Anton", rate = 10, sum = 45

**Шаг 4.** avg = 45.0 / 3 = 15.0

**Шаг 5.** Проходим по массиву:
- Andrey: 15.0 > 15.0? Нет.
- Sergey: 20.0 > 15.0? Да. `first == 1`, печатаем `Sergey`, `first = 0`.
- Anton: 10.0 > 15.0? Нет.

**Вывод:** `Sergey`

## 11. Особые случаи

### Все с одинаковой оценкой

Среднее равно этой оценке. Никто не «строго выше» — вывод пустой.

### Один студент

Его оценка равна среднему (сам с собой). Вывод пустой.

### N = 0

По условию N ≥ 1. Проверку добавляем в начале — если `n < 1`, завершаем программу с ошибкой.

## 12. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Использовать `gets()` | Удалена из C11 |
| `scanf("%s", name)` | Не читает имена с пробелами |
| Целочисленное среднее | Теряет дробную часть, ошибочно включает/исключает студентов |
| Запятая после последнего имени | Формат вывода нарушен |
| `if (i < n - 1)` для запятых | Проверяет не то, что нужно |
| Не съедать `'\n'` после `scanf` | Следующее чтение имени прочитает пустую строку |
| Забыть `free(students)` | Утечка памяти |
| Забыть проверить `malloc` на `NULL` | При нехватке памяти — падение |
| Забыть `'\0'` в конце имени | Строка может выводиться с мусором |
| Забыть `#include <stdlib.h>` | `malloc` и `free` не будут объявлены |
