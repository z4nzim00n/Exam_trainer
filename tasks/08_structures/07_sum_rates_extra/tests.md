# EXAM_08_07. Сумма оценок — Тесты

## Компиляция

```
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
|---|---|---|---|
| `3` `Andrey` `15` `Sergey` `20` `Anton` `10` | `45` | `printf '3\nAndrey\n15\nSergey\n20\nAnton\n10\n' \| ./main` | пример из условия |
| `1` `Solo` `7` | `7` | `printf '1\nSolo\n7\n' \| ./main` | один студент |
| `2` `A` `-5` `B` `5` | `0` | `printf '2\nA\n-5\nB\n5\n' \| ./main` | отрицательная оценка |

## Некорректные данные (n/a)

| Вход | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `0` | `n/a` | `echo "0" \| ./main` | студентов не может быть 0 |
| `-1` | `n/a` | `echo "-1" \| ./main` | отрицательное количество |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| `2` `A` `5` | `n/a` | `printf '2\nA\n5\n' \| ./main` | данных второго студента нет |
| `1` `A` `x` | `n/a` | `printf '1\nA\nx\n' \| ./main` | оценка не число |
