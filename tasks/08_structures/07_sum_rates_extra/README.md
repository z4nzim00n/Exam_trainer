# EXAM_08_07. Сумма оценок

## Задание

| EXAM_08_07 | |
|---|---|
| **Уровень:** | 1 |
| **Темы:** | Структуры. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов задаётся вводом (первое число). Далее для каждого студента вводятся имя и оценка (целое число). Вывести на стандартный поток вывода сумму оценок всех студентов. Переноса строки в конце быть не должно. Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Имя студента не содержит пробелов.

## Примеры

| Входные данные | Результат работы |
|---|---|
| `3`<br>`Andrey`<br>`15`<br>`Sergey`<br>`20`<br>`Anton`<br>`10` | `45` |
| `1`<br>`Solo`<br>`7` | `7` |

**Внимание:** Мы любезно напоминаем вам, что процедура тестирования вашей программы включает анализ стиля кода. Пожалуйста, загляните в папку "materials/".
