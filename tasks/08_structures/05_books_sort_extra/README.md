## EXAM_08_05. Книги: сортировка по году и названию

### Задание

| EXAM_08_05                  ||
|-----------------------------| ------- |
| **Уровень:**                | 4 |
| **Темы:**                   | Структуры, динамические массивы, сортировка, strcmp. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `book` с полями «название» и «год издания». Количество книг указывается на стандартном потоке ввода первым числом. Далее для каждой книги задаются две строки:

1. название книги;
2. год издания (целое число).

Программа должна отсортировать книги **по возрастанию** года издания. Если у двух книг одинаковый год, они сортируются **по алфавиту** названия (в порядке ASCII).

Вывести отсортированный список в формате `Год Название`, каждая книга на отдельной строке.

В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Количество книг N — целое число от 1 до 100.
- Название — строка длиной до 99 символов.
- Год — целое число от 1000 до 2100.
- Разрешается использовать `strcmp` из `<string.h>`.
- Динамическая память должна быть освобождена.

### Пример

Входные данные:

```text
4
Brave New World
1932
1984
1949
Animal Farm
1945
Fahrenheit 451
1953
```

Результат работы:

```text
1932 Brave New World
1945 Animal Farm
1949 1984
1953 Fahrenheit 451
```

### Ещё пример (одинаковый год)

Входные данные:

```text
3
Zoo
2000
Apple
2000
Mango
2000
```

Результат работы:

```text
2000 Apple
2000 Mango
2000 Zoo
```

> Все три книги изданы в 2000 году, поэтому сортируются по алфавиту названия.

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
