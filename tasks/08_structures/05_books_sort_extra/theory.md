# EXAM_08_05. Книги: сортировка по году и названию — теория

## 1. С чего начать

Это усложнённая версия 08_02. Там сортировка по одному полю. Здесь — по двум:

1. Сначала по году (возрастание).
2. Если годы равны — по названию (алфавит).

Такая сортировка называется **двухуровневой** или **многключевой**.

## 2. Как сравнивать два элемента

Для двух книг `a` и `b` логика такая:

```
Если a.year > b.year → a должна быть после b → меняем.
Если a.year < b.year → a должна быть перед b → не меняем.
Если a.year == b.year → сравниваем названия:
    Если a.name > b.name (по алфавиту) → меняем.
    Иначе → не меняем.
```

В коде:

```c
int swap = 0;

if (books[j].year > books[j + 1].year) {
    swap = 1;
} else if (books[j].year == books[j + 1].year) {
    if (strcmp(books[j].name, books[j + 1].name) > 0) {
        swap = 1;
    }
}
```

## 3. Функция strcmp

`strcmp(a, b)` из `<string.h>` сравнивает две строки посимвольно:

| Результат | Значение |
| --- | --- |
| `< 0` | `a` раньше `b` в алфавите |
| `== 0` | строки равны |
| `> 0` | `a` позже `b` в алфавите |

Примеры:
- `strcmp("Apple", "Zoo")` → отрицательное (A < Z).
- `strcmp("Zoo", "Apple")` → положительное (Z > A).
- `strcmp("Cat", "Cat")` → 0.

Сравнение идёт по кодам символов в ASCII. Заглавные буквы (`A` = 65) идут **перед** строчными (`a` = 97). Поэтому `"Zebra" < "apple"` — это нормально для ASCII-сортировки.

## 4. Сортировка пузырьком

Та же, что в 08_02. Единственное отличие — условие обмена:

```c
// Было (один ключ):
if (students[j].rate < students[j + 1].rate)

// Стало (два ключа):
if (books[j].year > books[j + 1].year) {
    swap = 1;
} else if (books[j].year == books[j + 1].year) {
    if (strcmp(...) > 0) swap = 1;
}
```

Обратите внимание: годы сортируем по **возрастанию** (`>`), а в 08_02 оценки были по **убыванию** (`<`). Направление зависит от условия.

## 5. Почему не сравнивать названия вручную

Можно написать свой цикл сравнения строк, но `strcmp` — стандартная функция, она разрешена условием и делает ровно то, что нужно. Изобретать велосипед здесь нет смысла.

## 6. Частые ошибки

| Ошибка | Почему |
| --- | --- |
| Сравнивать только год | При равных годах порядок будет случайным |
| Сравнивать только название | Годы не отсортируются |
| `strcmp(a, b) < 0` для обмена | Это поменяет направление алфавитной сортировки |
| Забыть `#include <string.h>` | `strcmp` не объявлена |
| Перепутать направление сортировки | Возрастание vs убывание |
