# Сортировка студентов по баллам — теория

## 1. С чего начать

Ввод тот же, что в задании про средний балл: количество студентов, затем имя и оценка каждого. Нужно вывести имена, отсортированные по убыванию оценки, через `, `.

Сортировать можно только когда прочитаны все данные, поэтому храним их в массиве структур.

```
прочитать n → прочитать всех → отсортировать → вывести имена
```

## 2. Каркас решения (его стоит запомнить)

1. `typedef struct { char name[100]; int rate; } Student;`
2. `scanf("%d", &n)` и проверка `n < 1`.
3. `Student students[n];` и цикл чтения (как в 08_01).
4. Два вложенных цикла пузырька.
5. Цикл вывода: `, ` перед всеми именами, кроме первого.

## 3. Как выразить это на C

### Чтение

```c
scanf("%99s", students[i].name);
scanf("%d", &students[i].rate);
```

У `name` нет `&`, у `rate` есть.

### Пузырёк

```c
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - i - 1; j++) {
        if (students[j].rate < students[j + 1].rate) {
            Student temp = students[j];
            students[j] = students[j + 1];
            students[j + 1] = temp;
        }
    }
}
```

Сравниваем соседей `j` и `j + 1`. Если они стоят не в том порядке, меняем. После первого прохода минимальная оценка уходит в конец, после второго следующая и так далее, поэтому внутренний цикл каждый раз короче: `n - i - 1`.

Для убывания условие `<`, для возрастания `>`.

### Обмен структур

Структуру можно копировать целиком присваиванием, поэтому обмен идёт через `temp`, как для чисел. Менять отдельно `name` и `rate` не нужно, а массив `name` присвоить через `=` нельзя.

### Равные оценки

Условие `<` строгое: равные элементы не меняются местами, порядок ввода сохраняется. При `<=` он бы испортился.

### Запятая только между именами

```c
if (i > 0) printf(", ");
printf("%s", students[i].name);
```

## 4. Проверка на примере

```
3
Anton
10
Sergey
20
Andrey
30
```

Проход 1: 10 < 20, обмен → Sergey, Anton, Andrey; 10 < 30, обмен → Sergey, Andrey, Anton. Проход 2: 20 < 30, обмен → Andrey, Sergey, Anton.

Вывод: `Andrey, Sergey, Anton`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `<=` вместо `<` | Равные студенты поменяются местами |
| `>` вместо `<` | Сортировка пойдёт по возрастанию |
| Внутренний цикл до `n` | Выход за границу массива на `j + 1` |
| Менять только `rate` | Имена окажутся у чужих оценок |
| `students[j].name = ...` | Массив присваивать нельзя, ошибка компиляции |
| `scanf("%s", &students[i].name)` | Лишний `&`, ошибка с `-Werror` |
| `, ` после каждого имени | Лишняя запятая в конце |
