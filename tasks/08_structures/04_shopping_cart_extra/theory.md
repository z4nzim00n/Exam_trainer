# EXAM_08_04. Товары в корзине — теория

## 1. С чего начать

Новое здесь по сравнению с предыдущими заданиями:
- структура с **тремя** полями;
- **вычисления** на основе полей (цена × количество);
- **накопление** общей суммы.

Шаги:
1. Прочитать N и данные товаров.
2. Для каждого товара посчитать `price × quantity`.
3. Вывести строку товара с суммой.
4. Вывести общую сумму.
5. Освободить память.

## 2. Структура с тремя полями

```c
struct product {
    char name[100];
    int price;
    int quantity;
};
```

Принцип тот же, что и с двумя полями. Обращение:

```c
products[i].price
products[i].quantity
```

## 3. Переполнение при умножении

Это главная ловушка задания.

Цена до 10000, количество до 10000. Один товар: 10000 × 10000 = 10^8 — помещается в `int`.

Но 100 таких товаров: 100 × 10^8 = 10^10 — **не помещается** в `int` (максимум ~2.1 × 10^9).

Поэтому:

```c
long long total = 0;
long long line_sum = (long long)products[i].price * products[i].quantity;
```

Приведение `(long long)` перед умножением заставляет C выполнить умножение в типе `long long`. Без него умножение произойдёт в `int`, переполнится, и результат будет мусором.

### Формат вывода для long long

```c
printf("%lld", total);
```

`%lld` — спецификатор для `long long`. `%d` для него не подходит.

## 4. Чтение трёх полей

Для каждого товара:
1. Имя — через `getchar` до `'\n'`.
2. Цена — через `scanf("%d", ...)`.
3. Количество — через `scanf("%d", ...)`.

После каждого `scanf` съедаем `'\n'`. Итого три съедания на одну итерацию.

## 5. Вывод

Формат строки товара:

```c
printf("%s %d %d %lld", name, price, quantity, line_sum);
```

Между полями — пробелы. Перевод строки — между строками, не в конце.

Строка `Total`:

```c
printf("\nTotal %lld", total);
```

`\n` в начале, потому что это новая строка после последнего товара. Но после `total` переноса нет.

## 6. Частые ошибки

| Ошибка | Почему |
| --- | --- |
| `int total` | Переполнение при больших суммах |
| `price * quantity` без приведения | Умножение в int, потом присваивание в long long — поздно |
| `%d` для long long | Неопределённое поведение |
| Забыть `'\n'` между строками | Всё сольётся в одну строку |
| Лишний `'\n'` в конце | Нарушение формата |
