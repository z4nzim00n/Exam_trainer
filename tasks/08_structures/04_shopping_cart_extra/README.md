## EXAM_08_04. Товары в корзине

### Задание

| EXAM_08_04                  ||
|-----------------------------| ------- |
| **Уровень:**                | 3 |
| **Темы:**                   | Структуры, динамические массивы, вычисления. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `product` с полями «название», «цена» и «количество». Количество товаров указывается на стандартном потоке ввода первым числом. Далее для каждого товара задаются три строки:

1. название товара;
2. цена за единицу (целое число);
3. количество (целое число).

Программа должна вывести список товаров в формате `Название Цена Количество Сумма`, где Сумма = Цена × Количество. В конце вывести общую сумму всех товаров на отдельной строке в формате `Total Сумма`.

В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Количество товаров N — целое число от 1 до 100.
- Название — строка длиной до 99 символов.
- Цена и количество — целые числа от 0 до 10000.
- Общая сумма может превышать диапазон `int`, поэтому используйте `long long`.
- Динамическая память должна быть освобождена.

### Пример

Входные данные:

```text
3
Apple
50
10
Bread
30
2
Milk
80
3
```

Результат работы:

```text
Apple 50 10 500
Bread 30 2 60
Milk 80 3 240
Total 800
```

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
