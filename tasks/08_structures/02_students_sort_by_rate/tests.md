# EXAM_08_02. Сортировка студентов по баллам — Тесты

## Компиляция

```
gcc -Wall -Wextra -Werror -std=c11 main.c -o main
```

## Валидные данные

Многострочный ввод подаётся через `printf`: `\n` внутри него означает перевод строки.

| Вход | Результат | Команда | Пояснение |
|---|---|---|---|
| `3` `Anton` `10` `Sergey` `20` `Andrey` `30` | `Andrey, Sergey, Anton` | `printf '3\nAnton\n10\nSergey\n20\nAndrey\n30\n' \| ./main` | порядок по возрастанию на входе |
| `4` `Alice` `75` `Bob` `90` `Carol` `75` `Dave` `60` | `Bob, Alice, Carol, Dave` | `printf '4\nAlice\n75\nBob\n90\nCarol\n75\nDave\n60\n' \| ./main` | равные оценки сохраняют порядок ввода |
| `1` `Solo` `50` | `Solo` | `printf '1\nSolo\n50\n' \| ./main` | один студент, запятой нет |
| `3` `A` `30` `B` `20` `C` `10` | `A, B, C` | `printf '3\nA\n30\nB\n20\nC\n10\n' \| ./main` | уже отсортировано |
| `3` `A` `5` `B` `5` `C` `5` | `A, B, C` | `printf '3\nA\n5\nB\n5\nC\n5\n' \| ./main` | все равны, порядок не меняется |

## Некорректные данные (n/a)

| Вход | Ожидаемый результат | Команда | Причина |
|---|---|---|---|
| `0` | `n/a` | `echo "0" \| ./main` | студентов не может быть 0 |
| `-1` | `n/a` | `echo "-1" \| ./main` | отрицательное количество |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| `2` `A` `5` | `n/a` | `printf '2\nA\n5\n' \| ./main` | данных второго студента нет |
| `1` `A` `x` | `n/a` | `printf '1\nA\nx\n' \| ./main` | оценка не число |

## Cppcheck

Статический анализ кода. Нужен, чтобы найти потенциальные ошибки и подозрительные места в исходнике, которые компилятор может не заметить.

```
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

## Clang-format

Проверка стиля и форматирования кода.

```
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```
clang-format -i main.c
```

## Valgrind

Проверка ошибок работы с памятью. В решении нет `malloc`, проверка полезна для контроля выхода за границы массива.

```
printf '3\nAnton\n10\nSergey\n20\nAndrey\n30\n' | valgrind --leak-check=full ./main
```

Обратите внимание: Valgrind запускается уже на скомпилированном файле.
