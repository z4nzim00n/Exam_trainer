# EXAM_08_02. Сортировка студентов по баллам

## Задание

| EXAM_08_02 | |
|---|---|
| **Уровень:** | 3 |
| **Темы:** | Структуры, сортировка. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов задаётся вводом (первое число). Далее для каждого студента вводятся имя и оценка (целое число).

Отсортировать студентов по **убыванию** оценки и вывести их имена на стандартный поток вывода через запятую с пробелом. Студенты с одинаковой оценкой остаются в порядке ввода. После последнего имени запятой и переноса строки быть не должно. Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Имя студента не содержит пробелов.

## Примеры

| Входные данные | Результат работы |
|---|---|
| `3`<br>`Anton`<br>`10`<br>`Sergey`<br>`20`<br>`Andrey`<br>`30` | `Andrey, Sergey, Anton` |
| `4`<br>`Alice`<br>`75`<br>`Bob`<br>`90`<br>`Carol`<br>`75`<br>`Dave`<br>`60` | `Bob, Alice, Carol, Dave` |
