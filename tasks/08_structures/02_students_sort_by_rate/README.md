## EXAM_08_02. Сортировка студентов по баллам

> !ВАЖНО!
>
> Задание похоже на 08_01 (тот же ввод, та же структура), но вместо
> фильтрации по среднему баллу нужно отсортировать студентов по убыванию
> оценки и вывести их список.

### Задание

| EXAM_08_02                  ||
|-----------------------------| ------- |
| **Уровень:**                | 3 |
| **Темы:**                   | Структуры, динамические массивы, сортировка. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов указывается на стандартном потоке ввода первым числом. Далее для каждого студента задаются две строки:

1. имя студента;
2. оценка (целое число).

Программа должна отсортировать студентов **по убыванию** оценки и вывести их имена и оценки в отсортированном порядке. Каждый студент — на отдельной строке в формате `Имя Оценка`.

В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Количество студентов N — целое число от 1 до 100.
- Имя студента — строка длиной до 99 символов, состоящая из латинских букв, цифр и пробелов.
- Оценка — целое число от 0 до 100.
- Сортировка — по убыванию оценки (сначала наивысшая).
- Если у двух студентов одинаковая оценка, сохраняется порядок их появления во вводе (устойчивая сортировка).
- Формат строки вывода: имя, пробел, оценка.
- Динамическая память должна быть освобождена перед завершением программы.

### Пример

Входные данные:

```text
3
Anton
10
Sergey
20
Andrey
30
```

Результат работы:

```text
Andrey 30
Sergey 20
Anton 10
```

### Ещё пример

Входные данные:

```text
4
Alice
75
Bob
90
Carol
75
Dave
60
```

Результат работы:

```text
Bob 90
Alice 75
Carol 75
Dave 60
```

> Bob идёт первым (90). Alice и Carol имеют одинаковую оценку 75 — Alice выше, потому что она была введена раньше. Dave последний (60).

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
