## EXAM_08_03. Студент с наивысшим баллом

### Задание

| EXAM_08_03                  ||
|-----------------------------| ------- |
| **Уровень:**                | 2 |
| **Темы:**                   | Структуры, динамические массивы. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Количество студентов указывается на стандартном потоке ввода первым числом. Далее для каждого студента задаются две строки:

1. имя студента;
2. оценка (целое число).

Программа должна найти студента с **наивысшей** оценкой и вывести его имя и оценку в формате `Имя Оценка`.

Если несколько студентов имеют одинаковую максимальную оценку, вывести того, кто был введён первым.

В конце ответа не должно быть переноса на новую строку.

### Уточнения

- Количество студентов N — целое число от 1 до 100.
- Имя студента — строка длиной до 99 символов.
- Оценка — целое число от 0 до 100.
- Динамическая память должна быть освобождена перед завершением.

### Пример

Входные данные:

```text
3
Anton
10
Sergey
20
Andrey
15
```

Результат работы:

```text
Sergey 20
```

### Ещё пример

Входные данные:

```text
4
Alice
80
Bob
90
Carol
90
Dave
70
```

Результат работы:

```text
Bob 90
```

> Bob и Carol оба имеют 90, но Bob введён раньше.

> **Внимание:** процедура тестирования включает анализ стиля кода. Соблюдайте настройки `.clang-format` проекта. Также проверяйте программу на ошибки работы с памятью и утечки.
