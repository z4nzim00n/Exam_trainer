# EXAM_08_01. Один студент — теория

## 1. С чего начать

У студента два свойства: имя (строка) и оценка (число). Хранить их в двух отдельных переменных можно, но когда студентов много, удобнее объединить свойства в одну **структуру**.

Это задание про самое основное: как описать структуру, создать переменную и добраться до её полей.

## 2. Каркас решения (его стоит запомнить)

1. `typedef struct { char name[100]; int rate; } Student;`
2. `Student student;`
3. `scanf("%99s %d", student.name, &student.rate) != 2` → `n/a`.
4. `printf("%s %d", student.name, student.rate);`

## 3. Как выразить это на C

### Описание структуры

```c
typedef struct {
    char name[100];
    int rate;
} Student;
```

Структура — новый тип из нескольких полей. `typedef` даёт ему имя `Student`, и дальше не нужно писать слово `struct`. Описание стоит **до** `main`.

Для имени в 99 символов нужен массив на 100: одно место занимает `'\0'`.

### Переменная и поля

```c
Student student;
student.rate = 15;
```

Поле достаётся через **точку**: `student.name`, `student.rate`. Поле ведёт себя как обычная переменная своего типа.

### Чтение в поля

```c
scanf("%99s %d", student.name, &student.rate)
```

- у `student.name` нет `&`: имя массива уже адрес;
- у `student.rate` `&` есть, как у любого `int`;
- `99` защищает массив от переполнения;
- `scanf` вернёт 2, если оба значения прочитаны.

### Вывод

`printf("%s %d", ...)`: `%s` для строки, `%d` для числа. Пробел между ними в формате.

## 4. Проверка на примере

Ввод `Andrey` и `15`. В `student.name` попадает `Andrey`, в `student.rate` попадает `15`. Вывод: `Andrey 15`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| `scanf("%s", &student.name)` | Лишний `&`, ошибка компиляции с `-Werror` |
| Нет `&` перед `student.rate` | Программа упадёт |
| `student->rate` | Стрелка нужна для указателей, у переменной точка |
| Описать структуру внутри `main` после использования | Тип должен быть описан до использования |
| Забыть `;` после `}` | Ошибка компиляции |
| `%s` без ширины | Длинное имя переполнит массив |
