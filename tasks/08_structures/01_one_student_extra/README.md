# EXAM_08_01. Один студент

## Задание

| EXAM_08_01                  | |
|-----------------------------|---|
| **Уровень:**                | 1 |
| **Темы:**                   | Структуры. |
| **Директория для решения:** | src/ |
| **Файлы решения:**          | main.c |
| **Входные данные:**         | Стандартный поток ввода (stdin) |
| **Выходные данные:**        | Стандартный поток вывода (stdout) |

Создать структуру `student` с полями «имя» и «оценка». Ввести данные одного студента: имя и оценку (целое число). Вывести на стандартный поток вывода имя и оценку через пробел. Переноса строки в конце быть не должно. Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Имя студента не содержит пробелов.

## Примеры

| Входные данные | Результат работы |
|---|---|
| `Andrey`<br>`15` | `Andrey 15` |
| `Anna`<br>`0` | `Anna 0` |

**Внимание:** Мы любезно напоминаем вам, что процедура тестирования вашей программы включает анализ стиля кода. Пожалуйста, загляните в папку "materials/".
