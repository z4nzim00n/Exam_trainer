# EXAM_08_02. Сумма оценок — теория

## 1. С чего начать

В прошлом задании был один студент. Здесь их `n`, и количество известно только при запуске. Поэтому нужен **массив структур**: так же, как массив чисел, только каждый элемент это целый студент.

```
прочитать n → создать массив → в цикле прочитать всех, копя сумму → вывести сумму
```

Это ровно тот скелет, на котором строятся задания про средний балл, сортировку и поиск.

## 2. Каркас решения (его стоит запомнить)

1. Структура `Student`.
2. `scanf("%d", &n)` и проверка `n < 1`.
3. `Student students[n];` и `long sum = 0;`
4. `for (int i = 0; i < n; i++)`: читаем в `students[i]`, `sum += students[i].rate`.
5. `printf("%ld", sum);`

## 3. Как выразить это на C

### Массив структур

```c
Student students[n];
```

`students[0]`, `students[1]`, ... — отдельные студенты. Поле достаётся через точку **после** индекса: `students[i].rate`.

### Чтение в цикле

```c
scanf("%99s %d", students[i].name, &students[i].rate) != 2
```

Тот же `scanf`, что для одного студента, только вместо `student` стоит `students[i]`.

### Накопление суммы

```c
long sum = 0;
sum += students[i].rate;
```

Сумму нужно обнулить **до** цикла.

### Зачем проверка n < 1

Массив нулевой или отрицательной длины создавать нельзя: поведение неопределено. Поэтому ранняя проверка.

## 4. Проверка на примере

```
3
Andrey
15
Sergey
20
Anton
10
```

Сумма: 0 → 15 → 35 → 45. Вывод: `45`.

## 5. Частые ошибки

| Ошибка | Почему это неправильно |
|---|---|
| Не обнулить `sum` | В переменной мусор, сумма неверная |
| `students.rate` | Нужно указать, чей именно: `students[i].rate` |
| `students[i]->rate` | После `[i]` ставится точка |
| `scanf("%s", &students[i].name)` | Лишний `&`, ошибка с `-Werror` |
| Нет `&` перед `rate` | Программа упадёт |
| Цикл до `i <= n` | Выход за границу массива |
| `\n` в конце вывода | В конце переноса быть не должно |
