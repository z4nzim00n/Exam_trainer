# EXAM_08_03. Звёзды Голливуда

## Задание

| EXAM_08_03 | |
|---|---|
| **Уровень:** | 3 |
| **Темы:** | Структуры, строки. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Описать структуру с полями «имя», «фамилия» и «рост» (целое). Количество людей N задаётся вводом (первое число). Далее вводятся N людей: имя, фамилия и рост. После всех людей вводится имя для поиска.

Найти всех людей с введённым именем. Вывести на стандартный поток вывода их фамилии в порядке ввода через запятую с пробелом, затем двоеточие, пробел и средний рост найденных людей, округлённый математически до целого. Формат: `Фамилия1, Фамилия2: Рост`. Переноса строки в конце быть не должно. Если людей с таким именем нет, вывести "n/a". Проверить на валидность введённые данные. В случае ошибки выводить "n/a".

Примечание: Имена и фамилии не содержат пробелов.

Примечание: Для округления используйте функцию double round(double x); из библиотеки <math.h>.

## Примеры
