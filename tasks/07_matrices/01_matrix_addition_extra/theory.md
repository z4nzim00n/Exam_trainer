# EXAM_07_05. Сложение квадратных матриц — теория

## 1. Что означает сложение матриц

Складываются элементы, которые находятся на одинаковых позициях:

```text
C[i][j] = A[i][j] + B[i][j]
```

Например:

```text
A:       B:       C:
1 2      5 6      6  8
3 4      7 8      10 12
```

Никаких произведений и сумм по дополнительному индексу здесь нет.

## 2. Как хранить матрицу

```c
int matrix[10][10];
```

Это массив из 10 строк, в каждой из которых 10 целых чисел.

По условию `n` находится в диапазоне `1..10`. Используем только первые `n` строк и первые `n` столбцов.

Обращение к элементу:

```c
matrix[i][j]
```

- `i` — индекс строки;
- `j` — индекс столбца.

Индексы начинаются с нуля.

## 3. Нужны ли три массива

Нет. Можно:

1. Сохранить матрицу A.
2. Читать элементы B по одному.
3. Сразу прибавлять каждый элемент B к соответствующему элементу A.

```c
matrix[i][j] += value;
```

Это сокращение записи:

```c
matrix[i][j] = matrix[i][j] + value;
```

После чтения всей B массив уже содержит результат.

Исходная A больше не нужна, поэтому её можно изменить.

## 4. Вложенные циклы

```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        /* Работа с matrix[i][j]. */
    }
}
```

Внешний цикл выбирает строку. Внутренний перебирает все столбцы этой строки.

Для `n = 2` порядок будет таким:

```text
[0][0]
[0][1]
[1][0]
[1][1]
```

Именно в таком порядке элементы поступают на вход.

`scanf("%d", ...)` пропускает пробелы и переводы строк между числами.

## 5. Алгоритм

1. Прочитать размер.
2. Прочитать A в массив.
3. Прочитать B, прибавляя элементы к массиву.
4. Вывести полученную матрицу.

Проверки результата `scanf` позволяют завершить программу, если чтение не удалось. Но условие гарантирует корректный ввод и не требует печатать сообщение об ошибке.

## 6. Как не вывести лишние разделители

Пробел печатаем перед элементом, если он не первый в строке:

```c
if (j > 0) {
    putchar(' ');
}
```

Перевод строки печатаем перед строкой, если она не первая:

```c
if (i > 0) {
    putchar('\n');
}
```

Так разделители появляются только между значениями:

- нет пробела в конце строки;
- нет перевода строки в конце ответа.

## 7. Границы и сложность

Каждый элемент входных матриц находится в диапазоне `-100..100`.

Сумма находится в диапазоне `-200..200` и безопасно помещается в `int`.

Количество обрабатываемых элементов пропорционально `n²`, поэтому время работы — `O(n²)`.

В этой реализации память фиксирована: массив содержит 100 элементов независимо от введённого `n`.

## 8. Частые ошибки

| Ошибка | Последствие |
| --- | --- |
| Использовать `i <= n` или `j <= n` | Обрабатываются лишние элементы, возможен выход за границы |
| Перепутать строку и столбец | Часть данных окажется на неверных позициях |
| Заменять элемент значением B вместо прибавления | Результатом станет B, а не сумма |
| Читать A и B попеременно по одному элементу | Это не соответствует формату ввода |
| Печатать пробел после каждого числа | Появятся пробелы в конце строк |
| Печатать перенос после каждой строки | Появится запрещённый завершающий перенос |
