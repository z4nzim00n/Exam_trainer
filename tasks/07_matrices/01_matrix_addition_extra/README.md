## EXAM_07_05. Сложение квадратных матриц

### Задание

| EXAM_07_05 ||
| ------ | ------- |
| **Уровень:** | 3 |
| **Темы:** | Матрицы, вложенные циклы. |
| **Директория для решения:** | src/ |
| **Файлы решения:** | main.c |
| **Входные данные:** | Стандартный поток ввода (stdin) |
| **Выходные данные:** | Стандартный поток вывода (stdout) |

Написать программу, вычисляющую сумму двух квадратных матриц A и B размера N × N.

Через стандартный поток ввода stdin задаются:

1. Целое число N — размер матриц.
2. N × N целых чисел — элементы матрицы A построчно.
3. N × N целых чисел — элементы матрицы B построчно.

Каждый элемент результирующей матрицы C равен сумме элементов A и B, расположенных на той же позиции:

```text
C[i][j] = A[i][j] + B[i][j]
```

Результат вывести на стандартный поток вывода stdout в виде таблицы.

### Формат вывода

- Между соседними элементами строки должен быть ровно один пробел.
- Между строками матрицы должен быть перевод строки.
- После последнего элемента каждой строки не должно быть пробела.
- В конце ответа не должно быть переноса на новую строку.

### Ограничения и уточнения

- Гарантируется корректный ввод.
- Размер N находится в диапазоне от `1` до `10` включительно.
- Элементы матриц — целые числа от `-100` до `100` включительно.
- Разрешается использовать обычные массивы фиксированного размера. Динамическая память не обязательна.
- Здесь требуется сложение матриц, а не их умножение.

### Примеры

**Пример 1**

Входные данные:

```text
2
1 2
3 4
5 6
7 8
```

Результат работы:

```text
6 8
10 12
```

**Пример 2**

Входные данные:

```text
1
-5
8
```

Результат работы:

```text
3
```

**Пример 3**

Входные данные:

```text
2
1 -2
0 4
-1 2
0 -4
```

Результат работы:

```text
0 0
0 0
```
