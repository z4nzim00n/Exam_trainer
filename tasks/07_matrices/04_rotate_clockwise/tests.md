# EXAM_06_03. Поворот матрицы — Тесты

## Компиляция

Решение собирается с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `2 3\n1 2 3\n4 5 6` | `4 1\n5 2\n6 3` | `printf "2 3\n1 2 3\n4 5 6\n" \| ./main` | пример из условия (прямоугольная) |
| `3 3\n1 2 3\n4 5 6\n7 8 9` | `7 4 1\n8 5 2\n9 6 3` | `printf "3 3\n1 2 3\n4 5 6\n7 8 9\n" \| ./main` | пример из условия (квадратная) |
| `3 1\n1\n2\n3` | `3 2 1` | `printf "3 1\n1\n2\n3\n" \| ./main` | столбец превращается в строку |
| `1 1\n42` | `42` | `printf "1 1\n42\n" \| ./main` | матрица 1x1 |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
| --- | --- | --- | --- |
| `0 5` | `n/a` | `echo "0 5" \| ./main` | нулевая размерность |
| `3 -2` | `n/a` | `echo "3 -2" \| ./main` | отрицательная размерность |
| `abc 3` | `n/a` | `echo "abc 3" \| ./main` | не число |
| `2 2\n1 2\n3` | `n/a` | `printf "2 2\n1 2\n3\n" \| ./main` | не хватает элементов матрицы |

### Cppcheck

Статический анализ кода.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Проверка успешного сценария:

```bash
printf "2 3\n1 2 3\n4 5 6\n" | valgrind --leak-check=full ./main
```

Проверка сценария с ошибкой ввода:

```bash
printf "2 2\n1 2\n3\n" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
