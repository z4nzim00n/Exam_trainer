# EXAM_06_03. Поворот матрицы — теория

## 1. С чего начать

Нужно повернуть матрицу размером $M \times N$ на 90 градусов по часовой стрелке.

Давай посмотрим, как меняются координаты элементов.
Пусть исходная матрица $A$ имеет размер $2 \times 3$ ($M=2$ строки, $N=3$ столбца):

```text
1 2 3   (строка 0)
4 5 6   (строка 1)
```

После поворота на 90° по часовой стрелке мы получим матрицу $B$ размером $3 \times 2$ ($N=3$ строки, $M=2$ столбца):

```text
4 1
5 2
6 3
```

Заметь закономерность:
- **Последняя строка** старой матрицы (`4 5 6`) стала **первым столбцом** новой.
- **Первая строка** старой матрицы (`1 2 3`) стала **последним столбцом** новой.

## 2. Главный трюк: печать без второго массива

Можно выделить память под вторую матрицу, переложить туда элементы и вывести её. Но есть способ элегантнее и экономнее.

Мы можем хранить только **исходную** матрицу, а при печати просто идти по координатам **новой** (повёрнутой) матрицы и вычислять, какой элемент из старой матрицы нужно достать.

Новая матрица имеет $N$ строк и $M$ столбцов. Запустим два цикла:
```c
for (int i = 0; i < n; i++) {       // i — строка новой матрицы
    for (int j = 0; j < m; j++) {   // j — столбец новой матрицы
        // ...
    }
}
```

## 3. Математика индексов

Как найти элемент для позиции `[i][j]` в новой матрице?

1. Столбец новой матрицы `i` — это строка старой матрицы. Значит, `orig_col = i`.
2. Строка новой матрицы `j` — это столбец старой матрицы, но идущий снизу вверх. Значит, `orig_row = m - 1 - j`.

Проверим для элемента `4` в новой матрице (он находится в `i=0, j=0`):
- `orig_row = 2 - 1 - 0 = 1`
- `orig_col = 0`
  В старой матрице элемент `[1][0]` — это действительно `4`!

Проверим для элемента `3` в новой матрице (он находится в `i=2, j=1`):
- `orig_row = 2 - 1 - 1 = 0`
- `orig_col = 2`
  В старой матрице элемент `[0][2]` — это `3`!

## 4. Работа с одномерным массивом

Мы храним матрицу в одномерном массиве. Индекс элемента вычисляется как:
```c
index = row * N + col
```
*(Обрати внимание: умножаем именно на $N$ — количество столбцов в **исходной** матрице).*

Подставляем наши вычисленные координаты:
```c
int orig_row = m - 1 - j;
int orig_col = i;
int index = orig_row * n + orig_col;

printf("%d", matrix[index]);
```

## 5. Алгоритм решения

1. Прочитать $M$ и $N$. Проверить, что они $> 0$.
2. Выделить память под $M \times N$ элементов.
3. Прочитать элементы. При ошибке — `free`, `n/a`, выход.
4. Запустить цикл по $i$ от $0$ до $N-1$ (строки новой матрицы).
5. Запустить цикл по $j$ от $0$ до $M-1$ (столбцы новой матрицы).
6. Вывести пробел, если $j > 0$.
7. Вычислить `orig_row` и `orig_col`, вывести элемент.
8. Вывести `\n`, если $i < N - 1$.
9. Освободить память.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Умножать `orig_row` на `m` | В формуле индекса `row * cols + col` нужно умножать на количество столбцов **исходной** матрицы (`n`) |
| Перепутать `m` и `n` в циклах вывода | Новая матрица имеет размер $N \times M$, поэтому внешний цикл до `n`, внутренний до `m` |
| Пробел в конце строки | Verter выдаст ошибку форматирования |
| Лишний `\n` в самом конце | Условие требует отсутствие переноса после последней строки |
