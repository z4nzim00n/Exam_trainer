# EXAM_06_05. Квадраты чисел по спирали — теория

## 1. С чего начать

Задача похожа на предыдущую, но есть два отличия:
1. Спираль закручивается **против часовой стрелки**.
2. В ячейки записываются **квадраты чисел**: $0^2, 1^2, 2^2 \dots$ до $(N^2 - 1)^2$.

Начинаем мы по-прежнему с левого верхнего угла `(0, 0)`.

## 2. Порядок обхода (против часовой стрелки)

Чтобы закрутить спираль в нужную сторону, изменим порядок шагов:
1. **Вниз:** идём по столбцу `left` от `top` до `bottom`.
2. **Вправо:** идём по строке `bottom` от `left` до `right`.
3. **Вверх:** идём по столбцу `right` от `bottom` до `top`.
4. **Влево:** идём по строке `top` от `right` до `left`.

После каждого шага соответствующая граница сдвигается внутрь.

## 3. Запись квадратов

Нам нужна переменная `num`, которая начинается с `0` и увеличивается на `1` на каждом шаге.
В саму матрицу мы записываем `num * num`:

```c
matrix[i * n + left] = num * num;
num++;
```

Условие завершения цикла: `num < n * n` (так как последнее число — это $N^2 - 1$).

## 4. Защита от перезаписи центра

Как и в предыдущей задаче, если $N$ нечётное (например, 3), в центре останется одна ячейка.
Мы заполним её на шаге 1 (вниз). Но циклы 2, 3 и 4 всё равно попытаются запуститься!

Чтобы они не перезаписали центр мусором, в условие каждого `for` добавляем проверку `num < n * n`:

```c
for (int i = left; i <= right && num < n * n; i++)
```

Как только `num` достигнет $N^2$, все оставшиеся циклы мгновенно прервутся.

## 5. Алгоритм решения

1. Прочитать $N$. Проверить, что $N > 0$.
2. Выделить память под $N \times N$ элементов.
3. Задать границы: `top = 0`, `bottom = n - 1`, `left = 0`, `right = n - 1`.
4. Запустить цикл `while (num < n * n)`.
5. Пройти вниз, записывая `num * num`. Сдвинуть `left++`.
6. Пройти вправо, записывая `num * num`. Сдвинуть `bottom--`.
7. Пройти вверх, записывая `num * num`. Сдвинуть `right--`.
8. Пройти влево, записывая `num * num`. Сдвинуть `top++`.
9. Вывести матрицу с правильным форматированием.
10. Освободить память.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Записать просто `num`, а не `num * num` | Условие требует квадраты чисел |
| Начать `num` с 1 | Последовательность должна начинаться с $0^2 = 0$ |
| Забыть `num < n * n` внутри `for` | Для нечётных $N$ центр матрицы перезапишется |
| Перепутать порядок обхода | Спираль закрутится по часовой стрелке, а не против |
| Лишний пробел в конце строки | Verter выдаст Presentation Error |
| Перенос строки `\n` в самом конце | Условие требует отсутствие переноса после последней строки |
