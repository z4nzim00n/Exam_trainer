# EXAM_06_04. Спираль в матрице — теория

## 1. С чего начать

Нужно заполнить матрицу $N \times N$ числами от $1$ до $N^2$ по часовой стрелке, начиная с левого верхнего угла.

Самый надёжный и понятный способ — **метод сужающихся границ**.
Представь, что ты рисуешь спираль. Ты проходишь по краю, а затем этот край становится "стеной", к которой больше нельзя прикасаться.

## 2. Четыре границы

Заведём 4 переменные, которые ограничивают текущий "слой" спирали:
- `top = 0` (верхняя строка)
- `bottom = n - 1` (нижняя строка)
- `left = 0` (левый столбец)
- `right = n - 1` (правый столбец)

Также нам нужна переменная `num = 1`, которую мы будем записывать в ячейки и увеличивать.

## 3. Алгоритм одного витка

Пока `num <= n * n`, мы делаем 4 шага:

1. **Вправо:** идём по строке `top` от `left` до `right`. Заполняем ячейки. После этого строка `top` заполнена, поэтому сдвигаем границу: `top++`.
2. **Вниз:** идём по столбцу `right` от `top` до `bottom`. Заполняем. Сдвигаем границу: `right--`.
3. **Влево:** идём по строке `bottom` от `right` до `left`. Заполняем. Сдвигаем границу: `bottom--`.
4. **Вверх:** идём по столбцу `left` от `bottom` до `top`. Заполняем. Сдвигаем границу: `left++`.

После этого мы переходим к следующему внутреннему слою.

## 4. Зачем нужна проверка `num <= n * n` внутри циклов?

Если $N$ чётное (например, 2 или 4), спираль идеально замкнётся в центре.
Но если $N$ нечётное (например, 3), в самом центре останется **одна ячейка**.
Мы заполним её на шаге 1 (вправо). Но циклы 2, 3 и 4 всё равно попытаются запуститься! Если мы не проверим, что `num` уже достиг максимума, они перезапишут центр мусором или выйдут за границы.

Поэтому в каждом `for` мы добавляем условие:
```c
for (int i = left; i <= right && num <= n * n; i++)
```
Как только `num` станет больше $N^2$, все циклы мгновенно остановятся.

## 5. Работа с одномерным массивом

Мы храним матрицу в одномерном массиве. Индекс вычисляется стандартно:
```c
index = row * n + col
```
Например, при проходе вправо (шаг 1) строка фиксирована (`top`), а столбец меняется (`i`):
```c
matrix[top * n + i] = num++;
```

## 6. Форматирование вывода

Выводим матрицу построчно.
- Перед каждым элементом, кроме первого в строке, ставим пробел.
- После каждой строки, кроме последней, ставим перенос `\n`.

```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (j > 0) printf(" ");
        printf("%d", matrix[i * n + j]);
    }
    if (i < n - 1) printf("\n");
}
```

## 7. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Забыть `num <= n * n` внутри `for` | Для нечётных $N$ центр матрицы перезапишется |
| Перепутать `row * n + col` | Элементы запишутся не в те ячейки |
| Не сдвинуть границу (`top++`, `right--` и т.д.) | Программа зациклится на одном слое |
| Начать `num` с 0 | По условию нужно заполнять от 1 до $N^2$ |
| Лишний пробел в конце строки | Verter выдаст Presentation Error |
| Перенос строки `\n` в самом конце | Условие требует отсутствие переноса после последней строки |
