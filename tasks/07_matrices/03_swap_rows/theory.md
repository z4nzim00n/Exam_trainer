# EXAM_06_02. Перестановка строк — теория

## 1. С чего начать

Нужно прочитать матрицу размера $M \times N$, найти в ней минимальный и максимальный элементы, определить номера строк, где они находятся **впервые**, и поменять эти две строки местами.

Особенности задачи:
- Матрица не обязательно квадратная ($M$ может быть не равно $N$).
- Нас интересуют только **первые** вхождения минимума и максимума.
- Если минимум и максимум находятся в одной строке, матрица не изменится.
- В конце вывода не должно быть переноса строки.

## 2. Как хранить прямоугольную матрицу

Как и в предыдущей задаче, мы используем одномерный динамический массив размером $M \times N$:

```c
int *matrix = malloc((size_t)m * n * sizeof(int));
```

### Как узнать номер строки и столбца?

Элементы читаются построчно. Зная общий индекс элемента `i` и количество столбцов `n`, можно вычислить его координаты:

- **Номер строки:** `row = i / n` (целочисленное деление отбрасывает остаток).
- **Номер столбца:** `col = i % n` (остаток от деления).

Например, для матрицы $4 \times 3$ ($n = 3$) элемент с индексом `i = 7`:
- Строка: `7 / 3 = 2` (третья строка, так как нумерация с нуля).
- Столбец: `7 % 3 = 1` (второй столбец).

## 3. Как найти первое вхождение

Мы проходим по массиву от `i = 1` до `m * n - 1` и сравниваем элементы с текущими `min` и `max`.

Чтобы запомнить именно **первое** вхождение, используем **строгие неравенства**:

```c
if (matrix[i] < min) {
    min = matrix[i];
    min_row = i / n;
}
```

Если в массиве есть несколько одинаковых минимальных элементов (например, `1 5 1 2`), то при встрече второго `1` условие `1 < 1` будет ложным. Программа проигнорирует его и сохранит индекс самой первой единицы.

## 4. Как поменять строки местами

Зная индексы строк `min_row` и `max_row`, нам не нужно переставлять весь массив. Достаточно пройтись по столбцам и поменять элементы местами:

```c
for (int j = 0; j < n; j++) {
    int temp = matrix[min_row * n + j];
    matrix[min_row * n + j] = matrix[max_row * n + j];
    matrix[max_row * n + j] = temp;
}
```

Если `min_row` совпадает с `max_row` (например, в матрице всего одна строка или все элементы равны), цикл просто поменяет элементы строки сами с собой. Матрица не изменится, что полностью соответствует логике.

## 5. Форматирование вывода

Выводим матрицу построчно.
- Перед каждым элементом, кроме первого в строке, ставим пробел.
- После каждой строки, кроме последней, ставим перенос `\n`.

```c
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (j > 0) printf(" ");
        printf("%d", matrix[i * n + j]);
    }
    if (i < m - 1) printf("\n");
}
```

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| Использовать `<=` или `>=` при поиске min/max | Будет найдено последнее вхождение, а не первое |
| Перепутать `m` и `n` при выделении памяти | Матрица $M \times N$ имеет $M$ строк и $N$ столбцов, всего $M \times N$ элементов |
| Считать номер строки как `i / m` | Делить нужно именно на количество столбцов `n` |
| Не проверить `m <= 0` или `n <= 0` | Размерности должны быть положительными |
| Лишний пробел в конце строки | Verter выдаст Presentation Error |
| Перенос строки `\n` в самом конце | Условие требует отсутствие переноса после последней строки |
