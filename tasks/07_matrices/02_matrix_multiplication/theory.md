# EXAM_06_01. Умножение квадратных матриц — теория

## 1. С чего начать

Нужно перемножить две квадратные матрицы $A$ и $B$ размера $N \times N$ и получить матрицу $C$.

Правило умножения матриц:
Элемент $C_{i,j}$ (строка `i`, столбец `j`) равен сумме произведений элементов `i`-й строки матрицы $A$ на `j`-й столбец матрицы $B$.

Формула:
$$C_{i,j} = \sum_{k=0}^{N-1} A_{i,k} \times B_{k,j}$$

## 2. Как хранить матрицы

Размерность $N$ вводится пользователем, поэтому использовать статические массивы (`int a[100][100]`) нельзя. Нужно выделять память динамически.

Вместо массива указателей (`int **a`) проще и эффективнее выделить **один сплошной одномерный массив** размером $N \times N$:

```c
int *a = malloc((size_t)n * n * sizeof(int));
```

### Как обращаться к элементам

Чтобы обратиться к элементу в строке `i` и столбце `j` в одномерном массиве, используется формула:

```c
index = i * n + j
```

Например, для матрицы $3 \times 3$ ($n = 3$):
- Элемент $A_{0,0}$ → индекс `0 * 3 + 0 = 0`
- Элемент $A_{1,2}$ → индекс `1 * 3 + 2 = 5`
- Элемент $A_{2,2}$ → индекс `2 * 3 + 2 = 8`

## 3. Алгоритм умножения

Для вычисления каждого элемента $C_{i,j}$ нужны три вложенных цикла:

1. **Цикл `i` (от 0 до n-1):** перебирает строки матрицы $A$ и $C$.
2. **Цикл `j` (от 0 до n-1):** перебирает столбцы матрицы $B$ и $C$.
3. **Цикл `k` (от 0 до n-1):** вычисляет сумму произведений для конкретного элемента $C_{i,j}$.

```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        c[i * n + j] = 0; // Обнуляем ячейку перед суммированием
        for (int k = 0; k < n; k++) {
            c[i * n + j] += a[i * n + k] * b[k * n + j];
        }
    }
}
```

## 4. Форматирование вывода

Условие требует строгий формат:
- Элементы разделены пробелами.
- В конце строки **не должно быть пробела**.
- После каждой строки матрицы нужен перенос `\n`.
- В самом конце ответа **не должно быть переноса строки**.

Реализация:
```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (j > 0) printf(" "); // Пробел только перед 2-м, 3-м и т.д. элементами
        printf("%d", c[i * n + j]);
    }
    if (i < n - 1) printf("\n"); // Перенос строки, кроме последней
}
```

## 5. Управление памятью

Мы выделяем память под три массива: `a`, `b` и `c`.
Если при выделении памяти для `b` или `c` возникнет ошибка (`NULL`), нужно обязательно освободить уже выделенную память (например, массив `a`), чтобы избежать утечек.

То же самое касается ошибок ввода (`scanf != 1`): перед выходом из программы с `n/a` нужно вызвать `free` для всех трёх указателей. Вызов `free(NULL)` безопасен и ничего не делает, поэтому можно просто перечислить их все.

## 6. Частые ошибки

| Ошибка | Почему это неправильно |
| --- | --- |
| `malloc(n * n * sizeof(int))` без `(size_t)` | При больших `n` (например, 50000) `n * n` переполнит `int` до умножения на `sizeof` |
| Забыть обнулить `c[i * n + j] = 0` | В ячейке будет мусор, и сумма накопится некорректно |
| Перепутать индексы: `a[k * n + i]` | Это транспонирование, а не умножение строки на столбец |
| Пробел в конце строки: `printf("%d ", ...)` | Verter выдаст ошибку форматирования (Presentation Error) |
| Лишний `\n` в самом конце | Условие прямо запрещает перенос строки в конце ответа |
| Не освободить память при ошибке `scanf` | Valgrind покажет утечку памяти (definitely lost) |
