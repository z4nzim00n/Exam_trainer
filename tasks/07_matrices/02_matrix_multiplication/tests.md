# EXAM_06_01. Умножение квадратных матриц — Тесты

## Компиляция

Решение собирается с жёсткими предупреждениями:

```bash
gcc -Wall -Wextra -Werror main.c -o main
```

## Валидные данные

| Вход | Результат | Команда | Пояснение |
| --- | --- | --- | --- |
| `2\n1 2\n3 4\n5 6\n7 8` | `19 22\n43 50` | `printf "2\n1 2\n3 4\n5 6\n7 8\n" \| ./main` | пример из условия |
| `1\n5\n6` | `30` | `printf "1\n5\n6\n" \| ./main` | матрицы 1x1 |
| `2\n1 0\n0 1\n2 3\n4 5` | `2 3\n4 5` | `printf "2\n1 0\n0 1\n2 3\n4 5\n" \| ./main` | умножение на единичную матрицу |

## Некорректные данные (`n/a`)

| Вход | Ожидаемый результат | Команда | Причина |
| --- | --- | --- | --- |
| `0` | `n/a` | `echo "0" \| ./main` | размерность должна быть > 0 |
| `-2` | `n/a` | `echo "-2" \| ./main` | отрицательная размерность |
| `abc` | `n/a` | `echo "abc" \| ./main` | не число |
| `2\n1 2\n3` | `n/a` | `printf "2\n1 2\n3\n" \| ./main` | не хватает элементов для матрицы A |
| `2\n1 2 3 4\n1 2` | `n/a` | `printf "2\n1 2 3 4\n1 2\n" \| ./main` | не хватает элементов для матрицы B |

### Cppcheck

Статический анализ кода.

```bash
cppcheck --enable=all --suppress=missingIncludeSystem main.c
```

### Clang-format

Проверка стиля и форматирования кода.

```bash
clang-format -n -Werror main.c
```

Если нужно автоматически отформатировать файл:

```bash
clang-format -i main.c
```

### Valgrind

Проверка ошибок работы с памятью и утечек памяти.

Проверка успешного сценария:

```bash
printf "2\n1 2\n3 4\n5 6\n7 8\n" | valgrind --leak-check=full ./main
```

Проверка сценария с ошибкой ввода (память должна освободиться):

```bash
printf "2\n1 2\n3\n" | valgrind --leak-check=full ./main
```

> Обратите внимание: Valgrind запускается уже на скомпилированном файле.
