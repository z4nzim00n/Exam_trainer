## 🚀 Быстрый старт

1. Скачай или склонируй репозиторий.
2. Открой `trainer.html` в **Chromium-браузере** (Chrome, Edge, Brave, Opera).
3. Нажми **«Выбрать папку проекта»** и укажи корень репозитория.
4. Разреши доступ к файлам.
5. Выбирай задание в дереве слева. Условие откроется справа.
6. Решай в `main.c` в своём редакторе, потом проверяй (см. [«Проверка решения»](#-проверка-решения)).

> Если застрял, открой 💡 **Теорию**. Потом 🧪 **Тесты**. И только в конце ✅ **Решение**.

## 🛠 Инструменты

В корне лежат два HTML-файла.

| Файл | Для чего |
| --- | --- |
| `trainer.html` | Каталог всех заданий: дерево слева, содержимое справа. Условие, теория, тесты и решения открываются кликом, а при выборе теории или решения экран делится на две части, чтобы сравнивать. |
| `theory_tests.html` | Теория и тесты отдельной страницей. |

### Почему HTML, а не обычное приложение

Это сделано осознанно.

**1. Безопасность.** HTML-файл — это открытый текст. Любой может открыть его в редакторе и увидеть, что именно он делает. В нём нет скрытого кода. Запускать `.exe` от незнакомого человека из интернета рискованно, и просить об этом других неправильно. Здесь доверять вслепую не нужно: файл можно прочитать целиком.

**2. Работает везде.** Один и тот же файл открывается на Windows, macOS и Linux. Не нужно собирать три версии под разные системы, ничего устанавливать и подписывать.

### Почему нужен Chromium и выбор папки

Причина та же: **мультиплатформенность**.

- Браузер по умолчанию не имеет права читать твои файлы. Это защита: иначе любая страница могла бы лазить по диску.
- Чтобы страница могла показать задания из репозитория, ей нужно **явно выдать доступ к одной папке**. Для этого используется File System Access API. Он есть в Chromium-браузерах (Chrome, Edge, Brave, Opera). В Firefox и Safari его нет.
- Папку выбираешь ты сам через системное окно. У Windows, macOS и Linux разные файловые системы и пути (`C:\Users\...`, `/home/...`, `/Users/...`). Прописать путь заранее, чтобы работало у всех, нельзя. Выбор папки при запуске решает проблему без привязки к системе.
- Доступ получает только выбранная папка. Остальной диск страница не видит.

### Важно: это не официальный список

Задания **воссозданы по памяти и записям** и не являются официальными. Формулировки, примеры и тесты могли отличаться от настоящих. Цель этого репозитория — разобраться в приёмах и научиться писать небольшие программы самостоятельно.

Эталонные решения писались с помощью ИИ и проверялись нашими тестами, но **не настоящей школьной системой проверки**. Если тест и условие расходятся, верь условию и здравому смыслу.

### Что означает `_extra`

Папки с суффиксом `_extra` — дополнительные тренировочные задания. Часть из них очень простая, чтобы вникнуть в тему с нуля. Они **не подтверждены как экзаменационные**: могут не попасться или встретиться в другом виде. Отсутствие `_extra` тоже ничего не гарантирует.
