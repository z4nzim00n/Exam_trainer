## Быстрый старт

1. Скачай или склонируй репозиторий.
2. Открой `trainer.html` в браузере на базе Chromium: Chrome, Edge, Brave или Opera.
3. Нажми **«Выбрать папку проекта»** и укажи корень репозитория.
4. Разреши странице доступ к выбранной папке.
5. Выбери задание в дереве слева — его условие откроется справа.
6. Решай задачу в `main.c` в своём редакторе, затем запускай тесты.

Для быстрой проверки решений в заданиях есть автотесты. Когда освоишь материал, переходи к режиму повторения — он описан ниже, в разделе «Инструменты».

## Инструменты

В корне проекта находятся три HTML-страницы.

| Файл | Назначение |
| --- | --- |
| `trainer.html` | Каталог заданий: условие, теория, тесты и решения. При открытии теории или решения экран делится на две части — удобно сравнивать материалы. |
| `random2.html` | Режим повторения: выдаёт два случайных задания — среднее и сложное — из разделов 03 и выше. |
| `theory_tests.html` | Отдельная страница с тестами по теории. |

### Когда переходить на `random2.html`

Сначала пройди материал в `trainer.html`: 2–3 круга по всем разделам. После этого переключись на `random2.html`. Он не заставляет перечитывать базу, а поддерживает навыки на заданиях, близких к экзамену, и не перегружает.

### Почему HTML, а не отдельное приложение

Это осознанный выбор.

**Прозрачность.** HTML-файл можно открыть в обычном редакторе и посмотреть, что он делает. Не нужно запускать неизвестный исполняемый файл и доверять ему вслепую.

**Кроссплатформенность.** Один и тот же файл можно использовать в Windows, macOS и Linux. Не нужно собирать и поддерживать отдельные версии приложения для каждой системы.

### Почему нужен Chromium и выбор папки

Браузер не должен получать свободный доступ ко всем файлам компьютера. Поэтому тренажёр просит явно выбрать папку проекта.

Для этого используется **File System Access API**. Оно доступно в Chromium-браузерах, например Chrome, Edge, Brave и Opera, но не поддерживается Firefox и Safari в необходимом для тренажёра виде.

Папку выбираешь ты сам через системное окно. Это также позволяет не привязываться к конкретным путям Windows, macOS или Linux. Доступ выдаётся выбранной папке, а не всему диску.

## Структура задания

В большинстве папок заданий находятся восемь файлов:

| Файл | Для чего нужен |
| --- | --- |
| `.clang-format` | Правила форматирования кода. |
| `main.c` | Файл, в котором нужно написать решение. В нём оставлена начальная структура программы. |
| `README.md` | Условие задания. |
| `run_test.sh` | Скрипт автоматической проверки: форматирование, компиляция, `cppcheck`, `valgrind` и тесты ввода/вывода. |
| `solution.c` | Один из вариантов решения. |
| `solution_commented.c` | То же решение с комментариями. |
| `tests.md` | Примеры ручной проверки и команды для работы с `cppcheck`, `valgrind` и компилятором. |
| `theory.md` | Объяснение подхода к решению. |

В таблице ниже перечислено **62 задания**. Автотесты помогают быстрее проверить работу: ручная проверка каждого задания даже по две минуты заняла бы около двух часов.

Если скрипт не запускается из-за отсутствия права на выполнение, перейди в папку задания и выполни:

```bash
chmod +x run_test.sh
./run_test.sh
```

Либо запусти скрипт через Bash:

```bash
bash run_test.sh
```

> **Обрати внимание:** в некоторых заданиях проверка ожидает `return 0` даже при некорректном вводе. Сверяйся с условием и тестами конкретного задания, а не переноси это правило на все программы.

### Что означает суффикс `_extra`

Папки с суффиксом `_extra` содержат дополнительные тренировочные задания. Они помогают освоить тему с нуля, но **не подтверждены как экзаменационные**. Такие задачи могут не встретиться на экзамене или попасться в другом виде. Отсутствие суффикса тоже ничего не гарантирует.
